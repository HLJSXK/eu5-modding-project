# -----------------------------------------
# THE DEHQAN REVIVAL — the amirs estate, refounded
#
# After Expulsion or Eradication, the estate SLOT — men of the
# sword holding land — survives; its Turko-Mongol content does
# not. These privileges are the NEW charter: the Sasanian-descended
# Iranian gentry (the asvaran-dehqan inheritance, the class that
# kept the Shahnama alive and that the iqta system destroyed),
# consciously revived from above. The great Iranian counterfactual,
# priced: it never happened historically because the ghulam and the
# new confederation were always cheaper — here it is slower and
# politically expensive, but native.
#
# Gated on matter_turk_dissolved AND NOT matter_tork_iranized
# (Iranization fills the gentry niche with the commuted amirs —
# no vacuum, no revival). Note matter_post_tribal_state's permanent
# −30% amir power suppresses the refounded estate too — intended:
# the dehqan estate is born under crown dominance; that is the
# point of refounding from above.
#
# Design: docs/design/matter_of_tork_design.md, round-6 decisions.
# -----------------------------------------
