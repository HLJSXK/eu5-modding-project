# The axis is MOBILIZED vs MONETIZED piety. Strict enforcement
# converts the population's religiosity into levy manpower and
# clergy zeal at the cost of the urban commercial-cultural
# economy; lax enforcement (the Inju/Shiraz posture) frees the
# bazaar and the diwan and demobilizes the same energy.
#
# WIRING NOTES (elsewhere):
#  - ghazi_lord_at_war / is_legitimate_ghaza_target gains:
#        has_law_option = lax_hisba_enforcement
#    (a court that openly tolerates vice is legible prey for the
#    din-panah doctrine — Mubariz al-Din's actual pretext at
#    Shiraz. The law makes the pretext REAL without endorsing
#    the inference.)
#  - 1337 seeding: INJ = lax_hisba_enforcement (Abu Ishaq's
#    Shiraz); MZF = muhtasib_regime if it has ghazi_sultanate,
#    else strict; most others = customary_enforcement.
#  - The "temptation of Shiraz" events (conquest of a great lax
#    city pressures the conqueror to flip) check this law; a
#    ghazi_sultanate ruler flipping TO lax should pay a
#    legitimacy / farr-ledger cost in the event effect — Shah
#    Shoja repudiating his father's doctrine, priced.
#
# [verify] flags: modifier key names (land_morale_modifier,
# burghers_estate_target_satisfaction), whether law options
# support on_activate, estate key names in your estate rework.
