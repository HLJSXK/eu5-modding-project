# ============================================================
# ERANZAMIN — The kashi chain: Persian stonepaste porcelain
#
# Fritware/stonepaste was the Islamic world's engineered answer
# to Chinese porcelain: ~10 parts ground quartz, 1 part glass
# frit, 1 part white clay (Abu'l-Qasim's recipe, Kashan, 1301).
# Hence the recipe below: GLASS is an input, because the frit is
# ground glass. The efficiency gap vs the Chinese chain is
# expressed through input economics (costlier basket: glass plus
# extra fuel for the luster double-firing), not reduced output.
#
# Tier 1 (kashi_guild): the medieval luster/tile industry —
#   Kashan's Abu Tahir dynasty, lajvardina, the mihrab trade.
# Tier 2 (kashi_manufactory): the Safavid blue-and-white
#   imitation industry — Kirman/Mashhad workshops, the VOC
#   export boom during the Ming-Qing transition.
#
# IMPLEMENTATION CHECKS:
#  - Verify the base porcelain_guild's own potential gating. If
#    it is buildable globally, gate it OUT of the Islamic world
#    (NOT = the potential below), or the kashi chain is redundant.
#  - Verify goods keys: clay, coal, glass, tools, porcelain.
#  - Seed kashan with kashi_guild = 2 in its town_setup (the city
#    already has pottery_guild for the bulk tier; the two-tier
#    structure — cheap ware below, secret luxury craft above —
#    is the historical shape of the industry).
#  - Other plausible seeds: none required; let the market spread
#    it. Sultanabad-ware country and Mamluk Fustat could take a
#    level 1 if you want texture.
# ============================================================
