# ============================================================
# Matter of Tork — disposition modifiers
# Design: docs/design/matter_of_tork_design.md
#
# Layers:
#   - matter_answer_given: transient offset, applied when a slow
#     disposition is claimed (Iranization only — the tribes being
#     honored into the gentry is an answer; expulsion/eradication
#     give them nothing to be calmed by). Removed at disaster end.
#   - *_underway: transient process costs. Removed at completion
#     or disaster end.
#   - Outcome modifiers: permanent. One per disposition ending.
#   - Gap modifiers (matter_cavalry_gap, matter_eradication_aftermath):
#     fixed-duration suppressors of the permanent payoffs. Their
#     EXPIRY is the maturation — no polling.
#
# Matter of Tazik modifiers retained at the bottom untouched (its
# old implementation stays as-is until its own redesign/removal).
# ============================================================
