# ============================================================
# Ghazi: Burden of the Sword — static modifiers
#
# Three layers (per the design guide §4):
#   (1) Battle / war / designation pulse modifiers — applied by
#       on-action hooks and frontier-designation events.
#   (2) Apparatus refund + legacy pairs — granted in pairs by the
#       four apparatus events. The refund cancels its slice of the
#       disaster's standing modifier and is cleared on disaster
#       end. The legacy is the institutional trace that persists
#       past resolution; only the Dervish Rising (Broken-formal)
#       strips legacies.
#   (3) Resolution modifiers — applied by the four resolution
#       events.
#
# Refund invariant (verified):
#   monthly_legitimacy:                 -0.5 cancelled by +0.1+0.1+0.1+0.2
#   clergy_estate_target_satisfaction:  -0.05 cancelled by jihad_within
#   global_levy_size_modifier:          -0.10 cancelled by ribat_network
#   monthly_religious_influence:        -0.10 cancelled by investiture
#   monthly_prestige:                   -0.05 cancelled by sultan_of_ghazis
# ============================================================

# ============================================================
# LAYER 1 — battle / war / designation pulse modifiers
