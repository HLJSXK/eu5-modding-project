# National Destinies -- Romania (RMN)
# Six institutional layers from the medieval Wallachian-Moldavian principalities

# 1. The Sfatul Domnesc -- the princely council of the great boyars. Attested
#    in Wallachia from the reign of Basarab I (early 14th c.) and in Moldavia
#    from Bogdan I (mid-14th c.); composed of the marele logofat (chancellor),
#    marele vornic (chief justice), marele vistier (treasurer), marele spatar
#    (sword-bearer / cavalry commander), marele postelnic (chamberlain) and
#    other dregatori. The voivode legislated only in council; the boyars'
#    consent registered every charter, every donation, every confirmation of
#    estates. Its records (the suret and ispisoace registers of the chancery)
#    are the earliest dense administrative archive of either principality.
rmn_sfatul_domnesc_bureaucracy = {
	implementation_price = price:implement_bureaucracy_price
	maintenance_price = price:maintain_bureaucracy_price
	removal_price = price:remove_bureaucracy_price
	maintenance_price_modifier = {
		value = country_economical_base
		multiply = 0.003
	}

	potential = {
		has_or_had_tag = RMN
		has_game_rule = nd_bureaucracies_enabled
	}

	allow = {}

	estates_that_like = {
		nobles_estate
		crown_estate
	}
	estates_that_dislike = {
		burghers_estate
	}

	# The voivode's writ runs only after the great dregatori have set their
	# seals -- a permanent council registry slows decisions but legitimates
	# every charter the chancery issues.
	neutral_modifier = {
		country_cabinet_efficiency = 0.05
	}

	# At full investment, the council functions as the prince intends:
	# boyars are bound to the throne by office, the chancery clears its
	# rolls, and the great families lend the dynasty their armed retinues.
	positive_modifier = {
		scale = { value = scope:maintenance }
		nobles_estate_target_satisfaction = small_permanent_target_satisfaction
		monthly_legitimacy = 0.05
		global_levy_size_modifier = 0.05
	}

	# Neglected, the council becomes a faction-shop: rival boyar parties
	# (the Craiovesti, the Movilesti) raise candidates against the prince,
	# the voivode's writ is challenged at every diet, and the great
	# families' rising satisfaction is a dynastic threat, not a mandate.
	negative_modifier = {
		scale = {
			value = 1
			subtract = scope:maintenance
		}
		nobles_estate_satisfaction_recovery = 0.001
		global_separatism = 0.05
	}
}

# 3. The Pravila Mare of Matei Basarab. Printed at Targoviste in 1652 under
#    the prince's patronage as the "Indreptarea legii" ("Rectification of
#    Law"), translated by Daniil Andrian Panonianul from the Greek
#    Pedalion of Manuel Malaxos and the Slavonic kormchaia. It set the
#    Byzantine canon-civil hybrid (the basilika and the patriarchal canons)
#    into Romanian for the first time, governing inheritance, dowry, criminal
#    procedure, and ecclesiastical jurisdiction. Vasile Lupu's Carte
#    romaneasca de invatatura (Iasi, 1646) had already covered Moldavia.
#    Together they remained the formal law of the land until the Caragea
#    code (1818) and the Calimach code (1817), and indirectly until the
#    1865 Cuza codes. The pravila was read from the bench, taught in the
#    monastic schools, and printed in cyrillic Romanian on the prince's

	potential = {
		has_or_had_tag = RMN
		has_game_rule = nd_bureaucracies_enabled
	}

	allow = {}

	estates_that_like = {
		clergy_estate
		burghers_estate
	}
	estates_that_dislike = {
		nobles_estate

# 4. The Phanariote Administration. After the execution of Constantin
#    Brancoveanu in 1714 and the deposition of Dimitrie Cantemir in 1711,
#    the Porte ceased confirming native dynasts; from 1711 (Moldavia) and
#    1716 (Wallachia) until 1821 the throne was leased to Greek-speaking
#    Phanariot families of Constantinople (Mavrocordat, Ghica, Ypsilanti,
#    Sutu, Caradja, Mourousi, Callimachi). They paid enormous mucarrer
#    fees to the Porte, served two- to three-year terms, and recouped
#    their investment by tax-farming. They imposed the Greek language on
#    the chancery, reorganised the divan into ministerial despartiri,
#    professionalised the office-holders, abolished serfdom (Mavrocordat,
#    1746/1749), and printed the first regular newspapers and code-books.
#    The high boyars hated them as foreigners; the burghers and clergy
#    benefitted from the bureaucratic offices and Greek-school networks

# 5. The Asezamintul lui Constantin Mavrocordat. Constantin Mavrocordat held
#    each throne six times (Wallachia 1730-1769, Moldavia 1733-1769) and
#    used those tenures to push through the Romanian lands' enlightenment
#    fiscal reform: the rusumat (a fixed quarterly head-tax replacing the
#    arbitrary cisla apportionments), the rebuilt cadastral catastif, the
#    abolition of personal servitude (rumania abolished in Wallachia on 5
#    August 1746; vecinia abolished in Moldavia on 6 April 1749), and the
#    permanent salaried boyar offices that ended the medieval practice of
#    free dregatori provisioning themselves from peasant labour. The reform
#    converted the boyar from a domanial lord into a state functionary and
#    converted the peasant from a tied serf (rumin / vecin) into a clacas

# 6. The Regulamentul Organic. Drafted by mixed boyar commissions at
#    Bucharest and Iasi under the Russian governor-general Pavel Kiselyov
#    after the Treaty of Adrianople (1829), promulgated in Wallachia on 1
#    July 1831 and in Moldavia on 1 January 1832. The two near-identical
#    quasi-constitutions established the principalities as parallel
#    administrative entities: a single elected General Assembly per
#    principality, a state budget, a separation of judicial and executive
#    functions, ministries (interior, finance, justice, foreign affairs,
#    war), a uniform corvee schedule (12 days per year), abolition of
#    customs barriers between Wallachia and Moldavia, and a common system
#    of weights and measures. Drafted under foreign tutelage, the
#    Regulamentul nonetheless built the institutional armature that
#    permitted the 1859 personal union of Cuza and the 1866 Constitution
#    that followed it. The high boyar privileges -- exemption from tax,
#    monopoly of the Assembly's lower chamber -- survived; the great
#    families resented every line that registered them as a class.

		multiply = 0.003

	}

	allow = {
		OR = {
			has_primary_or_accepted_culture = culture:wallachian
