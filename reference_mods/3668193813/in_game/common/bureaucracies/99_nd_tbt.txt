# National Destinies -- Tibetan Empire (Yarlung-era restored) bureaucracies
# Four institutions of the imperial Tibetan state, drawn from the constitutional
# settlement of the seventh through the ninth centuries: the gar-zlon council
# of Gar Tongtsen, the stong-sde myriarchy levy of Songtsen Gampo, the bonpo
# imperial cult of the Yarlung tsenpos, and the lo-tsa-ba translation court of
# the Three Dharma Kings. The auto_modifier (nd_tbt_bureaucracy_authority)
# grants 2 slots; the imperial capital adds 1 = 3 effective. The player picks
# 3 of 4.
#
# Note on estates: in the Yarlung imperial settlement the "nobles_estate" is
# the great clan-aristocracy (the Dru, Khyungpo, Nanam, Bro, and other lineages
# whose blon-po served the tsenpo), the "clergy_estate" is the institutional
# religious establishment (initially the bonpo priesthood, later the Buddhist
# sangha translated into office under the Three Dharma Kings), the
# "crown_estate" is the tsenpo's household and the gar-zlon ministerial
# apparatus that surrounded him, and "peasants_estate" the stong-sde
# households -- the basic fiscal-military unit of the empire.

# 1. gar-zlon -- the imperial council, the constitutional spine of the Yarlung
#    state. Codified by the chief minister Gar Tongtsen Yulsung in 654-655
#    after his return from the embassy that brought Princess Wencheng to
#    Songtsen Gampo's court: a standing cabinet of seven blon-po ("ministers")
#    around the blon-chen-po ("grand minister") who functioned as the empire's
#    chief executive under the tsenpo. The Gar family dominated the office for
#    fifty years; even after their fall the seven-minister structure persisted
#    through the imperial period, codified in the Old Tibetan Annals and the
#    bilingual treaty inscriptions. The council bound the great clans
#    permanently into the imperial executive -- the price of which was that
#    the tsenpo could not act in war, treaty, or succession without the
#    council's seal.
gar_zlon_bureaucracy = {
	implementation_price = price:implement_bureaucracy_price
	maintenance_price = price:maintain_bureaucracy_price
	removal_price = price:remove_bureaucracy_price
	maintenance_price_modifier = {
		value = country_economical_base
		multiply = 0.003
	}

	potential = {
		has_or_had_tag = TBT
		has_game_rule = nd_bureaucracies_enabled
	}

	allow = {}

	estates_that_like = {
		nobles_estate
		crown_estate
	}
	estates_that_dislike = {
		clergy_estate
	}

	# The seven blon-po sitting under the blon-chen-po make the great clans
	# constitutional pillars of the imperial executive.
	neutral_modifier = {
		nobles_estate_target_satisfaction = small_permanent_target_satisfaction
	}

	# Working council: the blon-chen-po coordinates the great clans, treaty
	# inscriptions are sealed in the council's name, the standing cabinet
	# pushes paperwork on a continental scale, and the great clans' sons
	# serve in the tsenpo's household as a matter of ministerial duty.
	positive_modifier = {
		scale = { value = scope:maintenance }
		nobles_estate_satisfaction_recovery = 0.001
		crown_estate_satisfaction_recovery = 0.001
		army_initiative = 0.10
	}

	# Decayed council: the Gar lineage's monopoly provokes Tridu Songtsen's
	# 698 purge; the blon-chen-po becomes a hereditary office contested by
	# rival clans; the council deadlocks over succession; royal authority
	# becomes the prize of clan factions and the empire begins the long
	# decomposition that ended in Langdarma's assassination.
	negative_modifier = {
		scale = {
			value = 1
			subtract = scope:maintenance
		}
		nobles_estate_satisfaction_decay = 0.020
		monthly_inflation = 0.005
	}
}

# 2. stong-sde -- the myriarchy system, the imperial conscription apparatus
#    that organized the Tibetan plateau into ru ("horns"), each subdivided
#    into stong-sde ("thousand-districts") of nominally one thousand
#    households apiece. Songtsen Gampo's reforms in the 630s established the
#    four ru of central Tibet (g.yo-ru, dbu-ru, g.yas-ru, ru-lag); subsequent
#    tsenpos extended the structure across the conquered Sumpa and Zhang-zhung
#    territories and later into Amdo. Each stong-sde owed a quota of armed
#    men, mounts, and grain to the imperial muster; the yul-sde officers
#    (literally "land-administration") kept the rolls and answered to the
#    council. The system gave the Yarlung empire a peasant-based field army
#    that no other steppe-derived power could match -- and bound the
#    households into hereditary military service that increasingly resembled
#    serfdom by the imperial period's end.

		multiply = 0.003

	potential = {
		has_or_had_tag = TBT
		has_game_rule = nd_bureaucracies_enabled
	}

	allow = {}

	estates_that_like = {
		crown_estate
	}
	estates_that_dislike = {

# 3. bonpo Priesthood -- the pre-Buddhist ritual aristocracy of the Yarlung
#    state, the chaplain-judges who kept the tsenpo's mandate over the
#    plateau. The bon-po served as funerary specialists for the imperial
#    tombs at Chongye, as oracle-officers (ku-tsab) interpreting the
#    omens that ratified war and treaty, and as ritual judges in the
#    tsenpo's court. Their cosmology -- the lha-sras tsenpo descending
#    from the sky on the dmu-rope -- gave the Yarlung dynasty its
#    sacred legitimacy. Even after Trisong Detsen's eighth-century
#    Buddhist conversion, the bonpo institutions survived as a parallel
#    apparatus; the ninth-century king Langdarma sought to restore them
#    to primacy. In a restored Yarlung empire the bonpo office remains

# 4. lo-tsa-ba Translation Court -- the imperial Buddhist translation
#    project, the institutional achievement of the Three Dharma Kings
#    (chos-rgyal): Songtsen Gampo (the legendary founder), Trisong
#    Detsen (the historical patron, 755-797), and Tri Ralpacan (the
#    final imperial codifier, 815-838). The sgra-bsgyur lo-tsa-ba
#    ("translator-officials") were a salaried imperial corps drawing
#    on Indian panditas at Samye monastery (founded 779) and the
#    standardized Tibetan vocabulary fixed by the Mahavyutpatti decrees.
#    Their output was the bka'-'gyur and bstan-'gyur canon -- one of
#    the largest translation projects in pre-modern history. Ralpacan
#    standardized the rates of state support for monks (the seven-monk
#    rule, by which seven peasant households supported each ordained
#    monk) and gave the sangha a fixed place in the imperial budget.
#    The translation court made literate Buddhism a department of
#    state -- and the violent reaction it provoked, ending in
#    Ralpacan's assassination and Langdarma's persecution, made the
#    institution a flashpoint between the literate-monastic and
#    clan-warrior factions of the empire.
