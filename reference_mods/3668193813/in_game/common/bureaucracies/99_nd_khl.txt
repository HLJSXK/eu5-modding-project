# National Destinies -- Khilafah bureaucracies
# Five historically grounded institutions of the universal Sunni caliphate
# restored under one Caliph from al-Andalus to the Indus. Auto-modifier
# grants 2 slots; capital adds 1 = 3 total. Player picks 3 of 5. The set
# spans the caliphal jurisdictional supremacy (Diwan al-Mazalim), pan-
# islamic fiscal coordination (Bayt al-Mal), the unification of the four
# Sunni madhhabs under the Caliph (Pan-Islamic Ulama Council), the
# universal pilgrimage apparatus (Hajj Caravan Apparatus), and the
# trans-imperial revival of Abbasid translation-and-sciences scholarship
# (Bayt al-Hikmah Network).

# 1. Diwan al-Mazalim -- the Court of Grievances. The caliph (or his
#    delegated wazir-mazalim) sat in personal jurisdiction over wrongs
#    that the ordinary qadi courts could not reach: oppression by
#    governors, seizure by tax-farmers, and abuse of waqf endowments.
#    The institution is traced to Caliph Umar (d. 644) and was systematized
#    under the Abbasids and Mamluks (al-Mawardi's al-Ahkam al-Sultaniyya
#    is its locus classicus). Restored at universal scale, it makes the
#    Caliph the supreme appellate authority over every emir and qadi in
#    the ummah -- and the chief check on noble overreach.

	implementation_price = price:implement_bureaucracy_price
	maintenance_price = price:maintain_bureaucracy_price
	removal_price = price:remove_bureaucracy_price
	maintenance_price_modifier = {
		value = country_economical_base
		multiply = 0.003
	}

	potential = {
		has_or_had_tag = KHL
		has_game_rule = nd_bureaucracies_enabled
	}

	allow = {
		religion = religion:sunni
	}

		global_separatism = 0.10
		global_nobles_estate_power = 0.10
	}
}
