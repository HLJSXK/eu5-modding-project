###############################################################
# National Destinies -- MGE Mongol Empire bureaucracies
#
# Vanilla EU5 1.2 ships no MGE bureaucracies (only BYZ has any).
# These six model the durable institutions of the unified Mongol
# Empire of Chinggis Khan and his successors (1206-1294 unified,
# partitioned thereafter into Yuan, Chagatai, Ilkhanate, Jochid):
#
#   1. Great Yasa            -- Chinggisid customary law code
#   2. Kuriltai Assembly     -- elective council of Chinggisid princes
#   3. Keshig Imperial Guard -- day-and-night household corps
#   4. Yam Postal Network    -- paiza-keyed mounted relay system
#   5. Darughachi Governance -- resident overseers of conquered cities
#   6. Yelu Chucai Synthesis -- Sinicised Liao-Jin scribal apparatus
#
# IDs are prefixed mge_ per the National Destinies bureaucracy spec.
# All are gated on `has_game_rule = nd_bureaucracies_enabled` so the
# player's game-rule choice is honoured.
###############################################################


# =====================================================================
# Great Yasa -- the Chinggisid law code
#
# The Great Yasa (Yeke Jasaq) is the customary law promulgated by
# Chinggis Khan and elaborated under Ogedei. It bound the imperial
# clan, the army, and the subject peoples alike: it set the death
# penalty for theft and adultery, regulated the hunt, fixed the
# ordering of the keshig, and -- crucially -- placed the khan
# himself under the law's letter. The Yasa was kept in scrolls
# (kokie debter) read aloud at each kuriltai. Recitation reaffirmed
# the dynasty's compact with its tribes, but also limited what the
# khan could lawfully decree.
# =====================================================================
mge_great_yasa_bureaucracy = {
	implementation_price = price:implement_bureaucracy_price
	maintenance_price = price:maintain_bureaucracy_price
	removal_price = price:remove_bureaucracy_price

	potential = {
		has_or_had_tag = MGE
		has_game_rule = nd_bureaucracies_enabled
	}

	allow = {}

	estates_that_like = {
		tribes_estate
		nobles_estate
	}
	estates_that_dislike = {
		clergy_estate
	}

	# always-on: the Yasa's mere existence binds the steppe army
	neutral_modifier = {
		monthly_horde_unity = 0.05
	}

	# upheld: codified discipline, harsher justice, levy cohesion
	positive_modifier = {

		land_morale_modifier = 0.05

	}
}


# =====================================================================
# Kuriltai Assembly -- the council of Chinggisid princes
#
# The kuriltai was the great assembly of the imperial clan and senior
# noyans, summoned to elect a new khan, ratify campaigns, and divide
# spoils. From Onon (1206) to the contested Karakorum quriltai of
# 1251, no khan's authority was unquestioned without it. The assembly
# legitimised the throne but also fragmented imperial decision-making:
# the partition of the empire after Mongke's death (1259) was the
# kuriltai system's greatest failure. Where it functioned, princes
# fought together; where it failed, they fought each other.
# =====================================================================

# =====================================================================
# Keshig Imperial Guard -- the day-and-night household corps
#
# The keshig was Chinggis's ten-thousand-strong household army,
# divided into the turqaut (day guard) and the kebte'ul (night
# guard). It served simultaneously as the khan's bodyguard, his
# personal staff, and the training school for future commanders
# and darughachi: most senior administrators of the empire passed
# through keshig service. Recruitment drew sons of noyans as
# hostages, transmuting hereditary aristocracy into chosen royal
# servants. The institution let the khan project competent men
# into every corner of the realm -- but also sealed the hereditary
# aristocracy out of the inner court.

# =====================================================================
# Yam Postal Network -- the paiza-keyed mounted relay
#
# The yam (jam, ortoo) was a system of relay stations spaced roughly
# a day's hard ride apart, manned by ortoochi keepers who supplied
# fresh mounts, food, and shelter to imperial messengers bearing
# paiza tablets of authority. Marco Polo described it as the
# wonder of the empire: news, decrees, tax registers, and merchants
# moved across continental distances in weeks rather than months.
# The network was funded by the qubchur tax and corvee labour
# levied from peasant communities along the routes -- a burden
# they bitterly resented but could not refuse.
# =====================================================================

# =====================================================================
# Darughachi Governance -- resident overseers of conquered cities
#
# A darughachi (basqaq in Turkic, daruga in later usage) was a
# Mongol-appointed resident commissioner placed over a conquered
# city, region, or vassal court. He took the census, levied the
# tamgha customs, conscripted artisans for imperial workshops,
# and collected the tribute owed to Karakorum. Unlike the timar
# or jagir, the darughachi held no land and could be transferred
# or recalled at the khan's pleasure: the position was deliberately
# detached from local elites to prevent its capture. Russian and
# Persian chronicles record the office as the heaviest of
# imperial burdens on settled populations.

# =====================================================================
# Yelu Chucai Synthesis -- the Sinicised scribal apparatus
#
# Yelu Chucai, a Khitan scholar inherited from the Jin chancery,
# convinced Ogedei Khan that taxing the settled population was
# more lucrative than slaughtering it. Under his stewardship the
# Mongol court adopted Liao-Jin fiscal practice: registered
# households, fixed silver/silk levies, scribal record-keeping in
# Chinese, and Confucian-trained clerks rather than tribal
# accountants. Subsequent Yuan administration grew from this
# synthesis. The reform alienated the steppe nobility, who lost
# their right to plunder freely; it required, by its nature, the
# command of a sedentary capital with literate clerical traditions.
# =====================================================================
