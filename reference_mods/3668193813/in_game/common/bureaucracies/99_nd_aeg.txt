# National Destinies -- AEG (Aegyptus) bureaucracies

# Five institutions of the restored Pharaonic-Mamluk state:
#
#   1. Iqta-Halqa System          -- Mamluk military land tenure +
#                                    halqa native cavalry register
#   2. Diwan al-Mal               -- Coptic-staffed treasury bureau
#   3. Mashyakhat al-Azhar        -- Council of Senior Sunni scholars
#   4. Khidmat al-Haramayn        -- Custodianship of Mecca/Medina,
#                                    the mahmal pilgrim caravan
#   5. Karimi Tujjar al-Khan      -- Karimi merchant fellowship
#                                    centered on Khan al-Khalili
#
# Auto-modifier (nd_aeg_bureaucracy_authority) grants 2 slots; the

# future Egyptian-region formables.

# =====================================================================
# Iqta-Halqa System -- Mamluk service-fief and native cavalry register
#
# Standardized under Baybars (r. 1260-1277) and Qalawun (r. 1279-1290),
# the iqta linked an emir's rank to the size of his tax-grant: an emir
# of forty held one-third the iqta of an emir of one hundred. Beneath
# the mamluk regiments, the ajnad al-halqa enrolled non-mamluk free
# cavalry -- native Egyptians and sons of mamluks -- under the sultan's
# direct command. Together the two registers produced the manpower of
# every Mamluk campaign from Ayn Jalut to the Hejaz frontier.
#
# Working: large standing levies, fast recovery from war, the emirs
# satisfied with their iqtas. Decayed: emirs treat iqtas as private
# fiefs, halqa decays into rentier patronage, peasants flee tax-farm
# extraction.
# =====================================================================
aeg_iqta_halqa_bureaucracy = {
	implementation_price = price:implement_bureaucracy_price
	maintenance_price = price:maintain_bureaucracy_price
	removal_price = price:remove_bureaucracy_price
	maintenance_price_modifier = {
		value = country_economical_base
		multiply = 0.003
	}

	potential = {
		has_or_had_tag = AEG
		has_game_rule = nd_bureaucracies_enabled
	}

	allow = {}

	estates_that_like = {
		nobles_estate
	}
	estates_that_dislike = {
		peasants_estate
	}

	# The mere existence of the iqta register binds emirs to crown service
	# in exchange for tax assignment. Halqa cavalry are perpetually on the
	# rolls.
	neutral_modifier = {
		nobles_estate_allowed_leading_military = yes
	}

	# Iqta administered cleanly: rank-graded fiefs, halqa squadrons drilled
	# and paid, large reserve of cavalry mobilizable for sultan's campaigns.
	positive_modifier = {
		scale = { value = scope:maintenance }
		global_levy_size_modifier = 0.10
		levy_recovery_modifier = 0.15
		nobles_estate_target_satisfaction = small_permanent_target_satisfaction
	}

	# Iqta neglected: emirs treat assignments as patrimonial estates, halqa
	# decays into ghost rolls and patronage, fellahin flee the tax-farms.
	negative_modifier = {
		scale = {
			value = 1
			subtract = scope:maintenance
		}
		peasants_estate_satisfaction_decay = 0.02
		global_monthly_control = -0.01
	}
}


# =====================================================================
# Diwan al-Mal -- Coptic-staffed treasury bureau
#
# The fiscal heart of the Mamluk state. Coptic Christian scribes
# dominated the dawawin from the late Fatimid period through the entire
# Mamluk era, their expertise in tax assessment and double-entry
# bookkeeping passed through family secretarial dynasties. Hibat Allah
# al-Sadid (d. 1282-83) served as mustawfi al-suhba (chief comptroller)
# under Qalawun. Coptic employment in the chancery was suspended at
# least nine times by popular pressure between 1280 and 1450, but the
# bureau always recalled them: no one else could keep the books.
#
# Working: efficient land-tax, customs receipts, ledger discipline,
# Copts content under formal protection. Decayed: the bureau becomes
# a private patronage network of Coptic clerks, popular resentment
# rises, gold flows are skimmed before they reach the treasury.
# =====================================================================

# =====================================================================
# Mashyakhat al-Azhar -- the Sheikhate and Senior Scholars of al-Azhar
#
# Founded by Fatimids in 970 as a Shi'i seminary, al-Azhar was
# converted to Sunni teaching after Saladin's 1171 takeover. Under the
# Mamluks it became the supreme institution of Sunni jurisprudence in
# the Islamic world after Baghdad's fall to the Mongols in 1258. The
# Hay'at Kibar al-Ulama -- the Council of Senior Scholars -- gathered
# eminent jurists of all four Sunni madhhabs (Hanafi, Maliki, Shafi'i,
# Hanbali) and issued fatwas binding from Morocco to Indonesia. The
# Sheikh of al-Azhar served as the highest religious office of the
# realm.
#
# Working: religious cohesion, fatwa-driven conversion, theological
# legitimacy of the sultan's authority. Decayed: madhhab factionalism,
# scholasticism without political weight, dhimmi communities pressed

# =====================================================================
# Khidmat al-Haramayn -- Custodianship of the Two Holy Mosques
#
# From the mid-14th century onward the Mamluk sultans claimed the title
# Khadim al-Haramayn al-Sharifayn -- Servant of the Two Noble Sanctuaries.
# The mahmal, an ornate ceremonial litter dispatched annually with the
# Egyptian pilgrim caravan, asserted Mamluk sovereignty over the Hejaz
# road. Sultan al-Ashraf Barsbay (r. 1422-1438) used the title to
# legitimize a foreign-born military caste against rival Muslim claims.
# The custodianship integrated pilgrim revenue, sharifian diplomacy,
# and the prestige of guarding the qibla.
#
# Working: legitimacy as defender of the faith, prestige across Sunni
# courts, pilgrim caravan revenue and tolerance toward visiting heretical
# sects. Decayed: bedouin attacks on the mahmal, sharifian houses

#

# burgher and dhimmi prosperity, sea trade reach. Decayed: smuggling and
