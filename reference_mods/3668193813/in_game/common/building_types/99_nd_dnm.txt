# ===== DANUBIAN MONARCHY -- Custom Buildings =====
# Six institutions that built the composite monarchy: the central
# treasury, the river staple, the Military Frontier district, the Jesuit
# college, the Theresian cameral academy, and the Imperial Arsenal. All
# non-production buildings, so all use building_maintenance PMs only.
# Building IDs are suffixed _building where they would otherwise collide
# with the same-named advance's localization key.
