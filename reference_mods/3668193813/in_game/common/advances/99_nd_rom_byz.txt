# ==========================================
# Italian Roman Restoration (ROM_BYZ) — Heritage Advances
# ==========================================

# than ROM_f. Heritage represents POST-formation: what changes when Greek
# and Italian fuse in Rome. Distinct from BYZ's pre-restoration heritage
# (those are pre-Italian Renaissance Constantinople flavor) and from
# ROM_f's "I conquered the world" Latin imperial fantasy.

# Gate: has_or_had_tag = ROM AND has_variable = nd_rom_byz_formed
# nd_rom_byz_formed is set only by nd_rom_byz.1, so it cleanly separates
# this content from ROM_f players (who set nd_rom_formed instead).
