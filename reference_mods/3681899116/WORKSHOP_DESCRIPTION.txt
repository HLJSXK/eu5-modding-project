Many players dig through game files or the wiki just to find a country's unique events. This mod solves that.

It adds a new in-game "Events" tab that automatically lists each nation's dynamic historical events and unique events in one place.

What this mod includes:

- Automatic per-country event lists
- Dynamic tag support
- Live requirements panel with green/red checks
- Current requirement numbers from the game engine when available
- Monthly chance shown as a percentage
- Filters for All / Available / Upcoming / Expired / Fired
- Fired tracking for one-time events
- Improved generated summaries, descriptions, and outcomes
- Multilingual localization

Dynamic Tag Support:
If you form a new nation, such as Prussia or Great Britain, the tab automatically detects the tag change, unloads the old country view, and reloads the correct event list for the new country.

Live Requirements:
Requirements are no longer only static text. The panel now uses dynamic in-game trigger evaluation, so you can see which conditions are currently fulfilled, which are not, and current values for many numeric requirements.

Event Mods Support:
If you install another event mod and want its DHE / unique events to appear:

1. Close Europa Universalis V.
2. Open the mod folder.
3. Double-click "Rebuild Country Events List.bat".
4. Wait for the rebuild to finish.
5. Launch the game again.

Requirements for rebuild:
- Python 3

Notes:
- Fired tracking is intended for one-time events.
- On older saves, events that already fired before this version was installed cannot always be reconstructed retroactively.
