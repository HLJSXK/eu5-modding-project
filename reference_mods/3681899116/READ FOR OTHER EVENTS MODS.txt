Quick Guide: Rebuild with Installed Mods

Use this if you installed another event mod and want its DHE / unique events to appear in Unique Events Tab.
It also rebuilds the readable titles, requirements, and effects with the current generator.

Steps:
1. Close Europa Universalis V.
2. Open this mod folder.
3. Double-click `Rebuild Country Events List.bat`.
4. Wait until the script finishes.
5. Launch the game again.

Requirements:
- Python 3 installed
- Europa Universalis V installed through Steam

What it does:
- scans the base game
- scans installed local mods
- scans installed Workshop mods
- rebuilds the Unique Events Tab event list automatically
- regenerates country windows and localization
- refreshes the interpreted requirements and effects text

Important:
- This is not automatic in-game.
- If you only use vanilla + this mod, the rebuilt list stays at the current official baseline.
- If you have other event mods installed, their detected events can be added to the list.
- Run it again whenever you install, remove, or update another event mod.
