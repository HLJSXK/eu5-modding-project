# 06 · 截图比对结果（2026-10-11，1080p 实机截图）

截图保存在 `screenshots/`（A 局势面板、B 地点人口页签、C SOL tooltip）。比对工具：`renderer/compare.py`（并排 / 放大比对指定区域）。

## 已确认并写入渲染器的规则

| # | 问题 | 实机结果 | 修正前的渲染 |
|---|---|---|---|
| A1 | 隐藏子元素是否仍占一个 spacing | **不占**。主卡片紧贴在页签栏下方 | 已正确；“占间距”的假设被否定，对照组已删除 |
| A2 | 45px 空条外观 | 纯棕底，只有左侧 12px 有花纹 | 整条平铺花纹。根因：`spriteborder` 的单位是**界面单位**，不是贴图像素（要乘以 texture_density 才是贴图像素） |
| A3 | `widgetanchor` 默认值是否等于 `parentanchor` | 是。开始日期旗帜居中 | 已正确 |
| A4 | 滚动条是否挤占内容宽度 | 不挤占。滚动条叠在卡片右侧 | 已正确 |
| B1 | 文字放不下时的处理 | 固定宽度的单行文字会**缩小字号**（长文化名“阿什肯纳兹犹太”变小） | 原先溢出、重叠；已实现 `fontsize_min` 缩字 |
| B2 | 三个图表的高度 | 人口图表顶到最大高度（7 行，含人数为 0 的部落民），文化和宗教均分剩余 | 修正 expanding 优先规则，并补上人数为 0 的阶层后与实机一致（y 715 / 818 / 920） |
| B6 | `righttoleft` | 迁徙吸引力的图标在右 | 已正确 |
| B4 | `\|Y`（人口增长） | `GetGrowthForUI` 返回引擎已格式化好的字符串（绿色“+3”，零增长时为空字符串、整列隐藏）；`\|Y` 不会覆盖字符串自带的颜色 | 示例数据已改为引擎的格式 |
| — | 饼图外观 | 饼图是**圆环**（`piechart_alpha.dds` 本身就是环形遮罩），中间放图标 | 原先画成实心扇形；现在通过切片贴图绘制 |
| — | 阶层按钮底色 | 按阶层着色 | 原先是灰色。根因：只有颜色、没有贴图的 modify_texture 应视为纯色图层，且颜色可以是数据绑定；阶层颜色取自 `named_colors/02_map.txt` |
| C1 | tooltip 比屏幕还高时 | 向上平移，底边贴住屏幕下沿，不截断也不缩放 | 渲染器只渲染 tooltip 本身，未模拟屏幕定位 |
| C2/C3 | 数字格式 `\|+2`、`\|+=1%` | `+` = 按正负着色（正绿、负红、零不着色），**不加正号**；`=` = 正数加 `+` | 原先单独的 `+` 不着色；现已修正，表格数值变为绿色 |
| C4 | 字体回退 | 中文用 NotoSansSC，数字用 NotoSerif，与推断一致 | 已正确 |
| C6 | 行高 | 字号 15 的自适应文字行高 21px（行距 23 = 21 + spacing 2）；多行文本同样是 21px | 原先 22px；模板中 `Font_Size_Small` 的 `size {0 23}` 对自适应文字不生效 |
| — | 商品文本图标尺寸 | 约 27px | 原先 20px。根因：引擎注册的商品图标使用 `NJominiIcons.MODIFIER_TEXT_ICON_SIZE {32 32}`（以字号 18 为基准），在字号 15 下缩放为 26.7px |

修正后，tooltip 的高度与实机完全一致（992 = 1080 − 88），各文字行的纵向位置误差在 0–1px 以内；局势面板各行误差在 1px 以内。
