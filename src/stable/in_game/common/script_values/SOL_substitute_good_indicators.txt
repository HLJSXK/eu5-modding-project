### ============================================================
### SECTION: Per-Good Scarcity Flags (GUI tooltip helpers)
### ============================================================
# Part A: sol_good_<good>_scarce — returns 1 when the specific good
#   is scarce at the evaluated location market.
#
# Part B: sol_demand_share_<good> — returns this good's current demand
#   share percentage (0-100) based on the weight system, using scarcity-only
#   weights (no pop-specific modifiers, since this runs in location scope).
#   Baseline share = 100/N; lower when scarce, higher when group-mates are scarce.
#
# Both sets used by SOL_substitute_tooltip.gui to drive per-good rows.
# Scope when evaluated: location (via Location.MakeScope.ScriptValue)
# ============================================================
