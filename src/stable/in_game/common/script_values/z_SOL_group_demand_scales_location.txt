# Location-scope demand scale values — one entry per (strata, group) pair.
# Full formula (non-tribesmen):
#   demand_scale = (sp + 1) * demand_base * sol_era_coeff * sol_market_scarcity_adj
#
#   demand_base             = gdp * alpha/P + offset  (z_SOL_group_demand_base_location.txt)
#   sol_era_coeff           = global_var:sol_era_coeff
#                             Corrects for progressive goods unlock: simulator assumes the
#                             full goods catalogue; early-game missing slots reduce spending.
#                             Starts at 2.0, decays ×0.95 per era as more goods unlock.
#   sol_market_scarcity_adj = variable:sol_market_scarcity_adj on each location
#                             Corrects for market price fluctuations: scarce goods push
#                             pops to cheaper substitutes, reducing effective spending.
#                             Cached yearly per location; range [0.80, 1.20].
# Tribesmen use: (sp + 1) * sol_era_coeff * sol_market_scarcity_adj  (no income term).
#
# Generated by engel_export.py — DO NOT EDIT MANUALLY
#   nobles   : local_nobles_savings_pressure / local_noble_gdp_per_capita_display
#   clergy   : local_clergy_savings_pressure / local_clergy_gdp_per_capita_display
#   burghers : local_burghers_savings_pressure / local_burghers_gdp_per_capita_display
#   commoners: local_commoner_savings_pressure / local_commoner_gdp_per_capita_display
#   tribesmen: local_tribesmen_savings_pressure
