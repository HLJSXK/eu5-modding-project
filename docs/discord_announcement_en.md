# Standard of Living v1.4 beta

Standard of Living now has a separate Workshop item for the EU5 1.4 beta branch.

## Please choose the correct version

- **Playing the default EU5 1.3 release?** Keep using [Standard of Living (v1.3)](https://steamcommunity.com/sharedfiles/filedetails/?id=3698931463). Nothing changes for you.
- **Playing the EU5 1.4 beta branch?** Subscribe to the v1.4 beta item and disable the v1.3 item.
- **Do not enable both versions at the same time.** Saves made with one version are not supported on the other.

## What's in the v1.4 beta

- **Updated for EU5 1.4 beta.** Renamed and removed vanilla fields are migrated, including price keys, resolution AI weights, and the new winter food effect.
- **Camels are now part of SOL.** The new 1.4 good is included in noble demand, market base spending, and the Living Standard panels. SOL now calibrates 56 goods.
- **No wealth threshold on wine.** The new 1.4 wine threshold is removed, consistent with SOL's policy that no threshold gates pop demand.
- **Location window rebuilt on the 1.4 beta [Glorp UI](https://steamcommunity.com/sharedfiles/filedetails/?id=3812518640).** It is migrated to the new 1.4 GUI API and keeps the Living Standard button.
- **Everything from the 08/14 update is included.** Stratum-level control, capped savings pressure, and yearly AI refreshments work the same as in v1.3.

## Known issues

- 1.4 changed how colonial charters are created, so the AI colonial charter restriction may not apply in this beta yet.
- The compatibility submods (PP, M&T, JTG, and others) are built for v1.3 and have not been released for the beta yet.

## Required mods and load order

1. [Community Mod Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776) 2.x
2. [Glorp UI (1.4 beta)](https://steamcommunity.com/sharedfiles/filedetails/?id=3812518640) and [Construction Manager](https://steamcommunity.com/sharedfiles/filedetails/?id=3736668860) (both optional)
3. Standard of Living v1.4 beta

**SOL must be below Glorp UI and Construction Manager** for the combined location window to show correctly.

A new campaign is recommended. This is a beta for a beta: both EU5 1.4 and this item may still change, so please report any problems here.
