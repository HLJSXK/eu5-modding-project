# 10 单变量地点算法：侵入式队列与有界服务

日期：2026-10-19。状态：现行算法设计与离线小图实验；未实现 EU5 玩法脚本，未通过引擎性能验收。

本文与 [02](02_Spread_Model.md) 共同执行用户硬约束：**每个地点×商品只维护一个持久浮点 x**；唯一放宽是方案A的暂存队列指针 q，只在排队期间存在（2026-10-19 决定，理由是不依赖无法确认复杂度的原生容器）。原先的量化状态积分、带 queued/prev 的常驻地点链表、压力及逐边缓存方案撤下。旧实验仅为历史研究，不为本版证明复杂度或吞吐。

## 1. 存储账本

| 所在层 | 允许持久数据 | 禁止的替代做法 |
|---|---|---|
| 地点×商品 | 持久：x∈[0,100]；暂存：排队期间的 q（下一个地点引用，队尾指向自身） | 其他数值、布尔、prev指针、日期、强度/阶段副本；出队后仍保留的 q |
| 商品调度器 | head、tail、length、round_remaining、round、截止日、剩余预算 | 原生 current/next 集合；为每地点建立一行旧值、到期、斜率的全局记录 |
| 国家/市场/商品 | 政策、共享 rho/p、有限入口、国家派生聚合、国家级事件冷却 | 把已删除的接触/依赖状态搬到这里，按地点键继续保存 |
| 单次任务 | 读取的old、累加器、new、当前邻边及少量临时表达式值 | 任务结束后保存每地点临时表，或持久化全图x_next |

q 只是维护传播边界所需的调度位置，不承载额外地方动力学；队列占用的地点数等于排队数，与被触及地点总数无关。不能用浮点位数打包额外状态。引擎本身已有的邻接、所有权、市场关系无需重复复制为地方变量。

## 2. 每次更新只拉取当前强度

```text
old = x[v]
new = rho × old + sum(p[u,v] × x[u]) + 当轮有限入口输入
new = clamp(new,0,100)
若 new < epsilon：new = 0
若 |new − old| > delta（= 0.1）或 new = 0 ≠ old：x[v] = new，入队
否则：不写回，不入队
```

每次任务完整读取该目标的实际来源，不保存累计压力、来源数或每边已提交贡献。撤掉一个来源之后，剩余来源自然仍在求和中；无须对旧边贡献做增量补丁。

变化比较使用本任务尚未丢弃的 old/new 与共享容差 δ = 0.1（02 第 2.1 节），阶段用 x 的阈值直接派生。没有单独保存的经济强度、传播强度、上轮强度或更新时间。源的任何有效 x 变化都可能唤醒邻居，不能沿用“只在旧传播档变动时通知”却宣称与裸 x 公式一致。

## 3. 边界：每商品一条侵入式 FIFO（方案A）

```text
push(v):  若 v 有 q：返回                      # 已在排队，去重只读一次
          v.q = v                              # 队尾指向自身
          若 length = 0：head = v  否则：tail.q = v
          tail = v；length += 1
pop():    v = head
          若 length = 1：head = tail = 空  否则：head = v.q
          删除 v.q；length −= 1；返回 v
```

1. 初始化仅入队已有种子、它们实际影响的目标及有限长程入口，不扫描全世界每商品来建立零状态。新路线打开时直接入队目标；来源x已稳定也能启动新前沿。
2. 逻辑轮开始时令 round_remaining = length，本轮恰好服务这么多个；期间新入队的排在后面，下一轮才处理。
3. 服务一个地点：pop，读取 x 和邻边，按02公式更新并原地回写。
4. 若 |new−old| > δ（或归零），写回并 push 自己及其出边目标；仍在排队的目标只读一次 q 就跳过，它被服务时会读到新值。变化 ≤ δ 则不写回、不入队，q 已随出队删除。
5. 预算不足时停止 pop，round_remaining 与队列原样保留，下月继续。round_remaining 归零即一轮结束，不需要交换任何集合。

这里的候选包含未采纳前沿和仍在变化的内部地点；稳定内部自然退出。除 q 外不附加逐地点 prev/queued/due/version 字段，"是否在排队"就是"q 是否存在"。

所有操作都是常数次变量读写：读写一个地点变量、读写四个商品级变量。不需要原生集合的去重、成员查询、按索引访问、删除或交换，因此调度成本不随队列长度变化，也不受原生容器实现影响。剩下的原生依赖是：地点变量能保存/删除一个地点引用，并能进入该引用的作用域。本 mod 已有相同形态的先例——`src/stable/in_game/common/scripted_effects/D_SOL_lshud_ranking.txt:156–168` 用国家变量保存前后国家引用并通过 `global_var:... = { set_variable ... }` 进入，但那是国家作用域；地点作用域的写法仍按 CLAUDE.md 三步规则核实。

## 4. 顺序、暂停与读档

- 数值原地异步：当前轮较晚的节点可能读取较早节点的新 x；没有数值双缓冲。出队后再入队的地点排到队尾，因此服务顺序与集合版略有不同，同属顺序误差。
- 新候选不得递归当场执行；当前轮内已有节点的顺序误差仍需测量。
- 未完成轮次跨月继续，rho/p仍按一个逻辑步服务，不以地点last_update补算历史。超载将直接拉慢传播，必须报告轮次长度及任务等待。
- 暂存的是商品级的工作进度。读档保留各地点 x、排队地点的 q 以及商品级 head/tail/length/round_remaining；读档后可从 head 走 length 步做一次完整性检查（计费、仅调试开关开启时），不能全图重建第二份数值状态。
- 当前任务需要完整预留费用后才 pop。不能先写回x，再因没有额度而丢掉必需的入队。
- 不允许无上界的整源展开。先统计实际地图最大邻接度，按该上界为一个完整节点预留输入枚举与必要输出通知成本；若上界不可承担，应核实其他有界枚举方案，不能把中途累加器按地点长期保存。

## 5. 共享输入和重新唤醒

国家政策、禁令、宗教/文化、供应、市场迁移及边系数变化，都会使原来已稳定的 x 再次需要计算。相关国家/入口/地理引用可以用来逐项入队；若没有变化hook，用有界轮转探测补偿，发现和服务延迟分别报告。

长程传播只作用有限市场中心、港口、首都或外交目标。读取共享参数与当前引擎属性，服务后不在地点缓存压力、政策值、旧所有者或版本。新市场即使此前完全没有x，也可由满足真实条件的入口播种。

不能因 x 当前稳定就永久忘掉它的外部关系。缺少可行唤醒路径是功能缺口，不是“零成本优化”。共享参数刷新、入队和轮转发现本身计入预算。

## 6. 月度操作预算重新定义

仍以新增痴迷计算每月不超过500,000为要求，内部计划额度480,000，剩余20,000留裕量。**全部商品共用一份预算，不为每层复制。** 但旧版128U状态槽、32U边槽、76次状态变差及对应吞吐结论均不适用于新模型。

对真实生成脚本审计：

```text
C_node(d) = pop（3）+ 固定保护/读取/写回成本（8）
          + d × 邻边读取、系数、乘加成本（4d）
          + 发生变化时：自身登记与出边枚举（1+d）
            + (1+d) 次 push，每次新入队 4、已在排队 1
预扣上限 = 3 + 8 + 4·d_in + 1 + d_out + 4·(1+d_out)    # d=6 时 70
C_month = 本月实际服务的各节点费用之和
        + 国家时钟：活跃国家数 × 3（检查 2 + S_c 更新 1）+ 重标定时本国地点数 × 4
        + 入口/共享输入/探测/聚合/回调/清理费用
```

国家时钟模式下，服务前要先查一次所有者是否在退潮（+2），读邻居时取所有者的 S_c（每条边 +2），所以 `tools/obsession_sim` 用两套计价：无时钟 `PRICE_QUEUE`，有时钟 `PRICE_CLOCK`（预扣上限 20 + 13d，d=6 时 98）。

核心公式本身只需约2d次邻居乘加，以及自身保留、可选入口加法、限幅/归零。变量读取、作用域保护、写回和入队出队另外计数。以d=6为例，公式算术与比较仅十几次，不能直接声称节点任务就是200U。

新值变化时可能需要第二遍邻边枚举来登记目标，两次枚举都计费。每次入队只写引用；绝不嵌套执行目标状态。静态地理、参数表查询和已在排队的判断也不能免费。

上面的 3/4/1 是离线抽象计价；P0 展开真实脚本前，不把它当成 EU5 指令数。预算通过后才反推月度节点容量与可接受轮次延迟；操作封顶不能替代传播时效验收。

## 7. 经济聚合不另存地方账本

地点变化只登记有关国家需要刷新。国家/商品聚合可以分片读取当前x和必要原生权重，用少量国家/商品级进度与总量准备下一经济快照。

若无法在无旧权重/旧所有者/旧贡献的条件下可靠做差值，就重新聚合并计费，不能加回这些地方字段。跨月重聚合是混合服务时刻的异步快照，不承诺全世界某日精确同步。准备好后由原有自然SOL求解入口消费，不额外触发solver。具体选择加权平均还是其他代表强度，须同时评估稀释效果与聚合成本。

国家退潮期间，本国聚合等于 S_c × 已存的本国和（κ > 0 时为 κ + (1−κ)S_c 倍），不需要逐地点重读；重标定或结束写回时顺带重建本国和。习俗退场保留的是 κ×x；关闭经济效果按国家缓存清理，不复制或清空全世界地点变量来维护另一套偏好记忆。

## 9. 退潮：国家级时钟与懒衰退（2026-10-19 基准）

规则见 02 第 8 节，这里只写算法与成本。

```text
每月，对每个已加入且未结束的国家 c（商品 g）：
    U += 2
    若未在退潮 且 t ≥ J_c + T：进入退潮，S_c = 1          # T 基准 240
    若在退潮：
        S_c ← g_c × S_c；U += 1                             # g_c = 1 − (1 − g) × 本国 λ 倍率
        κ = 0  且 S_c < 0.1 ：遍历本国地点 x ← x·S_c（< ε 归零），U += 4/地点；S_c = 1；全为 0 则结束
        κ > 0  且 S_c < 0.01：遍历本国地点 x ← x·(κ + (1−κ)S_c)，U += 4/地点；结束（定格为习俗）

节点服务时：出队后若所有者在退潮，丢弃（U += 5），不计算、不入队
入队时：目标所有者在退潮则拒绝（U += 2）
读取邻居：x_eff(u) = 所有者在退潮 ? x_u × S_c : x_u
加入：某次更新使 x 从 <1 到 ≥1 且本国 J_c 未设，写 J_c = t（U += 2）
```

成本由三部分组成：增长前沿的节点服务（与无时钟时同量级，略贵于 `PRICE_QUEUE`）、每月每个活跃国家 3 U、每约 114 个月一次的本国重标定（κ > 0 时只在结束时一次）。合成网格上单商品：平均约 2.75 万 U/月，峰值 12.2 万 U（增长前沿），时钟部分约 5,000 U/月；若按年更新时钟（年度步长换算 g¹²）可降到约 400 U/月。

不再需要的东西：全局退潮开关、逐节点衰退、退潮期年度步长。δ 的冻结下限问题随之消失，因为退潮不经过 δ。

尚未模拟：国家政策对 g_c、κ_c 与剩余保持期的修正（05 第 2.4 节），所有权变化时的 S_c 换算（01 第 5 节），以及时钟组按省/区域细分。
