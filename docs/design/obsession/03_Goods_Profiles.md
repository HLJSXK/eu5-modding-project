### 2.1 退潮参数（国家级时钟，2026-10-19 基准）

各国×商品在首个地点 x ≥ 1 时开始计时，保持 T 个月后整国按每月因子 g 衰退；结束时保留 κ×x 作为习俗（κ = 0 则退到零）。三者都是商品级共享参数，可再乘国家政策修正（05）。基准对所有商品取 T = 240 月、g = 0.98/月；κ 的首轮建议如下，全部待真实地图与 09 里程碑校准。

| 类别 | κ（习俗保留率，首轮建议） | 理由 |
|---|---:|---|
| knowledge（books、paper） | 0.5 | 阅读与书写习惯一旦建立很少消失 |
| smoke（tobacco） | 0.4 | 成瘾性最强，禁令几乎都失败 |
| stimulant、sweet、intoxicant、ritual | 0.3 | 日常饮食与宗教生活的一部分 |
| spice、medicine | 0.2 | 饮食与医学潮流会部分沉淀 |
| staple | 0.1 | 玩家风尚专用，留存很少 |
| fashion_textile、treasure | 0.05 | 风尚过去基本不留 |
| decor、beast | 0 | 收藏热与炫耀消费退潮后不留习俗 |

τ 较小的类别（fashion_textile 20 年、lacquerware 25 年）可以考虑缩短 T，但在真实地图校准前保持 T = 240 统一，避免同时调多个量。

**注意**：
- 阶层覆盖来自 `data/target_demand.csv`。表里写「仅贵族」的商品，痴迷修正只会影响贵族的消费，教士、市民和下层不受影响。文案必须如实描述成「宫廷风尚」。
- `pearls / gems / amber / ivory` 等合并行在实现时展开为每个商品一行，参数相同。
- PP 的 `victuals` 没有已核实的全局需求接口，JTG 的 26 种额外商品也未审计，v1 都不纳入。

## 3. 文化与宗教亲和表

### 3.1 原则

- 原版文化的 `goods_demand_modifier` 只覆盖很少的组合（olives、tea、legumes、saffron 等），不足以表达选择性。痴迷自建一张「商品类别 × 文化组」和「商品 × 宗教组」的亲和表。
- 亲和表作为即时乘数影响**传播系数 p 和入口输入**，不另存接受度状态，也不直接改需求。文化差异体现为传入速度和覆盖范围。
- 表格的键用原版的文化组和宗教组。具体判定接口（主文化所属文化组、国教所属宗教组）在 08 的 P0 清单里核实。

## 5. 历史局势与原版事件的衔接

原版已经有用市场临时需求表达的咖啡、茶、巧克力事件（`prices.txt`，事件号和行号见 [08](08_Technical_Implementation.md) 的冲突清单）。处理原则：

1. 新游戏里，被痴迷局势覆盖的原版事件不再施加市场临时需求，改为给目标国家的有界入口地点一次性增加 x 并登记传播候选，叙事保留；不能免费修改全国所有地点。
2. 只做最小范围的覆盖（单个事件），不替换整个 `prices.txt`。
3. 旧存档里已有的市场临时需求无法归属到国家，保留不动，并在 tooltip 里显示「旧制市场需求仍在生效」。

## 6. 风尚创造（通用痴迷）中的商品

玩家可以为任何有 SOL 人口需求的商品创造风尚，但难度不同（详见 [06 风尚创造](06_Player_Fashions.md)）：

| 类别 | 培育难度系数 | 说明 |
|---|---|---|
| 时尚织物、陈设器物、珍宝 | ×1.0 | 宫廷风尚最自然 |
| 兴奋饮料、甜味、香料、烟草、酒类 | ×1.2 | 已有历史局势时，改为给历史局势增加一个新发源地 |
| 知识、仪式、药物 | ×1.3 | 需要相应的制度或宗教背景 |
| 坐骑与异兽 | ×1.5 | 只影响贵族 |
| 日常与主粮 | ×2.0 | 「为面包痴迷」需要更多理由 |
