# 07 界面与地图模式

状态：2026-10-19 设计修订。地点 × 商品只保存一个浮点强度 `x`。地图和界面读取当前 x、允许的国家/市场聚合、共享波次信息及真实引擎状态。阶段直接派生：x = 0 未接触；0 < x < 1 未采纳前沿；1/20/45/70 分别是成员及阶段 2/3/4 的下界，100 封顶。

不保存也不显示地方 E、D、R、历史峰值、传播来源/途径或地点传入年份（国家级加入月份属于国家时钟，可以显示）；不得在全局地点键表中复制它们。国家聚合表示当前地点 x 的汇总，不是另一套传播积分。GUI 实现仍须读共享及本地 GUI 指南，经 renderer 与实机核对；本文是显示需求，不是已验证 GUI 代码。

## 1. 地图模式

### 1.1 已有引擎证据

局势数据地图的 root 是地点，支持主色、条纹、图例及 tooltip，见 `.eu5-base/reference_game_files/game/in_game/common/situations/readme.txt:17-19`、`black_death.txt:243-264`。独立地图字段见 `.eu5-base/reference_official_defines/types/map_modes.txt:3-28`，选择器见原版 `gui/hud_bot.gui:1795-2116`。SOL 已有国家变量着色与局势地图；面板地图覆盖见共享 anti_pattern `situation_custom_mapmode_not_script_field`。这些证据不证明新 GUI 绑定已通过测试。

### 1.2 地图清单

| # | 名称 | 主色 | 条纹 | 用途 |
|---|---|---|---|---|
| M1 | 单商品痴迷，局势数据地图 | 地点当前有效 x 的主题色深浅（所在国退潮时为 x×S_c，并整体偏灰）；共享波次休眠时灰化 | 0 < x < 1 | 实际地点前沿、飞地、屏障，以及由内向外的退潮带 |
| M2 | 主导痴迷，独立地图 | 所有者当前聚合强度最高的商品 | 第二高商品，聚合强度达到 20 时 | 国家当前口味地理；图例明确国家聚合口径 |
| M3 | 痴迷总强度 | 所有者当前聚合需求增幅之和 | 存在聚合强度 ≥ 70 的商品 | 当前国家预算压力 |
| M4 | 抵制与禁令 | 所有者真实政策：无/禁奢令/全面禁令 | 禁令与该地 x ≥ 45 同时存在 | 政策与现存强度的冲突，不声称已测得走私 |
| M5 | 我的风尚 | 玩家倡导商品在各地的当前 x | 0 < x < 1 | 该商品当前分布，不推断各地由谁传入 |
| M6 | 供需风险 | 所有者阶段 ≥ 2 商品的共享可得性最低值 | 当前聚合强度 ≥ 45 且可得性低 | 当前高强度与断供风险，不显示依赖记忆 |

M4/M6 的显示阈值待校准。当前 x 相同的长期习惯和新热潮无法区分，界面不能声称知道两者的不同历史。

### 1.3 主题色与图例

主题色由 `data/obsession/goods.yaml` 配置：coffee 深棕、tea 青绿、tobacco 土黄、cocoa 红棕、sugar 粉白、liquor 琥珀、porcelain 钴蓝、fine_cloth 茜红、books 墨蓝，其余按类别给色。相邻大商品尽量选不同色相。

图例标明 x 阈值、未采纳前沿与共享波次休眠。不能因波次休眠而隐藏仍有 x 的习俗；动态商品图例若不可用则使用固定图例，P0 核实。

### 1.4 地点 tooltip

```text
[地点名] · [当前所有者]
  咖啡  风尚  x 38
  茶    未采纳前沿  x 0.24
  当前政策：咖啡禁奢令
  当前市场供货：稳定
  咖啡共享波次：欧洲传播，1610–1690
```

商品图标使用引擎注册的内联图标，商品键查原版 goods。共享波次年份不是地方传入年份。所有者、政策和供货须有真实引擎读取或已计费共享聚合；没有数据时如实显示未取得数据。tooltip 不遍历邻边或历史来推测来源，不新增 src/via/peak/since 缓存。

### 1.5 性能

M1/M5 读取选定商品的一个地点 x，直接比较阶段；不存地方阶段或主导商品缓存。M2/M3 读允许的国家汇总；M4/M6 读真实政策与共享供货数据。国家/市场聚合维护计入预算，地图不触发世界扫描。月度刷新、打开面板和 tooltip 的实际成本另测，不能因“只读”就不计成本。

## 2. 局势面板

局势、成员展示、行动入口继续保留。共享模板加每商品薄文件的生成方式参照原版 situation 面板 readme 及现有 `global_living_standard.gui`。原版局势专用成员列表不能直接视为通用地点列表；国家排名基于允许的聚合，GUI scope 绑定须 P0 核实。

```text
[商品图标] 苏菲之杯
咖啡 · 欧洲传播 · 本波 1610–1690 · 波次发源：也门

世界概况
  当前成员地点数 / 前沿地点数 / 成员国家数
  领跑国家：当前聚合强度 78
  近 50 年世界成员数趋势（共享采样）

我的国家
  当前聚合强度 38 · 风尚
  可得性 0.84 · 当前政策：禁奢令
  痴迷倍率 / 替代后商品因子 / 市场实际需求
  下一阶段：聚合强度 45；不提供到达年份预测
  本国热潮：1615 年传入 · 将于 1635 年开始退潮（或：退潮中，余 62% · 已定格为习俗 30%）

主要成员：按当前国家聚合强度排序，最多 8 名
大事记：实际发生的世界和本国事件
[局势行动]
```

共享波次可记录本波起止、发源和阶段，不据此填写各地点来源或开始年份。大事记最多 6 条，世界成员数每 5 年采样，均存在局势 scope；禁止逐地点采纳史。聚合显示统计口径及共享批次刷新时间，不增加地方时钟。

需求效果区分痴迷倍率、替代后商品因子与市场实际需求，不能将痴迷倍率说成实际需求增幅。当前 x 无法可靠推断未来路径，不提供“预计 6 年采纳”的地方承诺。

## 3. SOL 面板中的“潮流与风尚”

```text
当前聚合强度：咖啡 38 · 烟草 52 · 酒 30（波次休眠）
未采纳前沿：茶，当前前沿地点数 4   [隔离港口]
风尚培育：琥珀 62/100   [宫廷示范] [取消]
或 [倡导风尚]
```

点击商品打开局势。培育进度是允许的国家共享状态；行动对入口 x 加种子或改变国家/市场共享参数，调用同一核心。习俗显示保留的当前 x，不是另一份地方习俗快照。

## 4. 商品卡片和 tooltip

| 位置 | 增加内容 |
|---|---|
| 商品卡片 | 当前国家聚合强度对应的痴迷标记；图标按 GUI 指南核实 |
| 商品 tooltip | 当前聚合强度、阶段、政策及经济倍率；无传入来源、年份、峰值或依赖度 |
| 市场商品 tooltip | 允许的市场聚合成员数和当前需求效果，标明刷新口径，维护计费 |

## 5. 通知

| 情况 | 信息来源与限制 |
|---|---|
| 本次更新跨过采纳/阶段阈值 | 调用内临时比较旧/新 x；国家通知按聚合变化限频，不保存地方首次标志 |
| 高强度商品断供 | 真实供货变化与当前强度触发国家事件，不声称已经测得依赖戒断 |
| 新波次启动 | 共享波次信息；按国家联系条件筛选 |
| 玩家风尚在大国形成 | 国家聚合跨阈值及共享倡导信息，不宣称唯一传播来源 |

再次跨阈值可能再次产生同类通知；国家事件冷却可以限频，没有地方历史就不保证“史上首次”。通知筛选与统计维护同样计费。
