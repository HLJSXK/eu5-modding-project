# 12 百年窗口与单变量容量

日期：2026-10-19。状态：百年排期候选与单变量设计；未实施玩法脚本，未做引擎耗时验收。

**现行硬约束以02为准：每地点×商品唯一持久浮点x。** 此前接触/依赖方程、量化事件预测、带queued/prev的常驻地点链表、压力/边贡献缓存、细强度与传播强度双副本全部撤下；调度改用方案A的暂存队列指针（见10）。时间窗口审计仍有效；旧事件率和状态槽容量不能沿用。

## 1. 每轮工作期包含缓冲不超过100年

推荐标称窗口最长80年，可提前启动10年、收尾最多10年；每轮从最早启动到最晚收尾≤100年。通用风尚同样适用，新发源地加入不刷新截止日。

局势容器可隐藏休眠以便复用。原地点x就是习俗，不保存另一份习俗快照。后续波通过新入口或新路线唤醒候选，不重新初始化所有老消费者；来源已稳定而x不变时，也要显式登记新路线目标。

缩短窗口只减少不必要的持续工作，不能把相同数量任务压入百年后声称省了操作。稳定节点退出引用候选、没有输入的零地区不扫描，才是与本模型直接有关的收益。

## 3. 切波真的停止旧任务

- 所有历史和玩家商品都用相同x公式与侵入式候选队列，不另分事件型扩散。
- 稳定节点退出候选；有外部变化再进入。没有逐地点到期、斜率、peak、seed或qSignal缓存。
- 商品级轮次/阶段控制工作是否继续，截止后原地保留x；队列中残留地点的出队清理仍计费。
- 收尾只完成已经形成的前沿/退潮，不能新增全球路线后把成本藏在交接里。
- 普通dirty不自动重开全球波。确有复兴时，取得期限与共享名额。
- 时尚型的后续退潮使用共享波龄/政策系数和同一个x，不能把地方峰值永久冻结，也不能加回消费史状态。

### 3.1 百年窗口与国家时钟的关系（2026-10-19）

百年上限约束的是**传播登记**：窗口截止后不再为该波次播种、开新路线或唤醒新地区。国家时钟的退潮在窗口之后继续走完，因为它只是已加入国家每月一次的 S_c 更新，成本约 3 U/国/月，不再服务节点。

因此一个波次的“工作期”分两段：窗口内的增长（主要成本）和窗口后的退潮尾巴（几乎不花 U）。T = 240 时，最晚在窗口末期加入的国家还要 20 年才开始退潮，再约 19 年退出成员档（g = 0.98），κ = 0 时再约 47 年完全归零。排期审计时，同时活跃层数只统计窗口内的增长层；退潮尾巴按活跃国家数单独计入时钟成本。

## 4. 单变量成本重新核算

现行更新：

```text
x_new = clamp(rho*x_old + Σ(p*x_neighbor) + hub_input,0,100)
```

每个地点的公式与实际邻接度d相关，O(d)。x变化后登记自己及邻居下轮候选，也是O(d)，但只登记引用不递归计算。稳定且无外部变化的地点退出候选，不付每月状态服务成本。

单变量已经取消原来的独立采纳积分、依赖度阈值、下一量化时间预测、多个状态锚点和逐地点日历轮。先前的128/200U服务成本、每对76次状态事件、16,470/28,000对容量以及63月重挂税属于已撤下架构，不能拿来评价本版。

50万约束仍针对新增痴迷工作；计划480,000操作额度由全部商品共享，20,000留裕量。但新额度必须按真实脚本展开后重新配置：

```text
状态节点服务 + 实际邻边枚举 + 入队/出队
+ 长程入口 + 共享输入刷新/外部唤醒 + 国家经济聚合
+ 回调、初始化与清理 ≤ 每月额度
```

不能只数乘法，也不能把所有维护都算成一个地点固定200次。方案A已不依赖原生列表去重与游标，但入队出队仍按次计费，邻边有界枚举尚未核实。经济聚合没有逐地点旧贡献账本，必要的重聚合读取必须计费。

## 6. 历史与性能验收

- 09主要历史目标保留，不以砍窗口直接写出采纳结果。欧洲咖啡北德约1700须在1690前形成前沿并在收尾完成，或在既有误差范围内提前到达。
- 茶后波承接俄国1690–1730与英国1720–1760；日本茶道1570–1590、俄国烟草1697解禁等窗外节点走有期限地方唤醒，照常收费。
- 先核实每地点每商品只一个浮点字段，且全局没有按地点复制数值状态。
- 核实地点引用变量（方案A）、实际最大邻接度、任务预扣与原生邻边枚举可实现。
- 比较不同服务顺序、预算和逻辑轮长的采纳日期与强度，不能用时间戳或双数值缓冲修正而违反约束。
- 同时测短排期11/12商品高峰、旧13/14与超额17商品；队列长度、最老任务、每轮跨月长度、入口发现和经济提交延迟分别报告。
- 最后实机验证操作数、过月耗时、存档体积、历史落点与SOL经济闭合。缺少容器上界或外部唤醒路径时，不能把模型精简视为已达成性能要求。
