# 01 局势框架：单变量地点状态

日期：2026-10-19。状态：现行设计，尚未实施。地点×商品唯一持久变量为浮点x；国家与局势只维护共享政策、工作窗口和由地方x派生的聚合。模型见02，实现约束见10。

## 1. 引擎事实与设计边界

路径缩写：D=`.eu5-base/reference_official_defines/docs/`，V=`.eu5-base/reference_game_files/game/in_game/`。

- 每个局势键只有一个实例；同商品不同波通过共享阶段和工作窗口复用。
- 参与者由本mod维护国家成员索引，visible判定是否展示，不能假设有可直接复用的原生成员系统。
- 启动、结束原语依据D`effects.log:12–15,1661–1664`及`triggers.log:8272–8276`；局势结束后能否重新启动仍是P0，必要时隐藏休眠复用容器。
- 局势行动的原版依据为V`common/generic_actions/black_death.txt:2,17–27`，面板入口为V`gui/panels/situation/common.gui:450–453`。这里只保留已查原语线索，真正写脚本仍按共享三步核实规则。

## 2. 每商品一个局势，地方只有一个x

商品局势使用`sol_obs_<good>`一类键。局势有多个发源地时，来源只表示当前有界播种入口，不能要求地点另存来源、首次日期或固定随机偏移。

- x=0：当前无热度；从未接触与退潮清零不再区分。
- 0<x<1：尚未采纳的弱影响，可在前沿图层显示。
- x≥1：已采纳。国内任一地点达到此条件就满足参与条件。
- 20/45/70为风尚/狂热/痴迷门槛，直接从当前x派生。

国家成员数/代表强度为地方x的派生聚合。均值可能低于1而仍有一个港口已采纳，因此国家成员判定不能简单写成均值≥1。重新聚合或来源明确的差值操作按真实费用计入预算，不额外持久化地方贡献账本。

## 3. 波次生命周期

| 共享阶段 | 条件与行为 |
|---|---|
| 萌发 | 发源条件和日历窗口满足后，有限入口获得x种子并登记源及受影响目标 |
| 扩张 | 当前成员/强度达到共享门槛；候选集沿邻接、贸易入口扩散 |
| 鼎盛 | 用国家聚合与波次公共信息判断，不依赖地方peak/date字段 |
| 国家退潮 | 各国×商品在首个地点x≥1时记加入月份；保持T（基准240月）后整国进入懒衰退，不再接收输入。不同国家先后进入，退潮由内向外推进（见02第8节） |
| 结束/休眠 | 截止后停止新的传播登记；已在退潮的国家继续按时钟衰退直至归零或定格为习俗；容器是否真正end由P0决定 |

12的百年候选是推荐排期：每轮从最早启动至最晚收尾≤100年；标称最长80年、前开/收尾各最多10年。通用风尚也受期限约束，加入新发源地不重置截止日。11的长窗仅为回归基线，保留全部历史商品与同一核心。

晚期重要节点通过有期限的地方唤醒进入同一x更新，不直接给出“已经采纳”的经济结果。新增路线必须显式登记其目标，即使旧来源x已稳定、播种没有改变其数值，也不能因此漏掉传播。

## 4. 退场与习俗

结束表示本轮密集传播结束，不表示原有消费消失。原地x就是留下的偏好，不复制第二份地方快照。

- 稳定内部在窗口内也可退出候选，邻居或共享条件变化时再唤醒。
- 截止先停用商品级轮次，残留队列分片出队清理并计费，不在截止日遍历全部地点清变量。
- 退潮由国家级时钟驱动：国家×商品存加入月份、衰退标志、结束标志和共享因子S_c，地点仍只有x。读取时x_eff=x×S_c（有习俗保留率κ时为x×(κ+(1−κ)S_c)）。
- 习惯型商品用共享习俗保留率κ：S_c降到0.01以下时整国定格为κ×x并停止计算；时尚、陈设类κ≈0，退到零。κ按商品类别设定，见03第2.1节。
- 不保存地方峰值、依赖、习俗下限或退潮时间；同x但历史不同的地点没有额外差别。
- 新历史波复用已有x，只建立新入口/候选；普通dirty不自动重启全球传播。

## 5. 所有权与继承

地点x随土地保留。吞并、释放、殖民等不再继承另一套国家强度/熟悉度；新的国家代表强度来自其实际地方x。

所有权变化可利用引擎提供的旧/新国家引用登记聚合重建。地点不新增旧所有者、旧市场或旧人口权重缓存。若无法保证增量正确就使用计费的有界重聚合；winner为空时要保护作用域。

国家时钟下的换主：若旧国家正在退潮，先把x按旧国家的S_c写回为有效值（x←x×S_c，O(1)）；之后按新国家状态处理——新国家未在退潮则该地点重新可被点燃并入队，新国家已在退潮则随新国家的S_c继续衰退（写回时除以新S_c）。新国家若从未加入，换主不会替它记加入月份，只有地点x≥1的更新才会。

## 6. 调度与SOL接入

传播任务由商品级共享调度器按月推进，局势回调只门控、登记共享任务、事件和工作期限；不每月扫描全球地点商品对。

国家经济自然刷新入口依次使用：

```text
已准备好的国家x聚合快照
→ 痴迷修正
→ 原有替代计算
→ 原有SOL支出聚合与求解
→ 原有地点需求修正
```

传播年中改变x只登记国家聚合需要刷新，不触发额外全量SOL求解。准备未完成时保留旧完整经济快照，下一自然入口再消费。重聚合的地点读取、商品循环与国家修正写入均计入新增预算，不能藏进既有遍历而不计费。

## 7. 需求组合

同种商品需求修正的多个来源在引擎中相加，因此痴迷与替代需要换算，保持现有经济契约：

```text
B = max(0,1+其他来源的商品需求偏移)
H = 1 + h_g × X[c,g]/100
M = 现有替代倍率
痴迷修正 size = B × (H−1)
替代修正 size = (B+痴迷修正) × (M−1)
最终因子 ≈ B × H × M
```

X是国家由地方x得到的聚合，不是独立演化状态。B的回读和本mod实际生效修正的扣除沿用现有替代系统契约；不在这里新增引擎修正名称。B=0或阶层基础需求为0时不创造需求。权重和代表强度选择须与地图/国家成员语义分开说明。

## 8. 开关与兼容

历史痴迷、玩家风尚与事件开关可保持国家/局势级状态。关闭传播停止候选服务，关闭经济效果按国家修正清理，地点x保留且不重掷随机数。总SOL关闭时不留下未记账的痴迷需求。

standalone不依赖CMF；PP/M&T/JTG继续按08的商品、价格及经济权威性处理。地方单变量约束对所有目标一致，不因兼容而恢复额外地方状态。
