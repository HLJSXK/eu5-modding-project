# 20 验收矩阵规格（交付实现）

日期：2026-10-20。状态：**门槛已定稿**（用户授权由我调查并确定），交给实现者编码；开始拟合前按 15 §4 冻结。本文是 [15 §6](15_History_Fidelity_Criteria.md#6-三级闸门) 的操作化规格：15 定义「验收什么」，本文定义「怎么算、门槛多少、依据是什么」。两者冲突时以本文数字为准，并同步改 15。

## 0. 摘要

- 验收矩阵是 **配置 3 种 × 世界 2 种**：S（固有+结构）、H（+历史事件）、G（+通用事件替代历史事件）× R（史实时间线）、O（非史实世界，观察者存档）。F（游戏实际混合配比）不进入 3×2 主矩阵，只在 L3 作派生检查。
- 每格的门槛见第 4 节总表；依据见第 5 节；条件式规律 K1–K7 的最终口径、区间与证据级别见第 6 节（K1、K2、K4–K7 共 6 条达到 B 级可计分；K3 为 B 级但依赖未实现的规则，暂不可判定，不计入「≥5 条」）。
- 现在就能实现并运行的只有 **S×R 的 L1 项**；S×R 的 L2 需要 `D_event`，依赖事件层；H/G 需要事件层，O 需要观察者存档的快照序列，且现有存档只到 1510 年（第 8 节）。

## 1. 矩阵与记号

| 记号 | 配置 | 说明 |
|---|---|---|
| S | 固有 + 结构 | 关闭全部事件 |
| H | S + 历史事件 | 历史事件按条件与概率触发（19 §5） |
| G | S + 通用事件 | 关闭历史事件，只开通用事件 |
| F | S + 历史 + 通用 | 按 04 §2.3 配比混合；只在 L3 检查 |

| 记号 | 世界 | 世界状态时间线 | 判什么 |
|---|---|---|---|
| R | 史实 | 1337 开局 + 史实世界状态表（19 §2，W 级） | 绝对年份里程碑 + K 条 |
| O | 非史实 | 观察者存档快照序列（18） | 只判 K 条与健全性、事件落点 |

固有层不做运行验收，按 15 §4 与 19 §2.1 的出处与级别把关。

## 2. 运行协议

| 项 | 规定 |
|---|---|
| 参数 | 三个商品（coffee、tea、tobacco）用同一套参数；矩阵各格用同一套参数，只改启用的层与世界 |
| 蒙特卡洛 | 每格每世界 30 次，随机项包括：局势启动、事件触发、接触触发、W-B 事实在区间内的取值。种子编号 0–29 固定，结果可逐次复现；不同配置用同一组种子 |
| 未到达 | 里程碑未到达记年份 +∞（误差无穷大，计入分母），不得从分母剔除（15 §7） |
| 里程碑判分取值 | 每次运行算「在 tol 内比例」「在 2×tol 内比例」；判分用 30 次的中位数。15 §6.2 L2 的「MC 分位区间内仍 ≥60% 在 tol 内」= 30 次的「在 tol 内比例」的 10% 分位 ≥ 0.60 |
| 里程碑集合 | L1 用全部 A/B 里程碑；L2、L3 的主项用拟合集，留出集按 15 §6.2 单列 |
| `p_K` 取值 | 每次运行 `p_K` = 通过 ÷ 已触发；某次无任何已触发 K 时该次不进中位数。世界的 `p_K` 用其余运行的中位数；O 世界另要求 10% 分位（第 4 节） |
| 选参与留出 | 选参（包括 19 §7 在 S×R 上的扫描）只能看拟合集里程碑与 K 条；**留出集在所有配置、所有世界中都不得参与选参或人工看盘调整**（15 §5.9） |
| 冻结 | 开始拟合前，把本文第 4、6 节的门槛与 K 定义、里程碑表、世界状态表写入版本化 JSON 并记录哈希；任何改动单列且该次不算通过（15 §4） |
| 世界数量 | L2 需要至少 1 个 O 世界；L3 需要另 1 个**未参与任何选参**的独立 O 世界 |
| O 世界可判定条件 | 每次运行已触发的 A/B 级 K 条数取 30 次中位数，≥ 3 条才可判定；不足时该世界 `p_K` 记「无法判定」，不能用于宣称闸门 |
| O 世界的时间分辨率 | 观察者存档十年一档，世界状态在两档之间按阶梯保持（取前一档）；K 条在 O 世界判定时，允许区间两端各放宽 10 年 |

## 3. 指标定义

15 已定义的指标（里程碑误差、`p_order`、约束违反、`p_unseeded`、`p_conn`、MC、留出、`p_K`）沿用 15 §5。本规格新增指标前，先统一几个术语：

| 术语 | 定义 |
|---|---|
| 成员 | 地点 x ≥ 1（02）；「曾为成员」指运行中任一月份 x ≥ 1 |
| 陆地点 | 模拟图的全部节点（当前 20,893 个；14） |
| 非邻接输入 | 种子、发源输入、商人接触、所有权通道、事件给出的入口 x，以及开局习俗。凡不是经图上邻接边（含海峡边）传播得到的 x 都算 |
| 入口 | 首次成为成员时的直接原因是非邻接输入的地点；开局即为成员的地点也是入口，生效月 = 运行起始月 |
| 父来源类型 | 地点首次成为成员的那个月，贡献最大的输入类别：邻接 / 种子 / 发源 / 接触 / 所有权 / 事件 / 开局。模拟器须在回放中记录，属离线诊断数据，不是游戏状态 |
| 痴迷来源 | x_c ≥ 20 的国家，或 x̄ ≥ 20 的市场（不使用待校准的 θ，避免门槛随参数漂移） |
| 商人常驻 | 该国在该市场的商人份额 > 0 |
| 事件类别 | 每个事件声明 `kind = spread / impact / flavor`（04 §1 的传播、影响、风味）与 `pool = historical / generic` |

| 指标 | 定义 | 30 次汇总 | 用于 |
|---|---|---|---|
| `D_event` 事件依赖度 | 同一世界 R、同一种子下，A/B 级里程碑中满足 \|年份(H) − 年份(S)\| > tol 的比例（一侧未到达、另一侧到达也计入） | 中位数 | S×R 与 H×R 的对照 |
| `A_max` 单事件最大影响 | 在 H×R 中逐个关闭历史事件，每次统计年份位移超过 tol 的 A/B 里程碑数，取所有事件中的最大值 | 每个事件取 30 次中位数后再取最大 | H×R |
| `V_land` 陆路前沿速度 | 对每个父来源类型为「邻接」的到达地点 v：d = v 到「到达时已是成员的入口」在图上的最短跳数；Δ = v 的到达月 − 该入口生效月；只计 Δ ≥ 12 个月的到达，速度 = d ÷ (Δ/12)；取所有这类到达的中位数（跳/年）。按商品分别计算 | 中位数 | 健全性 |
| `C50` 50 年覆盖增量 | 任意连续 600 个月内新增「曾为成员」的陆地点数（不含开局即为成员者）÷ 陆地点总数，取最大值。按商品分别计算 | 中位数 | 健全性 |
| `T_alive` 首次外传 | 记局势启动当月 x_c ≥ 20 的国家集合为发源集（含开局习俗国家）；`T_alive` = 启动到首个发源集以外的国家 x_c ≥ 20 的年数。启动后观察期不足 100 年且尚未发生时记「无法判定」 | 中位数 | 健全性 |
| `p_link` 落点有据率 | 只统计 `pool = generic` 且 `kind = spread` 的事件。每次触发时，目标国满足以下任一条件即「有据」：在某痴迷来源市场有商人常驻；与某痴迷来源国接壤；拥有 x ≥ 1 的地点；满足事件自身声明的联系条件（如联姻）。有据次数 ÷ 总触发次数 | 中位数 | G×O |
| `B_max` 同月爆发 | 同一事件在同一月内于不同国家触发的最大次数 | 30 次中的最大值 | G×O |
| `E_gap` 通用事件空窗 | 「合格月」= 该商品处于活跃波次，且至少有一个国家满足某个通用传播事件的条件。`E_gap` = 连续合格月中没有任何通用传播事件触发的最长时长（年） | 中位数 | G×O |
| `M_mis` 误触发 | 历史事件在 O 世界中触发时，触发时刻不满足其声明条件的次数（应为实现错误） | 30 次总和 | H×O、F×O |
| `ΔK` K 条劣化 | `p_K`(加事件配置) 的中位数 − `p_K`(对应无事件配置) 的中位数，同一 O 世界、同一组种子 | — | H×O、F×O |

**健全**：一次运行中，三商品各自满足 `V_land` ≤ 1.5 与 `C50` ≤ 0.50，且凡可判定的 `T_alive` ≤ 100，即为健全。健全率 = 健全运行数 ÷ 30。三项都无法判定的商品不计入该次判断；若三商品都无法判定任何一项，该世界健全率记「无法判定」。

### 4.2 宣称规则

1. 某闸门要求的所有格都达标才可宣称该闸门；报告必须逐格列出。
2. H×R 达标而 S×R 不达标：说明历史仍由事件写出，不得宣称。
3. A/B 级 K 条少于 5 条，或任一要求的 O 世界「无法判定」：相应闸门不得宣称。
4. 三个商品同一套参数（15 §6）。

## 5. 门槛依据

| 门槛 | 取值 | 依据 |
|---|---|---|
| S×R L1 `p_order` ≥ 0.60 | 比 H×R L1 低 0.10 | 允许缺少事件修正带来的次序错位，但方向必须对 |
| S×R L2 = H×R 的 L1 年份/顺序/约束三项 | — | 结构层单独应达到「方向正确」，否则不能说历史由规则推出（19 §0） |
| `D_event` ≤ 0.30 / 0.20 | — | 17 的首批结果中 36 个目标有 33 个是手工输入终点（约 0.92），路线平移 ±20 年时终点 1:1 跟随；本门槛要求事件只决定少数里程碑。0.30 约等于「三分之一」，与 17 §6 的自由度规则口径一致 |
| `A_max` ≤ 2 / 1 | — | 单个事件只应解释一处偶然偏离（如英国偏向茶影响英格兰与北海两条）；超过即是用事件替代规则 |
| `V_land` ≤ 1.5 跳/年 | — | 真实图上咖啡的历史推进：穆哈→麦加 17 跳/约 50 年（0.34）、→开罗 42 跳/约 55 年（0.76，含红海段）、→伊斯坦布尔 59 跳/约 105 年（0.56）、→威尼斯 91 跳/233 年（0.39）、→维也纳 88 跳/235 年（0.37）。引擎制度在同图实测约 2.5–3.3 跳/年（18 §3.4）。取历史最快值约 2 倍、引擎思想扩散约一半 |
| `C50` ≤ 0.50 | — | 历史最快的烟草：1580–1630 年间获得烟草使用的地区合计约占全图陆地点 47%（按地区键粗算：西欧、中东欧、奥斯曼、伊朗、南亚、中日朝、东南亚、几内亚与萨赫勒、俄罗斯）。这是地区层面的上界，地点层面更低；0.50 只拦失控 |
| `T_alive` ≤ 100 年 | — | 咖啡 1450 前后发源，约 1500 已到另一政权的麦加（约 50 年）；烟草约 1530 年代入伊比利亚，约 1560 年到法国（约 30 年）；取历史最长约 2 倍 |
| O 世界 `p_K` 0.6 / 0.8 | 与 H×R 的 L1/L2 相同 | 非史实世界只判 K，要求与史实同一水平；L3 加 10% 分位防止临界过线（15 §5.8） |
| 健全率 0.90 / 0.95 | — | 允许个别随机运行失败，但失控或熄灭不能是常态 |
| `p_link` ≥ 0.90 / 0.95 | — | 通用事件是历史事件的宽松版，仍应有接触来源；留 5–10% 给传闻、风味类不要求联系的传播事件 |
| `B_max` ≤ 3 | — | 04 §2.2 的事件预算目标为每个玩家 3 个局势时年均 1.5–2.5 个痴迷事件；同一事件同月在 3 个以上国家触发已明显偏离该节奏 |
| `E_gap` ≤ 50 年 | — | 波次窗口 ≤ 100 年（11）；一个窗口里通用传播事件出现空窗超过一半即「无处触发」 |
| `ΔK` ≥ −0.10 | — | 一条 K 在约 7 条中占 0.14；允许事件随机性造成不到一条的波动 |

## 6. 条件式规律 K1–K7（最终口径）

阶段界限沿用 02：阶段 2 为 x ≥ 20，阶段 3 为 x ≥ 45。国家强度 x_c、市场强度 x̄、区域强度均按人口加权。级别按 15 §4（A：年份确定、来源可靠无争议；B：通行史实，十年精度或两种常见说法；C：推断）。查证于 2026-10-20，来源列表见 6.2。

### 6.1 通用判定规则

1. **案例**：每条 K 以「国家 C」（或市场、区域）为单位，凡满足 t0 条件者各成一个案例；一次运行可有多个案例。该 K 本次的结果 = 所有已判定案例都通过才算通过，任一违反即违反。
2. **左删失**：t0 条件在运行起始月已成立的案例不判定（记「未触发」）。
3. **右删失**：到观察期末仍未出现 t1、且尚未超过允许区间上限的案例记「未触发」；已超过上限即判违反。区间写成「X 年内不发生」的，观察期不足 X 年且尚未发生时记「未触发」。
4. **消失**：国家 C 在判定前灭亡或失去首都所在地点，案例记「未触发」。
5. **O 世界**：世界状态按阶梯取前一档，允许区间两端各放宽 10 年（第 2 节）。
6. 某 K 在一次运行中没有任何已判定案例，记该 K「未触发」，不进 `p_K` 分母。

K1、K2、K4–K7 共 6 条为 B 级，满足 15 §6「A/B 级 K 条 ≥ 5」，`p_K` 可以计算。K3 依赖供给/税制规则（19 §8 待办），实现前每次运行记「未触发」。

K1 的区间较宽，是史实本身决定的：英国 60 年、法国与威尼斯约 160–180 年。这说明「有商人常驻」只是必要条件，快慢还取决于先占（法、意的酒与咖啡竞争）、正当性与事件等因素，K1 只排除「太快」（< 50 年）和「始终不来」两种明显错误；精度由 K2 与绝对年份里程碑补足。

模拟器需要的静态数据：地点 `raw_material`（14 的地图已有）、地点宗教与宗教→宗教组映射（K7；宗教组取自游戏 `common/religions`），市场成员与人口、各国在各市场的商人份额（R 世界来自世界状态表，O 世界来自存档）。

**与旧稿的差异**（查证结果）：

- 威尼斯首家咖啡馆按学术来源为 **1683 年**；常见的「1645 年」无可靠出处，「1615 年输入」只来自 Ukers（C）。09 §2.3 的威尼斯行已据此修正。
- 维也纳 1683 年的柯尔希茨基故事是后世附会，首张许可为 1685 年；维也纳缺少商人常驻的证据（只有使节），不作为 K1 案例。
- K1 区间由初稿 [50, 140] 放宽到 [50, 180]：威尼斯、法国商人早在开罗一带普及咖啡时（约 1505–1517）就常驻亚历山大里亚，到本国首家咖啡馆约 160–180 年；初稿按伊斯坦布尔 1555 年起算是错的。
- 咖啡在欧洲真正大众化在 19 世纪，18 世纪只是扩大；K3 只取「解除高税后 40 年内达阶段 3」，不再用「高税期间不超过阶段 2」（英国减税前走私茶已很普遍，该条与史实冲突）。
- 俄国大众饮茶在 19 世纪，不在 18 世纪。
- 烟草禁令「大多转为专卖」不准确：西班牙 1636、法国 1674 直接建立专卖而未禁止；日本是放宽、明是撤回、奥斯曼是教令合法化、俄国是解禁征税。K6 因此只判「消费未被根除」，不判结局形式。
