## 1. 「讲逻辑」和「贴近史实」如何兼得

只写逻辑条件会遇到一个问题：1337 年开局时，也门已经出产咖啡，并且被穆斯林国家拥有。如果条件一满足就启动，咖啡热会提前约 100 年开始。

解决办法是在逻辑条件之上加一个**激活风险率**（hazard）：

```text
每月启动概率 = λ_start × 时代系数 × 条件强度

不在 11 的该波允许启动窗口 → 0
条件不满足                 → 0
条件满足，时代早于目标时代  → λ_start × 0.1   （可能提前，但很少见）
条件满足，处于目标时代或更晚 → λ_start
```

- 期望延迟 ≈ 1 / λ_start 个月。λ_start 和目标时代是**校准参数**。
- 11 的日历工作窗口先作硬门控；旧的时代 ×0.1 提前风险只在允许窗口内有效，不能让咖啡在 14 世纪提前占满传播名额。
- 这样仍然是逻辑驱动的：条件不成立，局势就不会出现。例如，如果没有任何旧大陆国家拥有出产烟草的美洲地点，烟草热就不会开始，无论到了哪一年。
- 时代用原版的 `current_age`（`age_1_traditions` … `age_6_revolutions`，V`common/age/00_default.txt`）。各时代的确切起始年份在 P0 核实。

**「条件强度」**：条件越充分，启动越快。例如咖啡的条件强度 = 也门咖啡市场的穆斯林人口份额 × 该市场的贸易连接数（归一化）。

## 5. 校准流程

### 5.1 数据准备

1. 用 `tools/eu5_save_parser` 从存档导出：
   - 国家：首都、主文化、文化组、国教、宗教组、人口、大国排名
   - 地点：唯一动态强度 x、当前所有者、所属市场、区域、人口、出产商品；其余均为真实引擎状态，不复制成地方历史缓存
   - 邻接：地点之间的真实邻接，以及国家/市场共享入口
   - 市场：成员国及人口份额、进出口（来源市场、去向市场、商品、贸易量）
   - 政治：宗主和附庸、同盟
2. 历史快照：1337 年开局，加上约 1450、1550、1650、1750 年的观察者存档。没有观察者存档时，先用开局存档做静态图近似，后面再补。
3. 用快照分段：模拟 1337–1450 年用 1337 年的图，1450–1550 年用 1450 年的图，以此类推。

### 5.2 模拟

- 使用共享模拟包 `tools/obsession_sim`（2026-10-19 起的参考实现：方案A队列、δ = 0.1、国家时钟 T = 240）。真实地图按其 README 第 4 节的图格式导入；里程碑写成 JSON 后由 `milestones()` 直接给出模拟年份与误差，`front_profile()` / `front_speed()` 给出每年推进跳数。按实际原地更新顺序与服务轮次推进，不能把跨月分片默认成同步逐年求解。
- 离线输出地点 x、允许的国家聚合与阶段轨迹，从输出计算首次非零/首次采纳和进入阶段 2/3 的年份。轨迹与首次年份只属于离线报告，不回写成引擎地方 since/peak/last_update 等字段。
- 按区域汇总：区域内人口最多的国家（或人口加权中位数）进入某阶段的年份，作为该区域的到达年份。

### 5.3 损失函数

```text
L = Σ_里程碑 ( (模拟年 − 目标年) / 允许误差 )²
  + 10 × Σ_约束违反次数
  + 0.1 × Σ_参数 ( (参数 − 初值) / 初值 )²     （正则项：不要为了拟合把参数调得太离谱）
```

### 5.4 搜索

1. 先只开增长（预设 `growth_only`），搜索共享通道权重 p、边系数与保留率 rho，拟合到达年份与前沿速度；δ 固定为 0.1。
2. 再开国家时钟（预设 `baseline`），搜索保持期 T（基准 240 月）、退潮因子 g（基准 0.98/月）与各类别习俗保留率 κ，拟合“峰值后多少年显著下降”一类里程碑（如中国风峰值后 30–50 年、金酒热 1751 后下降）。
3. 再对商品做坐标下降：启动风险率、入口初始 x、固定商品抗性、国家/市场共享政策系数、走廊和文化/宗教静态系数。不增加地方亲和度、依赖度或历史参数状态。
4. 对随机性（seed、局势启动时间）跑 30 次蒙特卡洛，用损失的中位数，同时报告 10%–90% 分位数，检查结果的稳定性。

### 5.5 实机验证

- 观察者模式跑到 1750 年，每 25 年存档。用同一个损失函数打分。
- 实机和离线结果差别较大时，以实机为准，回头检查离线图的近似是否太粗（比如贸易关系变化太大）。
- 校准报告写入 `docs/technical/`，记录参数版本、存档、损失、分位数，以及每个里程碑的模拟值和目标值。
- 同时报告每月入队出队与时钟成本、边界与仍在变化的内部规模、积压、最长等待及政策变化后的唤醒延迟；校准要在 `--budget` 给定的额度下复核。离线计数不证明实机在 50 万以内。
- 日本茶道 1570–1590、俄罗斯烟草 1697 等窗口外节点若需地方唤醒，仍使用同一单变量核心并计预算；不能改写为免费采纳，也不能默认重开全球波。
