# 06 风尚创造（通用痴迷）

状态：设计草案。本文定义「通用痴迷」：玩家（以及少数满足条件的 AI）发挥主观能动性，培育出一种历史上不存在的痴迷，然后让它通过 [02 扩散模型](02_Spread_Model.md) 走向世界。

2026-10-19 单变量约束：每个地点×商品只保存 x，`0<x<1` 为未采纳前沿，`x≥1` 为成员，阶段由 1/20/45/70 的下界直接派生。培育是一个**国家级项目入口**：国家进度、费用、冷却、已选商品与期限可保存，但不能为每个地点保存培育进度，也不能在国家或全局地点键表里恢复地方接触/依赖/历史强度。传播后的成瘾差异来自商品固定保留率与国家政策，相同 x 的不同消费史不再可区分。

百年候选规则见 [12](12_Century_Windows_and_Capacity.md)：通用波从实际启动到收尾最长100年，新增发源地不能刷新期限；如需越过已有历史波截止日继续传播，须另获共享名额，不能通过不断加入来源无限续期。

---

## 1. 体验目标

1. **主动创造**：玩家不是等待历史潮流降临，而是选择一种商品、投入资源、经营条件，亲手点燃一股风尚，比如「威尼斯的琥珀热」「卡斯蒂利亚的大象崇拜」「明朝的葡萄酒风尚」。
2. **有战略回报**：风尚是一种经济武器。如果你是某种商品的主要生产国或出口国，为它创造海外需求，就能抬高价格、扩大出口。反过来，抵制别国输出的风尚，可以保护本国的预算结构。
3. **有风险和代价**：培育要花钱和威望，可能失败。风尚流行开来以后，本国的预算也会被它挤占，还可能引来道德争议和禁令。
4. **和历史潮流共存**：对已经存在历史局势的商品发起风尚，不会新开局势，而是给历史局势增加一个新发源地。玩家可以抢先点燃咖啡热，让它从意大利而不是也门开始。

---

## 2. 入口：「倡导风尚」行动

### 2.1 为什么不放在局势里

局势行动只在局势激活、并且国家是成员时可见（`visible`）。风尚创造发生在局势存在**之前**，所以入口必须是一个**国家级**入口：
- 首选：`generic_action`（类型为国家，P0 核实可用的 type），放在 SOL 经济面板的「潮流与风尚」区块里，通过按钮触发。
- 备选：决议（decision）。

### 2.2 前置条件

| 条件 | 值 |
|---|---|
| 同时进行的培育 | 最多 1 个 |
| 冷却 | 上一次培育结束（无论成败）后 15 年 |
| 威望 | ≥ 25（P0 核实威望的读法） |
| 首都市场 | 这种商品有供应 |
| 本国该商品的 SOL 需求 | 至少有一个阶层的校准需求大于 0（否则风尚不会产生任何效果） |
| 本国该商品的痴迷 | 还不是成员（已经是成员就用局势行动去加速，而不是重新培育） |
| 宗教系数 | ≥ 0.3（伊斯兰国家不能培育烈酒风尚） |
| 世界范围 | 按 11：全世界额外最多 1 个通用商品传播层，人类与 AI 共享；与现有历史波同商品时复用该层。新商品在收费前预留名额或排队，不能培育完成才发现名额不足 |

### 2.3 花费

- 启动：威望 −25，金钱 −3 个月收入 × 难度系数（类别难度见 03 第 6 节）。
- 持续：培育期间每月一个「宫廷赞助」开支修正，约等于月收入的 3%。
- 取消：随时可以取消，返还一半威望，冷却照常计算。

## 3. 培育期

### 3.1 进度

```text
进度每年增长 = 基础 10
             + 供应保障 (0–8)
             + 富裕引领者 (0–6)
             + 宫廷与艺术 (0–5)
             + 首都规模 (0–4)
             + 玩家杠杆 (见 3.2)
             − 逆风 (0–10)
             再除以 难度系数

进度达到 100 → 风尚成立
```

| 来源 | 计算 | 说明 |
|---|---|---|
| 供应保障 | 8 × min(1, 本国可得性 S / 0.8)；本国是产地时 +2 | 没有稳定供应，风尚就是空谈 |
| 富裕引领者 | SOL 贵族和市民的 funds/baseline，1.0 时为 0，1.5 时为 6 | 直接复用 SOL 的生活水平数据 |
| 宫廷与艺术 | 首都有与商品类别相关的艺术品或建筑（P0 核实 `create_art` 等接口能否带主题；做不到就改为培育事件链给出的加成） | 「凡尔赛效应」 |
| 首都规模 | 首都人口或城市等级 | 大城市才是风尚中心 |
| 逆风 | 宗教系数 < 1 时每差 0.1 扣 2；价格高于基准价 1.3 倍时扣 3；处于战争中扣 3 | — |

### 3.2 玩家杠杆（培育期专属行动）

| 杠杆 | 效果 | 代价 |
|---|---|---|
| 宫廷示范 | 进度 +10（一次性），培育事件「宫廷名媛带头」的概率提高 | 威望 −10，冷却 3 年 |
| 进口补贴 | 调用 `set_goods_import_trade_policy` 的负值（补贴），价格下降，供应保障提高 | 每月金钱，持续到取消 |
| 资助作家和艺术家 | 进度 +5 每年，持续 5 年 | 金钱 |
| 赞助专门场所 | 进度 +5 每年；风尚成立后，本国传播 p 额外 ×1.2，持续 10 年 | 金钱，市民满意度 +5 |

### 3.3 培育事件

培育期间每年 30% 概率触发一次，从下面抽取，每个事件只出现一次：

| 事件 | 选项 |
|---|---|
| 宫廷名媛带头 | A「公开支持」：进度 +15，贵族满意度 +5；B「保持低调」：进度 +5 |
| 教士批评奢靡 | A「辩护」：教士满意度 −10，进度不受影响；B「暂缓」：进度 −10 |
| 商人囤货 | A「打击囤积」：花钱，供应保障 +4，持续 3 年；B「默许」：价格上涨，逆风 +3 |
| 外国使节的嘲笑 | A「坚持品味」：威望 −5，进度 +5；B「入乡随俗」：进度 −10 |
| 艺术家的作品 | A「委托」：花钱，进度 +10；B「拒绝」 |
| 一场宴会 | A「盛大举办」：金钱 −中，进度 +15，威望 +10；B「从简」 |

### 3.4 失败

| 失败原因 | 处理 |
|---|---|
| 首都市场断供超过 2 年 | 培育失败，返还 25% 威望 |
| 玩家取消 | 返还 50% 威望 |
| 国家失去首都所在的市场 | 培育失败 |
| 有其他国家先在这种商品上让局势进入鼎盛 | 培育转为「加入」，将国家进度换算为首都等一个已选入口的播种强度 `x=max(x,min(25,进度/4))`，登记统一候选；未达到 1 时仍是前沿，不直接强制加入 |

## 4. 风尚成立

### 4.1 立即效果

- 在首都或一个已选港口播种 `x=max(x,25)`（该地阶段 2），只写这一份 x；登记该入口及邻接候选，国家因该地 x≥1 加入局势。其余地点沿同一模型传播，不在成立瞬间获得全境强度。发源国信息保存于商品/波次共享层，不增加地方发源标签。
- 如果这种商品的局势未激活：启动局势，局势名为「<国家形容词><商品名>风尚」（比如「威尼斯琥珀风尚」）。名称通过局势变量和脚本化本地化生成，P0 核实可行性；不可行就用通用名「琥珀风尚」，在面板副标题里写发源国。
- 如果局势已经激活：在同一商品层新增上述入口，本国的 π（国家传播系数乘数）在 20 年内 ×1.3；不另存固定随机 seed，也不重置共享波次起止时间。
- 发一条世界通知：「X 国掀起了 Y 风尚」。

### 4.2 风尚的扩散特性（和历史潮流的区别）

| 项目 | 历史潮流 | 玩家风尚 |
|---|---|---|
| 走廊加成 | 有 | 无 |
| 影响力加成 | 无 | 发源国是大国，或在所在市场占主导地位时 π ×1.3 |
| 出口加成 | 无 | 发源国是这种商品的出口地时，本国商人份额产生的常驻接触率 ×1.5（按 19 的商人常驻规则，不按商品贸易量） |
| 寿命 | 按 11/12 的共享窗口与交接，总计不超过 100 年 | 完整传播建议 30–60 年、硬上限 80 年，交接后总计不超过 100 年；时尚疲劳按本轮共享波龄提前 30%，不用地方 peak/采纳时间 |
| 留存 | 商品固定 ρ/λ 与国家政策决定当前 x 的留存 | 在窗口内，基准 λ ×1.3（高保留商品也可退潮）；结束按 02 的共享生命周期处理同一 x，不保存习俗概率、地方依赖或第二份强度 |

### 4.3 风尚的战略玩法

| 玩法 | 说明 |
|---|---|
| **为垄断商品造需求** | 你拥有世界上大部分琥珀产地 → 培育琥珀风尚 → 通过「赠礼外交」和「风尚输出」推向大国 → 琥珀价格上涨，你的产地繁荣 |
| **抢占先机** | 历史上咖啡从也门开始。如果你是威尼斯，掌握了红海贸易，可以提前在欧洲点燃咖啡热，改写传播路线 |
| **文化软实力** | 风尚的发源国在风尚流行期间获得威望加成（按全世界成员数计算，有上限） |
| **反制** | 敌国在向你输出风尚时，你可以用禁运、禁奢令、道德运动抵制，或者「引导替代」把需求转向本国能生产的商品 |

## 5. AI 的风尚创造

| 规则 | 值 |
|---|---|
| 发起条件 | 本国是某种商品的主要出口方（P0 核实可读的出口或产量数据），该商品在本国市场供过于求、价格低于基准价 0.85 倍，并且国库充裕 |
| 频率 | 全世界每个时代最多 2–3 个 AI 风尚；每个 AI 每 50 年最多 1 次 |
| 开关 | CMF 可以单独关闭 AI 风尚，只保留玩家风尚 |
| 理由 | AI 风尚让世界有变化，但不能多到让玩家觉得「满世界都是风尚」 |

## 6. 平衡护栏

1. **风尚不能凭空创造购买力**：被痴迷的国家把预算从其他商品挪过来，收入=支出的闭合不变。
2. **强度上限**：地方 x∈[0,100]，玩家风尚的 h 和历史潮流相同；国家强度仅由地方 x 聚合，不给玩家独立强度或额外数值优势。
3. **不能对自己无限叠加**：同一种商品只有一个局势、一个修正。
4. **冷却和名额**：15 年冷却，每国一次只能培育一个；世界额外最多 1 个通用商品传播层，多国同商品共享。11长窗基线历史层峰值12/13、含通用层13/14；12百年候选分别为10/11和11/12。AI不另占第二个通用层，旧4/5总上限作废。
5. **零需求阶层不受影响**：如果这种商品只有贵族有需求（比如大象），风尚只影响贵族，文案如实说明。
