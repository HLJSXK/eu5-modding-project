# 02 单变量地点扩散模型

日期：2026-10-19。状态：现行设计规格，尚未实施 EU5 玩法脚本。

**用户硬约束：每个地点×商品只允许一个持久浮点数 `x`。接触度与依赖度从模型中删除。** 唯一放宽是调度用的暂存队列指针 q（方案A，见第4节），只在排队期间存在。 本文取代此前的多状态方程、国家独立传播状态及地点量化事件积分方案。全部历史商品与通用风尚使用同一核心；排期继续见 11、12，实现边界见 10。

## 1. 唯一的地点状态

`x[l,g] ∈ [0,100]` 表示地点 l 对商品 g 的当前痴迷强度。未建立变量视为零，实际脚本读取的缺省/保护写法在 P0 核实。

| 项目 | 规则 |
|---|---|
| 持久化 | 每个地点每种商品只有 x 一个浮点值 |
| 零值 | 从未接触与完全退潮都可为零，不再区分消费历史 |
| 未采纳 | `0 < x < 1`，表示弱影响；仍是同一个强度，不另存接触度 |
| 成员 | 任一所属地点 `x ≥ 1` 的国家参与当轮局势 |
| 新奇/风尚/狂热/痴迷 | 直接由 x 的 1、20、45、70 门槛派生，不存阶段副本 |
| 习俗 | 波次停止重计算时原地保留 x，不复制第二份快照 |
| 调度位置 | 排队期间另有一个地点引用 q（队列中的下一个；队尾指向自身），出队即删除；不参与公式 |

这里的“一变量”是每个地点×商品，不是将所有商品混成一个数字。地点的原生所有者、市场、文化等引擎已有信息仍可读取；不新增相同信息的地点缓存。

**不允许新增**：另一强度副本、独立抵制度、峰值、首见日期、固定随机偏移、最近更新时间、斜率、到期时间、prev指针、独立的queued标志、排队以外仍保留的指针、来源数、累计压力、逐边已发送贡献、人口权重或经济贡献快照。把这些值放进全局按地点键的表，同样违反约束。不得通过浮点小数位打包额外状态。

## 2. 更新公式：保留自身，加上邻居影响

一次逻辑轮内，对候选地点 v：

```text
old = x[v,g]
y = rho[g,c] × old
对每个实际相连的来源 u：
    y += p[u,v,g] × x[u,g]
y += hub_input[v,g]
new = clamp(y, 0, 100)
若 new < epsilon：new = 0
若 |new − old| > delta，或 new = 0 而 old ≠ 0：
    x[v,g] = new；自身与邻居入队
否则：不写回、不入队（x 保持 old）
```

`old、y、new` 是执行当前任务时的临时表达式值，不是额外地点变量，也不为每个地点存一行工作表。任务结束后仅 x 留存。`epsilon` 是共享的小值归零参数，不能用低于引擎有效精度的尾数制造无限衰退任务。

- `rho`：当前商品/国家政策下的保留率，通常在 [0,1]；固定衰退率可写成 `lambda = 1-rho`，二者不是两份地点状态。
- `p`：当前边上的传播系数。商品传染力、走廊、文化宗教亲和、政策与供货均作为共享配置或当前输入影响 p/rho。事件/行动中的国家风尚影响力π是共享的来源影响乘数，可用于p或长程入口，不是地方变量。
- `hub_input`：贸易、宫廷、宗教、历史事件等经有限入口带来的当轮输入。只在入口处理，不对全世界有货地点自动广播；不持久化为地方压力。
- 直接读取邻居 x，不缓存另一个传播强度，不保存每边旧贡献。
- 所有系数按一次实际服务的逻辑步长定义，不能把全年系数不经换算用于每月。初始候选采用按月错峰服务；预算不足时暂停该候选的逻辑推进，不通过地点时间戳补算经过的月份。服务延迟属于模型误差，必须记录。

若没有任何种子、入口与正强度邻居，零强度不会凭空上升。单一来源对目标的贡献就是 `p × x_source`。多个来源先求和，再做一次本地限幅。

`rho + sum(p)` 可以大于 1，允许已有热度在网络中放大，100 的上限阻止无限增长；这不是守恒物质输运。若总增益低于 1、没有外部输入，热度会衰退。具体强弱须用新模型重新校准，不能沿用旧多状态参数。

### 2.1 变化容差 δ = 0.1（2026-10-19 采纳）

`delta` 是全商品共享的变化容差，取 **0.1**（x 的 0–100 刻度上的绝对值）。一次服务算出的变化不超过 δ 时视为"没变"：不写回、不入队，该地点休眠，直到邻居变化超过 δ 或外部输入把它重新入队。归零（new = 0 而 old ≠ 0）总是写回。事件、行动、播种等外部直接写 x 不受 δ 限制，写后照常入队。

δ 不是新状态，只改变"何时算变了"。它带来的效果与代价（[delta_adoption_study.py](experiments/delta_adoption_study.py)，13,572 节点网格，方案A计价）：

| 情景 | δ = 0 | δ = 0.1 | 说明 |
|---|---:|---:|---|
| 增长期总 U | 5,880 万 | 2,897 万（−51%） | 前沿外的极小 x 拖尾不再传播，活跃带收窄，峰值活跃 3,565 → 1,664 |
| 增长期轮数 | 677 | 780（+15%） | 前沿变慢；13,384/13,572 地点停在 99.9–100 而非恰好 100 |
| 强控制半区（增益 0.974）总 U | 9,091 万 | 1,672 万（−82%） | 边界收敛后锁死，第 780 轮全部休眠 |
| 全境疲劳退潮（增益 0.98）总 U | 5.46 亿 | 1.03 亿（−81%） | **但退潮在 x ≈ 2.6–4.9 处冻结，全部地点仍是成员** |

**冻结下限**：没有外部变化时，衰退每步的变化是 (1 − G)·x（G 为有效增益，孤立地点 G = ρ）。当 (1 − G)·x ≤ δ 时衰退停止，x 停在约 δ / (1 − G)。按 03 的基准保留率、每月一步、孤立地点计：

| 商品 | ρ₀ | 冻结下限 |
|---|---:|---:|
| books、paper | 0.998 | 50 |
| tobacco | 0.995 | 20 |
| coffee、tea、sugar、liquor、chili、incense、beeswax | 0.99 | 10 |
| wine、beer、medicaments | 0.985 | 6.7 |
| cocoa、pepper、cloves、saffron | 0.98 | 5 |
| staple | 0.975 | 4 |
| glass、furniture | 0.97 | 3.3 |
| horses、camels、elephants | 0.965 | 2.9 |
| porcelain、珍宝类 | 0.96 | 2.5 |
| lacquerware、fur | 0.955 | 2.2 |
| fine_cloth | 0.95 | 2 |

有邻居输入时 G 更大，下限更高。所有下限都 ≥ 1，所以**仅靠逐节点衰退，任何商品的退潮都不会让地点退出成员**。因此现行方案**不用逐节点衰退做退潮**，而用第 8 节的国家级时钟：退潮期的衰减由国家×商品共享因子 S_c 承担，不经过 δ，能退到零或定格为习俗。曾比较过的其他做法（退潮期年度步长：下限 δ/(1−G¹²)，ρ=0.99 约 0.88，但 books/paper 仍约 4.2；全图共享一个 S：成本最低但全球同时退潮）保留在 13 页面与实验对比项中。

## 3. 一变量约束对玩法的含义

| 原需求 | 现行表达 |
|---|---|
| 初步听闻、随后采纳 | 小 x 积累并跨越 1；没有另一条熟悉程度轨迹 |
| 成瘾商品留存久 | 商品固定 rho 较高，断供或禁令时衰退较慢 |
| 时尚自然退潮 | 国家级时钟：每国首个地点成为成员后保持 T 个月，再整国按共享因子衰退（第 8 节）；时钟存在国家×商品层 |
| 禁令与道德运动 | 国家/商品政策改变 rho、p 或入口条件；无地方抵制度变量 |
| 历史传入、赠礼、宣传 | 给有限入口直接增加小量 x，或暂改共享系数 |
| 习俗保留 | 商品级共享习俗保留率 κ：退潮结束时整国定格为 κ×x，不再计算；κ≈0 的商品退到零 |
| 先占效应 | 从当前其他商品 x 或国家聚合计算；不另存地点先占历史 |

**明确的取舍**：两个当前 x 相同、消费历史不同的地点，在相同外部条件下后续演化相同。独立依赖记忆、地方峰值/首见时间、稳定个体随机差异不再存在。不能用隐藏字段恢复这些差异。

## 4. 稀疏候选：侵入式 FIFO（方案A）

2026-10-19 决定：原生集合/列表的去重、游标、交换复杂度无从确认，候选不再用 `current/next` 原生集合，改为每商品一条侵入式 FIFO 队列，只用变量读写实现。

| 位置 | 内容 |
|---|---|
| 地点×商品 | q：排队期间存在，值为队列中下一个地点；队尾的 q 指向自身。q 存在 ⇔ 该地点在排队 |
| 商品 | head、tail、length、round_remaining（本逻辑轮还剩多少个待服务）、round |

- 入队 push(v)：若 v 已有 q，只读一次即返回（去重）；否则写 v.q=v，原队尾.q=v，tail=v，length+1。
- 出队 pop：取 head，若 length=1 则清空 head/tail，否则 head=head.q；删除该地点的 q，length−1。length 计数决定队列是否为空，不需要比较地点引用。
- 逻辑轮：开始时 round_remaining=length，服务这么多个即为一轮。本轮新入队的都排在它们后面，所以新候选下一轮才处理，不会同月递归。
- 播种、政策/拓扑变化把相关地点及受影响的目标入队。来源已有x且播种后数值没变时，也要显式入队新路线目标。
- 更新后 |Δx| > δ：把自己和受影响的邻居入队；仍在排队的邻居不重复入队，它被服务时会读到新值，因此不会产生"已读到新值却又重算一次"的空跑。
- |Δx| ≤ δ：不写回、不入队，q 已在出队时删除；邻居或外部条件后续变化仍可再次唤醒。
- 稳定内部地点因没有变化退出队列；零且无输入地区不被发现、不参加状态计算。

前沿和内部动态不是额外地点状态。没有来源计数或压力缓存；多个来源的正确结果由服务目标时读取全部实际邻边求和得到。q 只表示调度位置，不得附带 x、阶段、时间或贡献，也不能在出队后保留。

与集合版相比：同一组入队会因"出队后再入队排到队尾"而产生略有不同的异步顺序，这属于第5节已承认的顺序误差，不是错误。参考实现见 [queue_pointer_scheduler.py](experiments/queue_pointer_scheduler.py)。

## 5. 原地异步更新

不维护每地点的 `x_next`。本轮按共享顺序逐节点读取当前已提交 x，立即写回，因此结果可能受到服务顺序影响。新入队的地点排在本轮剩余部分之后，不能同月递归扩散；本轮仍在排队的地点会读到本轮较早的结果。

这不是严格同步的双缓冲扩散。不同顺序、月份预算和轮转方式对速度的影响要测试并进入历史校准。每商品只有 head/tail/length/round_remaining 等共享计数，不允许为消除顺序误差加回逐地点上一轮值、时间戳或版本。

## 6. 国家聚合、地图与需求

地图直接读取 x 并派生颜色/阶段。国家成员和代表强度是地方 x 的聚合，不再运行另一套国家传播状态。

国家需求可用国家聚合 `X[c,g]`：`H = 1 + h_g × X/100`；痴迷、外部因子和替代仍按 01 的 B×H×M 组合，零基准需求不会被创造。

国家聚合允许国家/商品缓存与分片准备任务，但不允许保存逐地点的旧权重、旧所有者或旧贡献。权重/所有权变化后，若无法仅凭当前任务信息正确提交差值，应将相关国家置脏，进行计费的有界重聚合；不能假装增量聚合永远免费。自然 SOL solve 消费已准备好的国家快照，不因传播额外触发全量求解。

## 7. 成本与验收

一地点服务必须读取 d 条实际邻边，公式算术为 O(d)，不是此前的完整多状态服务。零邻接输入的单步仅保留/衰退、限幅和写回。x 改变时另付 O(d) 的入队；目标只入队，不当场递归更新。每次入队/出队是常数次变量读写，不依赖原生容器复杂度。

更新节点、边枚举、入队出队、入口发现、政策唤醒、聚合、清理都计入全商品共享月预算。此前 128/200 U、状态总变差、依赖阈值事件率等旧估算撤下，不作为本模型的成本证明。调度参考实现见 [queue_pointer_scheduler.py](experiments/queue_pointer_scheduler.py) 和 [结果](experiments/queue_pointer_scheduler_results.json)；完整参考实现是 [tools/obsession_sim](../../../tools/obsession_sim/README.md)；集合版对照已归档为 [archive/single_state_diffusion.py](experiments/archive/single_state_diffusion.py)。它们只演示模型与抽象计数，不证明实机性能。

验收优先检查：δ = 0.1 下的前沿速度与锁边、国家时钟的加入/开始退潮/结束月份与由内向外的退潮顺序、每地点商品恰好一个持久浮点字段、q 只在排队期间存在且队列遍历一致、无旁路影子状态、零输入不发热、多来源、退潮与复燃、稳定节点休眠、外部变化唤醒、服务顺序影响、截止日行为、存读档和月度50万预算的真实展开成本。

## 8. 退潮：国家级时钟（2026-10-19 基准，T = 240）

退潮不再由全商品统一的波龄触发，而是跟随各国实际被传到的先后。

| 位置 | 新增的共享状态（每国家×商品） |
|---|---|
| 加入月份 J_c | 本国第一个地点 x 由 <1 变为 ≥1 的那次更新写入；只写一次 |
| 衰退标志、结束标志 | 布尔 |
| 衰减因子 S_c | 浮点，进入退潮时置 1 |

每月对已加入、未结束的国家：

```text
若未在退潮且 当前月 ≥ J_c + T：进入退潮，S_c = 1
若在退潮：S_c ← g × S_c
    习俗保留率 κ = 0：S_c < 0.1 时遍历本国地点写回 x ← x × S_c（小于 ε 归零），S_c = 1；全部为零则结束
    习俗保留率 κ > 0：S_c < 0.01 时遍历本国地点写回 x ← x × (κ + (1−κ)·S_c)，结束（定格为习俗）
```

读取规则：本国在退潮时，任何读者（邻居服务、地图、国家聚合、事件条件）都使用 `x_eff = x × S_c`（κ > 0 时为 `x × (κ + (1−κ)·S_c)`）。退潮中的地点不接收输入、不入队；邻居对它的入队请求只做一次所有者检查就被拒绝。国家聚合可以直接用 `S_c × 已存的本国和`，不需要逐地点重读。

基准参数：T = 240 月，g = 0.98/月，κ 按商品类别（03 第 2.1 节）。合成网格（13,572 地点、1,600 个平均 8.5 地点的国家）上：x ≥ 45 的环带第 360 月在 9–41 跳、第 600 月在 34–71 跳、第 840 月在 62–87 跳，中心先平静；κ = 0 时第 1,760 月全图归零，所有地点都曾是成员。单商品平均约 2.75 万 U/月，峰值 12.2 万 U 出现在增长前沿最宽时；时钟本身每月约 3 U × 活跃国家数。数据来自 [ripple_country_clock_study.py](experiments/ripple_country_clock_study.py)，现行实现是 [tools/obsession_sim](../../../tools/obsession_sim/README.md)。

已知局限：退潮粒度是国家。大国首个地点成为成员后 T 个月全国一起退潮，前沿尚未到达的部分不会再被点燃；真实地图上用模拟包的 `ever_member` 和里程碑检查覆盖率，必要时改按省/区域分组（对应作用域能否挂变量是 P0）。无主地点需要指定到某个组（按市场或区域），否则不会退潮。
