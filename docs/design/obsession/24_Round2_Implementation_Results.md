# 24 第二轮离线实现与拟合集结果

更新：2026-10-22（本轮始于 2026-10-21）。依据 [23 交接规格](23_Next_Round_Handoff.md)。本文随本轮工作更新；当前为**代码回归、49 候选/65 次选参及 240 次诊断均已完成；模型未达计划要求**。S/H×R 的拟合集 2×容差命中率均仅 4%，次序正确率 45.05%，不能宣称 L2/L3。下列本轮结果全部为 fit_only；L1 全集与留出正式判分由审计方执行。此前误读旧全集汇总并作废批次的记录单独披露。

## 输入与修订边界

两局观察者档案均为 1338.4.1–1840.4.1，各 52 档：`c681faf6-91c6-45a9-bde4-9d8c22cd321e` 启用 SOL，`9d1f3b46-96b1-4b41-b187-64b68248ff7e` 未启用 SOL。SOL 局提供近开局 R 市场边界与商人份额先验；原版局不参与这两项估计。两局的条件式检验均在选参提交后执行，不据此重新选参。

1338–1630 年的 31 档 SOL 存档中，无该市场有人口领地的外国正份额共 **20,439** 条，中位数 **0.000658154797523444**，样本哈希 `0ff9fab00491447b847b76458f7160e86b3c727597a1d83f8391e075e77f69c1`。R 的每个有出处社区直接取这个共同份额；O 保留真实份额，排除领土所有者后不重新归一化。

原始 `world_facts_v2.json` 实际没有交接说明提到的 `am_` 组。本轮保留原文件，生成含 **1,471** 条事实的 `world_facts.json`：补入 28 条美洲政治事实和旧 Hispaniola 记录，删除一条仅在 1837 年才开始、没有有效月份的记录。事实均用 `goods: "all"`；商品消费不作为世界输入。东亚、印度洋/东亚常驻及其余列明缺项按用户决定留到下一轮。

用户明确批准两项修订，并要求最终报告指出：

1. `previous_owner_tags` 在事实生效前一月筛选一次，随后固定。否则前任记录在交接年失效后，重建状态会退回 1337，后继记录失去匹配对象。新国家身份先于当月领土记录建立。
2. 删除与自身史料地域描述矛盾的前任条件，逐条公开。典型错误是 1490 年比贾普尔的前任却写成后世马拉塔，以及波斯后继政权一直要求前任为 1337 年小国标签。

共 **73 项输入修订**：66 项前任筛选修复、5 项日期/月精度修复、1 项范围排除、1 项最大一个月的离散化修复。完整 before/after、原因和原始源文件哈希见 [`world_facts_amendments.json`](../../../tools/obsession_sim/world_facts_amendments.json)。修订发生在任何本轮传播结果之前；正式 W-A/W-B 世界状态在种子 0–29 的检查中均无零影响事实。

以下没有用邻近地点代替：詹姆斯敦和萨尔瓦多尚未核实到可靠的地图键；圣克里斯托弗的英法分区无法用一个不可分割地点的单一所有者表示。它们列在 `unmapped_requested_sites`。伯南布哥和里约是独立有出处的殖民领地，不能声称补全了萨尔瓦多。`spanish_hispaniola` 保留单一里程碑可疑标记。

## 实现与固定值

J1–J12 均有回归覆盖：未到达的排序按 +∞，双未到达算错；`tea_0` 从结果目标移除；K1 排除有领土的商人，K5 只认接触/回流/事件，K4 仅同商品输入混淆；O 的不发生窗口缩短十年；事件效果独立即时重验；爆发数取封顶前候选；E_gap 分商品且无合格月为未知；咖啡发源集等待首个国家到阶段 2；评分分母不依赖到达的 W-C 祖先；预算延迟和放弃事件进入汇总。

领地回流使用本国在首都市场以外、x≥20 的人口占全国人口的比例，乘本国固定亲和并除以先占屏障。商人常驻是独立通道，正反向都排除在目标市场有有人口领地的国家，自接触不成立。共同年度风险率依原控制器转为月概率 `1-exp(-hazard/12)`；人口/市场聚合按固定 12 片更新，其滞后属于披露的工程限制。

2026-10-22 用户明确确认：年度量是允许大于 1 的**风险率**。23 第 3 节原称“每年触发概率”、第 4 节称“频率”的冲突已作规范修订。代码与扫描前冻结配置从始至终使用上述月换算，此次澄清没有根据结果改变公式。

用户确认年度入口公式限定于允许增长的时期：退潮期继续拒收 +7，同时固定退潮时钟照常推进。1337 年已符合资格的常驻或领地入口从开局参加抽样，无须等待一条新事实。零人口热区不产生领地回流；婚姻、常驻和国教元数据变化保留尚未完成的物理聚合，物理人口/领地/首都等变化才重建它。

只拟合 `p、rho、lambda_contact、lambda_ownership、preemption、internal_rate` 六项；拟合集 A/B 为 25 项，满足 6≤25/3。另公开 66 个非拟合数字及来源类别。δ=.01、θ=20、入口剂量=7、保持期=240 月、退潮=.98/月、咖啡/茶 κ=.3、烟草 κ=.4；亲和全开，酒为 C 级恒定 x=30。道路加成删除，所有邻接和海峡边权为 1。宗教正当化读取导出的宗教领袖声明状态。

旧全量结果已封存，本轮不解封。23 中 0.747 的旧拟合集排序值仅作为已提供基线引用，不宣称重新读取封存缓存得到该值。边界口径由合成回归验证，新模型另跑拟合集。

## 选参与诊断协议

扫描前提交 `experiments/round2_fit_protocol.json`。当前 V3 候选为 49 个固定随机种子 2026102103 的六维 Latin 分层点；先跑 S×R 种子 0，前四组再跑种子 1–4。先约束违反和预算，再最大化拟合年份、次序与 K 条的最差标准化比值，完整排序规则以协议为准。

所有候选和失败都保留。上一轮审计已发现至少 129 组候选，本轮不能只报告新协议下的数字而抹去旧批次。选定文件与日志先提交，再交审计方；留出和全集矩阵由审计方运行。

第一份协议在提交 `1c2e5387` 后启动了 49 组候选，但在任何一组完成、任何成绩被查看之前中止。静态复查发现：移除烟草闸门后，负面约束没有持续记住过去的跨洋所有权；联姻/常驻等元数据更新也不应清空尚未完成的人口聚合。已补回归并重新提交运行时，普通扫描仅保存统计、回放运行才保存世界帧。原协议及中止记录在 `round2_fit_protocol_v1_aborted.json`、`round2_aborted_batches.json`。

**隔离事件与作废记录：**2026-10-21 18:27（北京时间，日志为 10:27 UTC），在核对 `tools/obsession_sim/README.md` 的折叠旧流程时，误读到上一轮 S×R 全集顺序汇总 `p_order=0.5376`。没有读取留出地区的到达值；该批次没有任何一组完成。依 23 §7，立即终止并作废 V2，归档为 `round2_fit_protocol_v2_invalidated.json`，从 README 删除旧汇总。V3 更换生成种子，49 组向量与旧表无重合，范围和排序不因这个值改变，固定输入和模拟机制不改。两批中止/作废各登记 49 组次，均完成 0 组；本轮累计登记 **147 组次、98 个独立向量**，有效选参仍为 V3 的 49 组候选及 65 次运行。选参日志保留所有批次，不能将作废批次计作有效验证。

## 可视化与隔离

工作台只编辑六个参数，固定值另列；显示队列延迟、预算放弃事件、分商品 E_gap，汇总与运行详情均能切换两局观察者并保留 SOL/原版标签。通道消融及双倍预算单独列成对照表；部分结果明确标注实际次数，里程碑显示冻结地域筛选及强度门槛。自包含 HTML 无损压缩嵌入全部报告数据，原始 JSON 同时保留。O 详情明确为非史实世界，不展示历史年份对比。报告没有冻结有效性字段时只显示哈希，不误报输入已变化。完整矩阵入口交给审计方。R 拟合集回放在写文件前清除留出地点强度、所有到达列、时钟和相应输入记录；节点统计也重算为非留出范围，含留出的范围不生成采纳曲线。

## 工程验收

交付版本通过 **170 项相关 Python 测试及 33 项子测试、两组 Node 工作台/回放检查**；种子 0–29 的世界输入审计全部通过。测试范围为 `tools/obsession_sim` 全部及存档解析、关系、世界导出和归档四组直接依赖。无关的 `demand_analysis` 仍有三项既有失败记录，本轮未处理，不宣称全仓测试通过。报告器另有回归保证：拟合集差项不被当成 L1 全集结论，双倍预算否决只作用于 L2/L3。选参前的性能核验仅用空目标表与 120 个月窗口，没有读取历史目标成绩。

U 是用于估算脚本成本的手设加权计费单位，不是 CPU 指令数。48 万 U 是共同月预算，约 500 年一局的预算上限为 28.8 亿 U；离线世界重建、K/区域判分、来源诊断及输出还另有 Python 开销。因此离线壁钟耗时不能直接换算成实机月耗时。诊断曾应用户要求暂停并恢复，部分运行的壁钟耗时包含暂停时间，不用于选参或性能比较。

## 结果解释与本轮停止边界

- 就 S×R 的 30 次结果而言，年份差距同时有过早和过晚：日本茶道目标中位为 1340 年，早于 1580 年目标；欧洲茶的拟合目标全部未到达。咖啡只在麦加达到 A/B 年份容差，叙利亚和伊朗显著偏晚，其余主要欧洲目标未到达。烟草在伊比利亚、法国、低地的区域采纳亦明显偏晚。
- 商人常驻在当前 R 输入下很弱：每次五百年运行的咖啡接触次数中位只有 2 次，关闭后主要汇总不变。领地回流承担了更多传播；关闭后拟合次序从 45.05% 降为 8.79%。关闭领地后 K 升为 100%，同时案例构成改变、年份次序变差，不能当作模型改善。
- 去酒把 2×容差命中率从 4% 提到 8%，关闭全部先占也只有 8%；后者 K 降为 0。酒背景和先占不是本轮全部差距的充分解释。同市场带动关闭后 2×命中不变，但单倍容差命中由 4% 降为 0。
- 双倍预算的年份位移检查通过，但 K 中位由 50% 降为 0，K2 从基线十次全通过变为十次全失败。唯一超容差位移是西非烟草（tobacco_9）：基线十次中位未到达，双倍预算中位约 1790.9 年，仍远晚于 1625±30 年目标。只能说规定的年份敏感性门槛未触发，不能据此认定条件规律对预算稳健。
- 两局 O 都出现 K1/K5 的系统性失败；G 的 K6 也每次至少有失败案例。原版局的健全性失败均涉及咖啡百年内向发源国之外传播不足，S 为 9/30，G 为 8/30。茶的合格事件间隔在两局 G 中均超过 50 年；原版局封顶前候选爆发 B_max=4，也超过要求的 3。事件现场条件误触发数为 0，落点有据率均为 100%，这些工程质量项不能抵消传播差项。

东亚、印度洋/东亚常驻及其余已列时间线缺项仍是输入限制；本轮没有通过补入这些事实做对照，不能把全部差距归因于缺项。R 还使用 1337 人口和近开局市场边界，O 按十年档阶梯保持；聚合为 12 片更新。上述近似均需在解释时保留。

用户已选择“先看完整诊断，再决定”。本轮到此固定结果，不继续扩大搜索，也不按年份成绩改退潮、剂量、亲和或判分定义。下一轮应先审阅输入覆盖、目标地域代理、K 案例汇总方式和时钟/入口的一致性，再决定搜索或设计修订；任何新参数表仍需预注册。
