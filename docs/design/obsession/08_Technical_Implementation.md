## 3. 文件布局、数据与生成器

拟由 `scripts/gen_sol_obsession.py` 读 `data/obsession/` 生成 stable/standalone 的局势、scripted effects/triggers/values、走廊、行动及 AI 列表、价格、on_action、事件、地图、GUI、修正和双语本地化，并接入既有替代计算之前。文件是实施计划，不表示脚本已经存在。

| 数据 | 内容 |
|---|---|
| goods.yaml | 主题色、固定商品抗性、共享 p/rho/lambda、需求映射 |
| affinity.yaml | 商品 × 文化/宗教/气候静态系数，不存地方亲和度状态 |
| situations.yaml | 发源条件、共享波次、初始 x、里程碑 |
| corridors.yaml | 静态走廊和共享通道 |
| events.yaml / actions.yaml | 有界 x 种子或有期限共享系数变化、国家事件冷却与 AI |
| params.yaml | 极小值阈值 epsilon、变化容差 delta = 0.1、国家时钟 T = 240 与退潮因子 g = 0.98、各类别习俗保留率 κ、服务预算、误差与延迟验收 |

Python 参考实现是共享模拟包 `tools/obsession_sim`（方案A + δ + 国家时钟，含真实地图图数据接口与历史里程碑校准），生成脚本须与它使用同一公式；旧 E/D 或地方缓存版本先替换，不能作为新模型正确性依据。新 Python 脚本按 CLAUDE.md 配置 stdout UTF-8。

## 4. 持久状态约束

| 作用域 | 允许的数据 |
|---|---|
| 地点 × 商品 | 一个 x ∈ [0,100]，零可由未设置表示 |
| 地点 × 商品（暂存） | 排队期间的 q：下一个地点引用，队尾指向自身；出队即删除 |
| 商品 | 队列 head/tail/length/round_remaining/round、共享波次 phase/version/起止/发源 |
| 国家 × 商品 | 当前地点 x 的聚合与经济提交总量、共享 p/rho/lambda 政策、事件冷却；国家时钟的加入月份、退潮标志、结束标志、衰减因子 S_c |
| 市场 × 商品 | 共享供货、贸易入口及共享系数，不含地点键压力表 |
| 局势/国家 | 有限世界统计、事件日志、国家培育进度和当前排名 |

**禁止**地方 E/D/R、peak、seed 标志、since/last_update、独立 queued 标志、prev 指针、出队后仍保留的 q、qI/qSignal、pressure、sent、地方版本/截止日期/旧贡献或任何等价缓存。移动到全局地点键表、地点数组、国家内部地点映射、修正或地方事件定时器，同样禁止。q 只放下一个地点引用，不附带 x、阶段、时间或贡献。

调用内可临时读取旧 x、算新 x、求差和比较阈值，结束即销毁。跨月保留每地“临时量”仍属于持久状态，禁止。

## 5. 传播与候选推进

```text
new_x = clip(rho * x + sum(p_uv * x_u) + hub_input, 0, 100)
极小 new_x 归零
|new_x − x| ≤ delta (0.1) 且未归零：不写回、不入队
```

p/rho/hub 的参数按商品、国家、市场共享，或从当前引擎状态与静态地理求得。lambda 表达共享退潮政策并作用于 rho 等输入，不建地方衰退时钟。阶段直接比较 1/20/45/70；0 < x < 1 为未采纳前沿，没有独立接触度。

每商品一条侵入式 FIFO（见 10 第 3 节）。逻辑轮开始时记 round_remaining = length，只服务这么多个并原地写 x。值改变则 push 自身和相邻目标，已在排队的目标不重复入队；值不变则不入队，可在邻居或共享输入变化后重新唤醒。新入队的排在本轮之后。跨月只保留队列与商品计数。

稳定内部可以休眠，持续衰退或变化的内部必须保留自身。原地读取的邻居可能已更新，因此这是顺序相关的异步迭代，不是同步月度积分。跨月延后不能增设 last_update 追赶。共享政策/供货改变可能唤醒原本稳定的内部，需按国家/市场分片发现并入队，遍历、入队及延迟都计费。

事件直接增加选定地点 x 或暂改国家/市场共享系数，不留地方 seed 标志。新波复用已有 x，在允许入口唤醒，不能复制一套地方状态。退潮由国家级时钟承担（02 第 8 节）：每月对已加入、未结束的国家更新 S_c，读取一律用 x_eff；退潮中的地点不服务、不接收输入。结束时 κ×x 作为习俗原地保留，之后不再计算；δ 造成的冻结残留不能当作习俗。

## 6. 国家经济、时序与性能

地点扩散与需求作用层级分开。首版从地点 x 聚合国家商品需求，再接现有国家修正、替代与 SOL solver；国家聚合不是第二套传播模型。只放大已有阶层需求，零基础需求不凭空产生需求。

一次更新可用临时旧/新 x 更新国家汇总。但人口权重、所有者、市场变化后，单靠该差值可能不足以保证正确；须共享重建任务读取真实状态并分片扫描，不能存每地旧贡献。征服者继承领土当前 x，旧国家政策不会变成地方永久记忆。经济提交在相应替代/solver 前执行，未完成的聚合需标明共享批次完成度。

成本包括候选访问、去重/交换、邻居读取、x 更新、共享输入、国家聚合、修正回读提交、唤醒发现、事件和退场清理。地图/GUI 与引擎需求重算另测。50 万的单位须先定义，再按生成脚本逐原语计费；旧 48 万 U 抽象预算不能直接移用。

不得每月全域地点 × 商品积分。预算用尽只保留队列和商品计数，报告积压、最大等待与一轮完成时间。短窗层年减少不等于运算同比下降；操作封顶也不等于误差/体验通过。

实机测长窗 13/14、短窗 11/12 及 17 商品；覆盖全域政策变化、所有权/人口变化、读档、交接清理和累积习俗成本。脚本原语展开与实机耗时未测前，不宣称 50 万验收通过。

## 7. 需求层级与兼容

Tier A 使用国家商品修正，输入为地点 x 的允许聚合，首版采用。Tier B 研究 pop scope 商品脚本值读取地点 x，需验证语法、重算成本与 SOL 一致记账；不增地方状态。

stable/standalone 同内容；PP 不纳入 victuals 和零需求 lumber；M&T 使用最终商品数量/价格；JTG 新商品与既有热潮按兼容范围保留。外部商品因子仍正确组合，外部压至零时不复活。CMF/旧存档关闭清理须分片计费，关闭只移除本系统经济效果。

## 8. 与原版事件衔接

原版 `events/economy/prices.txt` 的叙事与贸易体系保留，仅替换上线商品的重复需求效果。用真实入口的有界 x 种子或国家/市场共享系数变化，重新校准幅度；旧 E +25 不等价于 x +25。介绍新商品通常先给 0 < x < 1，再由同一核心采纳；不能直接赋予地区采纳来冒充传播里程碑。

| 事件 | 衔接 |
|---|---|
| prices.1 三角贸易 | 保留贸易体系 |
| prices.2 瓷器、prices.16 印花布 | 对入口加 x 或改共享条件，随商品上线 |
| prices.5 咖啡、prices.7 茶和糖、prices.30 烟草 | 有界种子/共享参数替代旧接触度；未上线商品保留原制 |
| prices.21 日本茶道 | 改既有茶 x 或共享政策；不自动重开全球波，窗外地方唤醒计费 |
| prices.23 糖、prices.29 可可 | 随商品上线接统一接口 |

威尼斯禁咖啡馆使用真实国家政策；单事件覆盖先核实后最小修改。旧存档市场临时需求保留并说明，不自动归为地点采纳史。

## 9. 测试与验收

- 状态审计：地点 × 商品仅持久 x 与排队期间的 q；从 head 走 length 步与全部存在的 q 一一对应；存档/全局表无同等缓存。
- 数值：比较同顺序全量原地参考（同样施加 δ = 0.1）；检验 δ 下的前沿速度、锁边与退潮冻结下限；检验 0/1/20/45/70/100、清零、种子、共享参数变化、稳定内部唤醒及跨月误差。
- 经济：组合幂等、零需求、所有权/人口变更后的聚合、替代/solver 顺序；没有地方 sent 仍须记账正确。
- 生命周期：百年实际期限、同商品复用 x、休眠保留强度、有界唤醒、分片清理。
- 容量：计真实入队出队与邻边枚举成本，测重复唤醒、巨大边界、全域参数变化和大量内部退潮。未实测则标“未通过性能验收”。
- 历史和 UI：保留 09 地区里程碑与 07 地图/局势/行动；无虚构地方来源、时间、依赖字段。

玩法实现后用 eu5 Python 跑离线测试及 `scripts/validate.py --changed`，GUI 实现后做中英文 renderer 与实机核对。当前文档变更不代表这些运行验证已完成。
