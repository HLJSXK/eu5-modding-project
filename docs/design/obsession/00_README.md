# SOL「痴迷」系统设计

日期：2026-10-19。分支：`substitution`。状态：设计草案与离线实验，**尚未实施玩法代码**。

## 1. 已确定的硬约束

**每个地点×商品只维护一个持久浮点数 `x∈[0,100]`。接触度、依赖度从模型中移除。** 阶段、采纳、传播和消费偏好都从当前x直接派生。

这也禁止逐地点的抵制度、峰值、首见日期、固定随机偏移、更新时间、另一份传播/经济强度、累计压力、来源计数、边贡献缓存、prev指针或单独的队列标志。不能把这些字段搬到全局按地点键的表，或打包到x的小数位。

**唯一放宽（2026-10-19，方案A）**：每个地点×商品允许一个**暂存队列指针 q**（地点引用），只在该地点排队等待服务期间存在，出队即删除；队尾指向自身。它只承载调度位置，不参与动力学，不得附带数值、阶段、时间或贡献。放宽理由：原生集合/列表的去重、游标、交换复杂度无从确认，设计尽量不依赖原生接口；q使调度器只用变量读写完成。

边界通过商品级侵入式FIFO队列维护：商品层只存head、tail、length与本轮剩余数round_remaining；政策、传播系数、保留率和波次期限保存在商品、国家或市场等共享层。具体契约见 [02](02_Spread_Model.md)，调度与存储账本见 [10](10_Location_Diffusion_Algorithm.md)。

2026-10-18的多状态方程、量化事件积分、带queued/prev的地点链表及128/200U状态服务估算已撤下。旧实验保留为历史研究，不用于证明现行模型性能。

## 2. 玩法与统一更新

- **扩散**：当前强度沿邻接、贸易和宫廷等通道传播，保留地理屏障、飞地和商品差异。
- **事件**：历史与通用事件给有限入口增加x，或改变国家/商品共享参数。
- **行动**：赞助、赠礼、禁令、消费税、专卖、本土化与节制运动等，统一作用于当前x或共享政策。
- **玩家风尚**：国家级培育入口产生一个新种子，随后使用相同单变量核心。

一次地点更新仅做：

```text
x_new = clamp(rho × x_old + Σ(p × 邻居x) + 有限入口输入, 0, 100)
```

临时计算值只在当前任务中存在，结束后只回写x。小值按共享epsilon归零。rho表达保留/衰退，p表达传播；同x、同输入的地点不再因消费历史不同而具有不同依赖性。

## 4. 架构决定

| 决定 | 规则 |
|---|---|
| 每商品一个局势键 | 同商品不同波复用x和容器，不创建重复地点状态 |
| 地方只存x（另有排队期间的q） | 阶段1/20/45/70由x派生；0<x<1为未采纳弱影响；x≥1计成员 |
| 候选边界用侵入式FIFO | 地点只在排队期间持有指针q；商品层存head/tail/length/round_remaining；不用原生集合、索引、去重或交换 |
| 普通更新按邻居拉取 | 无逐边sent或地方压力缓存；变化超过共享容差δ=0.1才写回并把自身与邻居入队；已在排队的地点不重复入队 |
| 变化容差δ=0.1 | 增长期总U约−51%、前沿慢约15%、受控边界锁死；逐节点衰退会停在δ/(1−ρ)，因此退潮不走逐节点衰退 |
| 退潮：国家级时钟（T=240） | 每国×商品在首个地点x≥1时记下加入月份，保持T=240月后整国懒衰退：S_c每月×0.98，读取x×S_c，本国不再接收输入；退潮随各国加入先后由内向外推进。可选习俗保留率κ（商品级共享参数）。无新增地点字段 |
| 参数表达商品差异 | 用p、rho、T、衰退因子、习俗保留h与国家政策，不恢复地方依赖记忆 |
| 历史与玩家统一核心 | 所有商品同样扩散、退潮、展示、经济提交；不另做事件型替代实现 |
| 每轮不超过百年 | 标称最长80年、可前开10年和收尾10年；新增种子不续期 |
| 需求仍先走Tier A | 地方x聚合为国家X，H=1+h×X/100，与外部/替代因子按B×H×M组合 |
| 原有SOL自然提交 | 只在原来的solve入口消费准备好的国家聚合，不额外触发全量solver |
| 操作额度全商品共享 | 月度目标≤500,000；候选、入口、索引、聚合、清理均计费，尚未实机验收 |

## 5. 排期与性能证据

保留全部16种历史商品。11的长窗基线标称/包络商品层年为2817/3187，含通用层峰值13/14；12的26短波候选为2074/2714和11/12，潜在商品层年减少26.4%/14.8%。这些只是时间窗口代理，不是单变量模型的运算量或耗时下降比例。

现行方案的参考实现是共享模拟包 [tools/obsession_sim](../../../tools/obsession_sim/README.md)，它与下列实验逐值一致：[queue_pointer_scheduler.py](experiments/queue_pointer_scheduler.py)（方案A的15项小图断言）、[delta_adoption_study.py](experiments/delta_adoption_study.py)（δ=0.1）、[ripple_country_clock_study.py](experiments/ripple_country_clock_study.py)（国家时钟）。合成网格（13,572地点、1,600国）上基准情景：高强度环带约每10年外推12–15跳，第1,760月全图归零；单商品平均约2.75万U/月、峰值12.2万U（来自增长前沿）。这些计数不能证明真实月度50万已经达标。地点引用变量写法、国家×商品时钟变量、所有权变化换算、真实地图最大邻接度与每节点展开成本是下一步P0；真实地图校准流程见模拟包README第5节。

## 6. 保留的限制

1. Tier A需求是国家级，地方差异通过聚合体现，多文化帝国可能被平均值稀释。
2. 痴迷不能为基础需求为零的阶层创造需求；大众化涉及基础需求与Tier B的独立研究。
3. 痴迷改变支出分配，不创造购买力，仍受SOL收入支出闭合约束。
4. 原地更新没有全图数值双缓冲，服务顺序和超载延期会影响传播速度，须在新历史校准中测量。
5. 一变量意味着不追踪独立消费史；相同x、相同输入的地点后续演化相同。
6. 退潮以国家为单位：大国首个地点成为成员后T个月全国一起退潮，前沿尚未到达的部分不会再被点燃；真实地图上须检查覆盖率，必要时改按省/区域分组。
