# 05 局势行动

状态：设计草案。本文定义玩法三「局势行动」：玩家（和 AI）在痴迷局势面板里点击的行动，用来**控制扩散速度**和**干预痴迷的影响**。行动按商品类别和本国痴迷程度开放。

引擎依据（V = `.eu5-base/reference_game_files/game/in_game/`，D = `.eu5-base/reference_official_defines/docs/`）：

- **行动的形式**：`type = situation` 的 generic action。字段见 V`common/generic_actions/readme.txt`：
  - `type`（L5）、`potential`（L7-8）、`allow`（L9）、`price` / `price_modifier`（L12-17）
  - `select_trigger`（L18-62）、`ai_tick`（L64-67）、`ai_will_do`（L72）、`effect`（L75）、`cooldown`（L76）、消息键（L118-127）
  - 原版文件中也在用的 `icon` 和 `exclusive_group`（`black_death.txt:58, 248`）
- **原版范例**：`black_death.txt:241-335` 中的 `control_the_food_market`，以及对应的撤销行动 `stop_control_the_food_market`。这一对「开启 / 撤销」行动就是本文所有持续性政策的模板。
- **价格**：定义在 `common/prices/`，例如 V`common/prices/00_hardcoded.txt:717-731`。可用字段包括 gold、scaled_gold、gold_per_pop、stability、prestige、inflation、government_power，见 `prices/readme.txt`。
- **AI 列表**：每个行动都必须登记到 `generic_action_ai_lists`，用 `potential = { can_see_situation = situation:<key> }` 做门槛（V`common/generic_action_ai_lists/black_death_list.txt:1-25`）。否则引擎会报性能警告（共享知识库 anti_pattern `generic_action_missing_ai_list`）。
- **消息类型**：每个行动都要有消息类型，以及 SETUP / LOG / MAP 本地化（anti_pattern `generic_action_missing_message_type`）。项目里已经有生成器 `scripts/gen_messagetypes.py`。
- **界面**：局势面板通过 `SituationView.GetActionGroups` 自动列出按钮（V`gui/panels/situation/common.gui:410-416, 447-471`），**不需要自己写按钮**。
- **单一商品的禁运**：引擎没有直接的效果，要用含 `ban_imports_of_<good>` 的静态修正（例如 V`main_menu/common/static_modifiers/country.txt:3084` 的 `cotton_imports_banned`）。
- **进口关税和补贴**：`set_goods_import_trade_policy = { goods modifier }`（D`effects.log:10984`）。

## 1. 行动的组织方式

### 1.1 两组

| 组 | 目的 | 典型行动 |
|---|---|---|
| **扩散控制** | 加快或减慢本国（或别国）痴迷的增长 | 皇家赞助、赠礼外交、禁奢令、全面禁令 |
| **影响干预** | 不改变或少改变流行程度，而是把痴迷的后果转化为收入、产业、稳定或声望 | 消费税、国家专卖、本土化、节制运动 |

同一组内互斥的行动用 `exclusive_group` 管理，比如「皇家赞助」和「全面禁令」不能同时生效。

### 1.2 开放条件的三个维度

1. **商品类别**（见 03 第 1 节）：比如「国家专卖」只对烟草、酒类、兴奋饮料、甜味开放；「禁奢令」只对时尚、陈设、珍宝开放。
2. **本国痴迷阶段**：阶段越高，开放的干预越多，但禁令的代价也越大。
3. **本国与商品的关系**：生产国（本国有产地）可以选择「风尚输出」；纯进口国可以选择「本土化」「进口补贴」。

### 1.3 成本的缩放

- 金钱成本用 `scaled_gold`，或者按月收入缩放，保证大小国家都有意义。
- 持续性行动用「开启 / 撤销」成对的模式：开启时加一个永久的国家修正，撤销时移除。每月的开支写在修正里（比如「宫廷赞助开支」）。
- 稳定度和威望成本写在 price 里，原版的 price 系统会自动显示在按钮的 tooltip 中。

## 2. 行动目录

列：名称 · 类别 · 本国阶段 · 效果 · 代价 · 冷却或持续。2026-10-19 起统一使用 [02](02_Spread_Model.md) 的地方单变量 x；`0<x<1` 为未采纳前沿，`x≥1` 为成员，阶段下界为 1/20/45/70。本国阶段与成本读取当前地方 x 的国家聚合 x_c；国家成员判定仍遵循国内任一地点 x≥1。政策 P1/P2/P3、传播 p 和保留/衰退系数 ρ/λ 的档位见 04 第 3 节。所有政策、费用与期限保存在国家/共享层，不能增加地方抵制、依赖、峰值、个人时间戳或影子强度。相同 x 和外部条件的地点不再因消费史而不同。

下表直接增减 x 的效果只作用于首都/已选港口等有界入口，并唤醒统一候选集合；“本国 p/λ”是国家政策系数。政策变动需要逐地发现/应用时也受共享预算约束，不能免费遍历全国。影响力 π 仅为国家传播系数的共享乘数，不是第二份地方状态。

### 2.4 行动与国家级时钟（2026-10-19）

退潮改由国家×商品的时钟承担（02 第 8 节）后，上表中作用于 λ 的国家政策同时作用于本国退潮：本国退潮因子 `g_c = 1 − (1 − g) × λ倍率`，其中 g 是商品基准因子（0.98/月）。例如节制运动 λ ×1.5 时 g_c = 0.97，退得更快；国俗 λ ×0.5 时 g_c = 0.99，退得更慢。这些都是国家层数据，不新增地点状态。以下为首轮建议，待校准：

| 行动 | 对国家时钟的作用 |
|---|---|
| B8 节制运动 | 退潮期 g_c 按 λ ×1.5；若本国仍在保持期，剩余保持期减半 |
| B11 确立为国俗 | 本国习俗保留率 κ_c = max(κ, 0.6)，g_c 按 λ ×0.5；不阻止进入退潮 |
| A6 禁奢令、A7 全面禁令 | 增长期仍按 P2/P3 压低 p、提高 λ；若本国在保持期，剩余保持期按 P2 ×0.75、P3 ×0.5 缩短 |
| A1 皇家赞助、A2 名医背书 | 不推迟本国时钟，只影响增长期的 p 与入口 |

政策只改本国的 g_c、κ_c 或剩余保持期，不改其他国家的时钟；保持期剩余量可以由“加入月份 + T − 当前月”直接推出，缩短时改写本国加入月份即可，不需要额外计时变量。

## 3. 选择目标

- 绑定局势：`select_trigger = { looking_for_a = situation target_flag = recipient visible = { situation:sol_obs_<good> = this situation_is_active = yes } }`，照搬原版黑死病行动的写法。这样一个行动定义只会出现在一个局势里。
- **生成**：约 50 个局势 × 20 个行动，手写不现实。行动由生成器按「行动模板 × 适用的商品」展开，每种商品只生成适用于它的行动，预计共 500–700 个行动定义。
  - 风险：生成的 generic action 数量很多，对 AI 列表和界面的开销需要实测。
  - 替代方案：每个行动只定义一次，用 `select_trigger` 选择局势（`visible` 里判断 recipient 是任意一个痴迷局势），然后在 effect 里根据 `scope:recipient` 判断是哪种商品。这样行动总数只有约 20 个。但 effect 中需要「从局势得到商品」：可以在每个局势 scope 上存一个变量 `sol_obs_good`，内容是商品 scope（P0 核实局势变量能否存商品 scope）。**这个方案优先**。
- 第二个目标（A3 选国家、B10 选商品）：看原版有没有多步 `select_trigger` 的先例（P0 核实）；没有的话，A3 改成从局势面板的成员列表右键发起，B10 改成固定的替代目标（比如每种商品预设一个「本土替代品」）。

## 4. AI 规则

| 行动 | AI 倾向 |
|---|---|
| 皇家赞助、风尚输出、赠礼外交 | 本国是该商品的出口地，并且国库充裕时 |
| 禁奢令、全面禁令、道德运动 | 宗教系数 < 0.7，或者教士满意度低；当前 x_c ≥45 且商品固定保留率高时大幅降低 |
| 消费税、国家专卖 | 阶段 ≥ 3 且国库紧张时 |
| 进口补贴 | 几乎不用（花钱买消费对 AI 没有意义），除非是自己的风尚的培育期 |
| 本土化、扶持本土工坊 | 阶段 ≥ 3，本国是净进口国，国库充裕 |
| 节制运动、战略储备 | 当前 x_c ≥45 且供应偏低，或有国家级断供事件记录 |
| 引导口味 | 本国能生产替代品 |
| 确立为国俗 | 当前阶段 4 且国家愿意放弃未来禁令时优先使用 |

- AI 的 `ai_tick_frequency` 设得很低（比如 90–180 天一次），因为痴迷变化缓慢。
- 用原版的效用辅助函数：`add_static_modifier_utility`、`add_estate_satisfaction_utility`（`black_death.txt:44, 175`）。
