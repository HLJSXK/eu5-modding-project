## 3. 机制修改

### 3.1 领地回流（重写）

对每个国家 C、每个商品：

```text
A_C = C 拥有、且不在 C 首都所在市场内、且 x ≥ 20 的地点人口 ÷ C 的总人口
条件：C 首都 x < 20
每年触发概率 = λ_ownership × A_C × 亲和 / (1 + 先占)
触发：C 首都 x += 7
```

- 首都所在市场内的地点不计入，避免与同市场带动重复。
- 占一大片流行区比占一个村子影响大；1337 静态所有权之外的领地变化只来自世界状态年表（R）或存档（O）。
- 与现行实现（「只要有一块 ≥20 的地就按固定频率」）不同，必须重写并补测试。

### 3.2 商人常驻（收窄）

```text
来源市场 M：人口加权 x̄_M ≥ 20
正向：外国 C 在 M 有商人份额 s > 0，且 C 在 M 没有任何有人口的地点，且 C 首都不在 M
      每年触发概率 = λ_contact × s × 亲和 / (1 + 先占)；触发：C 首都 x += 7
反向：M 的中心所有者 S 在未流行的市场 N 有商人份额 s > 0，S 在 N 没有有人口的地点，且 N 的中心所有者 ≠ S
      同一公式；触发：N 的中心地点 x += 7
```

- **R 世界**：份额只来自 `world_facts.json` 的 `residency` 事实。删除 `worlds.py:303-316` 按领土人口重算份额的逻辑，并改正 `historical_base` 与 `share_rule` 的说明。每个有记录的社区取同一份额：观察者存档 1338–1630 中，在该市场**没有领土**的外国正份额的中位数。审计时测得约 0.00066（31 档、20,439 条）；实现者重算后写入 `world_priors.json` 并记录哈希。这个数从存档量出，不按历史年份调。
- **O 世界**：读存档真实份额，排除在该市场有领土的国家。
- 反向接触必须排除自己（22 §3.3 的 bug），补测试：一国拥有两个市场中心、其中一个已流行，另一个不得收到来自自己的接触。
