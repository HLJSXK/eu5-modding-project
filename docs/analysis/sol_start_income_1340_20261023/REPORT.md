分析日期：2026-10-23。代码参照 `8fe79b380147c3f1f0a45a8bddd5b9ba9a28f9fd`。本次只分析，没有调整游戏参数。

后续用户已明确采用“各国本地购买力的全球中位数”定基准；最新计算见 [购买力中位数篮子校准](../sol_pp_median_baseline_20261023/REPORT.md)。本文件保留此前“以货币净收入中位数定篮子”的不同方案分析，两者不能混用。

## 结论

可以用全球阶层净收入中位数给四阶层的完整原价篮子定标。但这只能定义“完整供应、基准价格、储蓄调整为零时”的 0% 参照点。

如果仍使用当前 `可支配资金 / 本国在售篮子成本 - 1`，同样收入的国家会因缺货、价格、储蓄以及商品有效因子不同，看到不同购买力。仅调整四个篮子基准值，不能保证所有人均收入等于全球中位数的国家都显示四项 0%。

若要求这个条件严格成立，应使用 `本国阶层人均净收入 / 固定的开局全球同阶层收入中位数 - 1` 作为收入相对指数；商品购买力另按实际在售篮子成本计算。

## 3. 按中位收入重设篮子之后，中位收入国家会看到多少

## 4. 为什么四个基准值不够

忽略商品因子与截断，定义：

- I_cs：国家 c 阶层 s 的人均净收入。
- S_c：储蓄形成的资金乘数。
- a_cs：在售商品保留的完整原价篮子比例。
- d_cs：低价后的在售篮子成本比例。

完整原价篮子定为 M_s 后：

`购买力 + 1 = (I_cs / M_s) × S_c / (a_cs × d_cs)`

当 `I_cs = M_s` 时，结果是 `S_c / (a_cs × d_cs) - 1`，只有 `S_c = a_cs × d_cs` 才恰好为 0%。完整供应、基准价、储蓄中性时三者都是 1，当然成立；一般国家不成立。

给各国再设置不同的归一化系数，可以强行令这些国家显示 0%，但如果用同一国家的篮子成本同时归一分子与分母，本地价格、缺货的影响会抵消，指标最终回到收入相对 M 的比值。

## 5. 可实施的三个目标

| 目标 | 做法 | 0% 的含义 |
| --- | --- | --- |
| 保留商品购买力，同时有统一收入锚点 | 完整原价篮子按 M 定标，继续使用本地成本 | 中位净收入、基准价格、完整供应、储蓄中性时为 0%；本地市场更便宜时可高于 0% |
| 严格保证中位净收入国家四阶层为 0% | 显示 `I_cs / M_s - 1`，商品购买力另列 | 恰好等于固定开局收入中位数；本地缺货和价格不参与此收入指数 |
| 只要求开局全球购买力中位数为 0% | 根据开局各国 F/B 的分布校准，而不是仅根据 I 的中位数 | 世界中位购买力为 0%，不保证人均收入等于 M 的每个国家为 0% |

针对用户描述的严格条件，第二项能直接满足。若仍希望主指标反映缺货和物价，第一项具有明确的经济含义，但应接受同等收入在不同市场有不同购买力。

M 应保存为固定的开局参考值。若每年重算世界中位数，它会变成相对世界排名式指标，全球共同增长也可能被抵消。还应确定一次全世界统一刷新后的校准日，避免混用不同周年缓存。

两组系数差别明显，说明统计单位必须在修改数据前固定。居民口径和国家口径分别表达不同的“全球典型”，不能把两组数混成一个锚点。

五位小数下，保持现有所有正需求成员至少 0.00001 的最低完整篮子成本分别为：贵族 0.001625、教士 0.001100、市民 0.001425、劳工/农民 0.000625、士兵 0.000725；都低于对应居民口径 M，因此正成员下限不会使校准目标在总成本层面不可能。

但实际生成仍需同时满足完整订阅组、全部正成员、重叠商品去重、INJECT 净需求可表达及组预算约束。小数舍入后要重新核对篮子预算，0% 应明确允许的显示/数值误差；不能直接声称未舍入系数实装后精确得到 0。

若只改变四阶层的数量尺度，需要重跑替代计算、市场单位成本、地点 raw scale 与国家矩阵；不会是仅修改一个显示比例。平民子类型若共用一个缩放系数，国家人口组成又会改变其完整篮子成本；本文采用子类型分别归一以消除这个额外差异。
