## 生效规则

- 贵族：原数量 x1。
- 教士：原数量 x2。
- 平民：劳工、农民、士兵原数量统一 x4。
- 市民：以原数量 x0.6555443548387097 为近似目标，每种商品取 1—2 位有效数字，并满足可生成的净需求步长。
- 部落民、原有不消费项目和订阅组结构维持原值。

`data/target_demand.csv` 保存最终净需求，已经重生成 stable、standalone 与 PP/M&T/JTG 三个兼容目标的商品定义和内部单位消费常数。这是消费篮子数据修改，没有另加 GUI 归一化乘数。
