## 1. 方法与样本

开局样本：`1340.04.01_autosave_c681faf6-91c6-45a9-bde4-9d8c22cd321e`，1340.4.1、1.4.1。

后期样本：`SP_CAS_1406_01_23_de3601a2-b771-4e4e-a6bb-34fed262dca7`，1406.1.23、1.4.3。

对每个国家当前归属地点的保存数据，分别汇总各阶层 `liquid_funds` 为 F、`base_spending` 为 B，计算 alpha=F/B。B 已包含本地供给过滤、价格、商品有效因子和保存的精度结果，F 已包含储蓄调整。按国家等权取 alpha 的中位数 k_s。

要求相应阶层有正人口且 B>0；保留 F=0 的国家。B=0 的样本无法形成有限购买力，按面板无消费状态排除。1340 年四阶层样本数依次为 1,503、1,587、956、1,590；其中零资金国家依次为 113、61、49、37。

用当前领土的地点汇总取得覆盖完整的国家样本，避免只统计有可用旧面板缓存的部分国家。所有汇总都按完整阶层预算相除，不平均地点百分比，也不按国家人口再次加权。

静态归一化公式为：

`新购买力 = 原 alpha / k_s - 1 = (1 + 原购买力) / k_s - 1`

保持其他状态不变时，这等价于该阶层所有消费商品数量乘 k_s。**必须对 alpha 相除，不能直接对界面有符号百分比相除。** 劳工、农民、士兵统一使用平民的同一个系数，保留三类人口原有相对消费结构。

## 5. 缓存敏感性和实装边界

1340 年如果直接使用旧面板中有值的国家子集，四个系数会变成 1.434696、2.262042、0.591407、3.723955，样本数仅 1,415、1,531、913、1,533。特别是贵族，这会显著改变结论，因此不采用该子集作为世界基准。

同次旧国家求解的资金目标/基础开销，四个系数为 1.011917、2.039216、0.659596、4.057173，与本次完整地点汇总系数均相差约 0.3%—0.7%。两者支持相同的篮子调整方向与量级。

上述新百分比是**固定存档状态的归一化换算**。若直接修改 GUI 标尺，公式可以精确实现这种显示；若真正修改商品数量，替代权重、逐项截断、市场价格、税基收入、储蓄与国家求解矩阵可能随之变化，不能把本表当作运行数月后的均衡预测。候选缩放不应作为额外的每月乘数重复累乘。

1340 存档属于开局早期，部分 AI 缓存来自不同周年刷新日，不能当作统一重算过的 1337 初始状态。正式实施建议在选定的统一刷新日采样、保存固定基准，并验证实装数量和内部成本一起生成，避免只改一侧。
