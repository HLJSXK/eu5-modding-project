# 1406 存档：平民购买力普遍超过 +500% 的原因

分析日期：2026-10-23。代码参照：`8fe79b380147c3f1f0a45a8bddd5b9ba9a28f9fd`。

存档：`data/saves/SP_CAS_1406_01_23_de3601a2-b771-4e4e-a6bb-34fed262dca7.eu5`，游戏版本 1.4.3，日期 1406.1.23，571,801,306 字节。本次只做分析，没有调整游戏数据或算法。

四个主阶层的同口径缺货/低价分解见 [四阶层补充分析](FOUR_STRATA.md)，同时覆盖 CAS 与全球，并分别给出成本降幅、购买力倍率和百分点贡献。

## 结论

观察成立。国家界面 CAS 平民缓存是 **+570.00%**；对当前归属地点缓存重新求和为 **+568.79%**。全世界 1,099 个有 SOL 地点缓存、且平民基准支出为正的国家，其平民购买力中位数为 **+528.27%**；565 国达到 +500%。只看至少五个地点的 426 国，中位数仍为 **+601.78%**。

数值来自当前购买力定义：`alpha = 可支配资金 / 基准消费支出`，界面显示 `(alpha - 1) × 100%`。+500% 代表六倍篮子购买力。主因是平民篮子相对当前 SOL 收入模型很便宜；缺货过滤和低价进一步压低支出分母，逐商品五位小数截断再放大了这个比值。

储蓄、替代偏好、国家求解器分别检查过：CAS 储蓄项实际降低资金 8.972%；在保存的逐商品成本上，用普通精度应用全部有效商品因子只增加平民总支出约 0.49%；购买力读取的是资金与基准支出，国家求解器的最终地点系数不参与该比值。

这能解释当前模型为何产生这些数字，不能仅凭一个存档认定真实历史收入应是多少，或唯一合理的消费基线应是多少。

## 2. 哪些环节把分母压到了 8.35

以下固定 CAS 存档的平民资金 55.84570 和人口组成。前三行使用 HEAD 数量表及存档市场信息做静态反事实；后面明确使用存档成本缓存。它们用来解释量级，不代表重新运行游戏后的均衡。

| 计算口径 | 平民基准支出 | 固定资金下的购买力 |
| --- | ---: | ---: |
| HEAD 全部篮子商品按基准价，无过滤、无有效商品因子 | 21.33449 | +161.76% |
| 只保留存档供应缓存为正的商品，仍按基准价 | 14.48204 | +285.62% |
| 供应过滤后，按 min(存档当前市场价, 基准价)，普通精度 | 9.50731 | +487.40% |
| 上一行逐商品成本截断到五位小数 | 8.86122 | +530.23% |
| 存档实际保存的逐商品成本，无有效商品因子 | 8.87802 | +529.03% |
| 存档逐商品成本 × 保存的有效商品因子，普通精度 | 8.92113 | +525.99% |
| 同上按游戏精度逐步回放并汇总到地点 | **8.35024** | **+568.79%** |

### 篮子本身便宜

即使所有篮子商品都供应、都按基准价计费，支出也仅有 21.33，相对 55.85 的资金仍显示 +162%。因此只修改缺货处理或精度，无法把此快照拉回零附近。

### 缺货会缩小统计篮子

供应过滤使完整基准价篮子支出从 21.33 降为 14.48，减少约 **32.12%**。例如塞维利亚市场 14 的农民篮子中，玉米、小米、马铃薯、稻米、烟草的供应缓存为零；这些商品在 HEAD 基准价篮子中合计占农民成本约 **35.62%**。

目前代码只在 `goods_supply_in_market > 0` 时计入该商品成本。替代算法对参与商品计算偏好，并没有把所有缺失商品的原始篮子预算完整转给在售成员。因此在其他条件固定时，货品消失会使分母更小、显示购买力更高。这个数字同时反映了“剩余在售篮子的价格”和“篮子缩减”。

### 实际低价影响大，价格上限影响较小

供应过滤后，以当前价格计费的篮子成本从 14.48 降到约 9.5；这是大量商品便宜导致的。单独取消基准价上限，使用全部实际价格，成本只是从 **9.50731** 升到 **9.63667**，相差 **1.36%**。不能把高购买力主要归因于价格上限。

### 小数量在逐商品计算时反复截断

平民的许多需求量只有 `0.00001` 至 `0.00030`。HEAD 当前价反事实中，第一次逐商品成本截断使 9.50731 降为 8.86122，约 **6.79%**。

第二个截断边界是 `sol_substitution.py` 的市场阶层支出缓存：先逐商品算 `saved_unit_cost × sol_good_effective`，截断后才相加。按存档成本计算的普通精度合计是 8.92113，但逐步整数回放后是 8.35024，减少 **6.40%**。即使有效因子接近 1，每项向下损失一个小数单位也会累积。

精确回放使用：`cost_int × factor_int // 100000`，先汇总每类人口的单位成本，再计算 `unit_cost_int × population_int // 100000`。CAS 所有 **263 个地点、六个市场的平民基准支出均与存档精确一致，最大误差为 0 个五位小数单位**。

市场 14 的农民原始单位成本缓存为 0.00196，应用有效因子并逐项截断后为 0.00185；其劳工、士兵成本分别为 0.00255、0.00401。

存档逐商品缓存与 HEAD 当前价回算有小幅差别，所以 8.87802 与 8.86122 不能当成同一时间的精度对照；第二个截断边界直接使用保存的成本和因子，263 地点的精确一致不依赖对刷新时间的猜测。

## 3. 全局分布，以及购买力与实际需求的区别

| 范围 | 平民购买力 |
| --- | ---: |
| 所有有正基准支出的国家，国家中位数 | +528.27% |
| 至少五个地点的国家，国家中位数 | +601.78% |
| 全球地点缓存的资金合计 / 支出合计 - 1 | +692.57% |
| 全球 13,600 个正平民基准支出地点，地点中位数 | +253.90% |
| CAS 地点中位数 | +260.78% |

CAS 263 地点中 71 个达到 +500%；全球 13,600 地点中 4,865 个达到 +500%。所以“普遍 +500%”适合描述国家层级，不能理解为每个地点都在 +500% 附近。

对照国家：FRA +223.42%、ENG +371.73%、HUN +365.08%、MAM +648.54%、CHI +253.00%、TIM +1031.18%。

购买力表达的是资金能买多少个统计基准篮子。它不等于当前实际购买量，也不是国家求解器最终施加的地点需求系数。CAS 保存的策略是 8（顶点近似）；在 SOL 模型内，平民原始系数对应支出约 **21.40981**，最终系数对应支出约 **40.00726**，仍低于资金目标 55.84570 约 **28.36%**。这也不是引擎实际成交账，后者还受到原版人口、商品与购买规则影响。

因此不能用 +569% 推断市场已经完成六倍平民消费，也不能通过改国家求解器来改变这个显示比值的定义。

## 4. 后续校准的可检验方向

1. 先明确参考篮子含义：若用于衡量生活改善，应考虑保留固定的订阅组预算，或给缺货单列指标；否则货品减少也能推高数值。该变化会影响需求闭合，应作为模型设计修改评估。
2. 在较大尺度或人口聚合后计算商品支出，最后再还原单位，减少极小需求量逐项截断的偏差。需要验证运行时范围、求解器输入和市场成本缓存的一致性。
3. 在参考口径明确后，再跨国家、跨年代校准平民篮子与收入模型；保留订阅组完整、全部成员正需求、重叠商品去重等既有约束。
