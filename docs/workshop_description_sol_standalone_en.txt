[h1]SOL Standalone[/h1]

Created by request, this is a lightweight standalone version of [b]Standard of Living[/b]. It includes only SOL's core income and population-demand system, without the broader balance changes of the full mod.

[h2]Important Balance Warning[/h2]

Enabling only SOL Standalone will significantly accelerate snowballing because it does not include the full mod's anti-snowballing balance changes. Unless you specifically need to enable only SOL's core system, please play the full [b]Standard of Living[/b] mod instead.

[h2]Included Features[/h2]

[list]
[*]Income-based dynamic population demand.
[*]Local income, savings, maintenance, and market-spending calculations.
[*]Living Standard situation panel, map mode, location display, and tooltip.
[*]SOL's recalibrated population demand for the 55 vanilla goods.
[/list]

[h2]Not Included[/h2]

[list]
[*]War, economy, tax, diplomacy, food, climate, or anti-snowballing balance changes.
[*]Age scaling, GDP-to-development, migration support, or CMF settings.
[/list]

[h2]SOL Standalone is an alternative to the full Standard of Living mod. Do not enable both together.[/h2]
