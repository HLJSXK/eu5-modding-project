[h1]SOL-PP Compatibility Submod[/h1]

[h2]Prosper or Perish-led compatibility for Standard of Living[/h2]

This is a required compatibility layer for using [b]Standard of Living (SOL)[/b] together with [b]Prosper or Perish (PP)[/b]. It is not a standalone mod.

The final setup is intentionally compact and PP-led:
[list]
[*][b]Full Prosper or Perish[/b] remains the foundation.
[*][b]SOL's core Living Standard system[/b] remains active, including income-based pop demand, the Living Standard situation and map, and the location UI.
[*][b]A selected set of smaller SOL economic and balance changes[/b] remains where it does not undermine PP's core design.
[/list]

[h2]Why This Compatch Is Needed[/h2]

SOL and PP both modify pop demand, goods, food and climate balance, base location and RGO values, age scaling, infrastructure prices, and several war-related location modifiers. Loading both main mods without a compatch produces several different kinds of conflict:

[list]
[*]Some PP replacements overwrite SOL changes, while additive changes from both mods stack and can produce unintended values.
[*]Road costs, weather and Little Ice Age effects, and shared blockade, siege, occupation, and looting modifiers can combine outside either mod's intended balance.
[*]PP adds [b]victuals[/b] to the population basket, but the normal SOL calculation does not account for it.
[*]PP removes lumber pop demand, while unpatched SOL data can add lumber demand back into the economy.
[/list]

This compatch resolves those overlaps as one deliberate ruleset instead of allowing load order to decide them accidentally.

[h2]Final Ruleset[/h2]

[h3]Prosper or Perish takes priority[/h3]
[list]
[*]PP's food economy, population growth and migration, food storage, victuals, buildings, production methods, rural capacity, and infrastructure design remain active.
[*]PP owns the shared base location/RGO, weather, Little Ice Age, road, institution, blockade, siege, occupation, and looting values.
[/list]

[h3]SOL core features retained[/h3]
[list]
[*]Income-based monthly local pop-demand scaling.
[*]Living Standard situation, map display, location panel, income/savings/maintenance accounting, and demand cache.
[*]Full victuals support in SOL calculations and both goods displays.
[*]PP's zero lumber pop demand is preserved.
[/list]

[h3]Selected SOL balance retained[/h3]
[list]
[*]Age-scaled building efficiency and city/town upgrade costs.
[*]Low-control construction penalty and the configurable base tax-efficiency rule.
[*]Difficulty tax adjustments, configurable AI devastation recovery, diplomatic-capacity spending, and cultural-tradition stability discounts.
[*]Harsher war exhaustion, total/capital occupation pressure, wartime cabinet restriction, hostile-troop/raiding/razing effects, colonial restrictions, and the higher call-to-war favor cost.
[*]SOL gold-transfer scaling and action-price changes that do not conflict with PP.
[/list]

[h3]SOL features disabled in this compact setup[/h3]
[list]
[*]GDP-to-development.
[*]SOL base location/RGO, winter, and Little Ice Age rebalance.
[*]The food-consumption, prosperity, and RGO-expansion parts of SOL age escalation.
[*]SOL road-price changes and SOL deltas on shared blockade, siege, occupation, and looting modifiers.
[/list]

[h2]Required Main Mods[/h2]

[list]
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3698931463]Standard of Living[/url]
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3613232232]Prosper or Perish[/url]
[*]Community Mod Framework 2.* (required by Standard of Living)
[/list]

PP currently has no mod ID that this submod can declare as a formal dependency, so it must be subscribed to and enabled manually.

[h2]Installation And Load Order[/h2]

Subscribe to and enable all four mods, then place them in this order from top to bottom:

[olist]
[*]Community Mod Framework
[*]Prosper or Perish
[*]Standard of Living
[*][b]SOL-PP Compatibility Submod[/b]
[/olist]

[b]The compatibility submod must be below both Prosper or Perish and Standard of Living.[/b]

A new campaign is recommended. After SOL or PP receives a major update, verify that this compatch has been updated before starting a long campaign.

[h2]Compatibility Status[/h2]

The current compatch was generated for SOL 1.3.11 and reviewed against PP 0.9.0. Static generation and project validation are complete. Because either main mod can change a large number of shared economy objects, an Observer test is still recommended after updates before committing to a long campaign.

If victuals are missing from the SOL panels, lumber has pop demand, or road costs appear to include both mods' increases, check the load order first.
