# SOL 2026年10月大版本更新 · 视频导演稿

## 定位与总时长

这是一期“更新介绍”视频，不是从头完整介绍。结构沿用上一期 SOL 视频（BV17uDKBuEXX）的风格：先痛点后方案，白底 PPT 为主，配聊天气泡小剧场；游戏实录只用来证明“游戏里真的长这样”。

按你上期的语速（约 4.6 字/秒，含停顿）估算，口播约 **4 分 01 秒**（粗剪实测 4:01，含 3.5 秒片头无口播），离 5 分钟上限还有约 59 秒余量。录完如果超时，优先删 S11“其他改动”的第一句，再删 S10 最后一句（图标）。

Johan 梗放在第 10 秒左右（S01），配三步时间线：1.1 两个勾 → 1.2 一只大手把它们打叉 → 1.4 面包碗从火里爬出来，角落小字“恩格尔曲线：那我呢？”（恩格尔曲线这次确实没回来，这个梗也是事实）。

## 需要你做的事

### 一、准备存档（一次就好）

1. 用新版 SOL 开一个新档。国家建议选匈牙利或法兰西（阶层齐全，排名和各阶层数据都好看）。
2. 至少跑过一个 1 月 1 日，让全球排名和等级出现；跑满一年后才会出现“同比”。
3. 如果有时间，用观察者模式跑到 1400 年前后再存一个档，生活水平地图和排行榜会更有看头（U11、U12 用）。
4. 游戏语言用简体中文，录屏 1920×1080，关掉其他 UI 模组（Glorp UI 可以开，界面兼容）。

### 三、配音

按 `口播稿.txt` 录。口吻与上期一致：第一人称，略书面，梗点到即止。录完把音频拖进剪映，用“文稿匹配”或导入 `subtitles_estimated.srt` 后整体对齐。

### 四、剪辑

1. 把 `animatic_粗剪预览.mp4` 放到最底轨当参照。
2. 按分镜表把 `slides/` 里的 PPT 页和你的 U 素材铺上去，替换占位卡。
3. 配上口播和字幕，加一首轻 BGM（上期同款即可）。
4. 导出前看一眼总时长不超过 5:00。

## 重新生成

改了台词或页面后，在 VM 或任何装有 Pillow 和 ffmpeg 的环境里运行：

```bash
python3 tools/build_video.py <输出目录> <项目根目录>
```

这会重新生成 `slides/`、`口播稿.txt`、`subtitles_estimated.srt`、`timing.json` 和粗剪预览。台词在 `tools/script.json`，素材说明在 `tools/shots.json`。
