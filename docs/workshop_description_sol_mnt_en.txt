[h1]SOL-M&T Compatibility Submod[/h1]

This is a required compatibility patch for [b]Standard of Living (SOL)[/b] and [b]MEIOU and Taxes (M&T)[/b]. It is not standalone.

[h2]What It Does[/h2]

[list]
[*]SOL and M&T both change goods, economic balance, maintenance calculations, and the location UI. Without a patch, M&T's goods and SOL's demand calculations use different values, and one mod's location UI overwrites the other.
[*]With this patch, [b]M&T leads the economy[/b], including prices, production, food, RGO, buildings, estates, roads, and other economic balance.
[*]SOL keeps its core income-based dynamic demand, Living Standard UI and map, and migration support.
[*]A small set of non-conflicting SOL war, colonial, and diplomatic rules is also retained.
[/list]

[b]This patch must be below both SOL and M&T.[/b]

[h2]Compatibility[/h2]

Made for SOL 1.3.11 and M&T 0.1.6. A new campaign is recommended. After either main mod updates, make sure this patch has also been updated.
