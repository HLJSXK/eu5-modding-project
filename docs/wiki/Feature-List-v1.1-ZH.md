# Standard of Living v1.1 - 详细功能说明

## 当前状态

**版本：** v1.1.0 旧版

**范围：** 完整的 1.3 之前 SOL 需求系统，以及经济、战争、扩张、食物、气候和价格平衡系统。

**目标环境：** Europa Universalis V 1.1 时代玩法 / 元数据目标为 1.*

**依赖：** Community Mod Framework 2.* 用于游戏内配置。

这是 Standard of Living 的旧版完整分支。与后续 1.3 beta 版本不同，v1.1 保留完整替代商品模型、稀缺档位、按阶层恩格尔曲线和市场中心稀缺修正。

如果你希望体验原本完整的 SOL 经济模型，请使用本分支。若游玩更新的 EU5 版本，请优先查看当前 Workshop 页面。

## 设计目标

原版人口需求过于静态，而 SOL 希望构建一种更能反映经济能力和市场条件的需求模型：

- 更富裕的阶层应当消费更多，并逐步转向更高价值的商品。
- 更贫穷的阶层应当更容易受到主食和基础商品价格影响。
- 商品应当能在有意义的消费组内彼此替代。
- 稀缺商品应当失去需求份额，便宜且过剩的商品应当吸收更多需求。
- 市场价格应当重要，但需求仍应与收入绑定，而不是纯粹陷入价格循环。
- 战争、低控制力、食物压力和扩张成本都应当反过来限制无脑扩张。

## 完整 SOL 需求系统

### 1. 校准后的基础需求

SOL 通过生成后的商品需求注入重新校准人口基础需求。

来源流程：

```text
data/target_demand.csv
-> scripts/gen_pop_goods.py
-> src/stable/in_game/common/goods/z_SOL_pop_goods.txt
```

这条基线不是整个系统，只是动态 SOL 模型进行缩放、再分配和显示的修正基础。

### 2. 替代商品组

v1.1 分支包含 20 个需求组。组内商品会根据市场价格变化互相替代。

| 商品组 | 示例商品 |
|---|---|
| 基本衣物 | 布匹、皮革 |
| 粗制品 | 木材、砖石、工具、陶器 |
| 主食 | 小麦、大米、杂谷、玉米、土豆、豆类 |
| 调味品 | 糖、盐、橄榄 |
| 取暖燃料 | 木材、煤炭、蜂蜡 |
| 家居用品 | 家具、陶器、玻璃、纸张、蜂蜡 |
| 标准衣物 | 布匹、精纺品 |
| 嗜好饮料 | 葡萄酒、啤酒、烈酒、烟草 |
| 奢侈饮品 | 茶、咖啡、葡萄酒、可可 |
| 奢侈食物 | 野味、口粮、水果、鱼类 |
| 奢侈品 | 精纺品、毛皮、瓷器、漆器、大理石、玻璃 |
| 蛋白食物 | 鱼类、野味、牲畜 |
| 香料 | 藏红花、胡椒、丁香、辣椒 |
| 贵重品 | 黄金、白银、珠宝 |
| 珍宝 | 琥珀、宝石、象牙、珍珠 |
| 药品 | 草药、水银 |
| 祭祀物品 | 熏香、水银 |
| 武器 | 武器、火器 |
| 坐骑 | 马匹、大象 |
| 知识用品 | 纸张、书籍 |

部分商品会作为显示用次级成员出现在多个需求组中。但它们的主要稀缺指标组仍然唯一，以保证替代权重和稀缺评分稳定。

### 3. 稀缺与过剩档位

每个市场会按商品价格相对默认价格进行分类。档位会改变商品在替代组内的需求权重。

| 档位 | 价格条件 | 需求权重 |
|---|---:|---:|
| 严重稀缺 | 高于 230% | 0.25 |
| 中度稀缺 | 高于 170% | 0.50 |
| 轻度稀缺 | 高于 130% | 0.75 |
| 略便宜 | 低于 85% | 1.25 |
| 便宜 | 低于 65% | 1.50 |
| 非常便宜 | 低于 40% | 2.00 |

简单说，人口会尽量避开稀缺替代品，并购买更多便宜替代品。

### 4. 按阶层的恩格尔曲线

旧版 SOL 系统不会把所有人口当成同一个平均消费者。需求会按以下阶层分别计算预算份额：

- 贵族。
- 教士。
- 市民。
- 平民。
- 部落民。

因此，价格冲击会根据消费阶层不同而产生不同影响。平民需求对主食压力更敏感，贵族需求则更容易受到奢侈品和威望商品价格影响。

### 5. 时代需求系数

v1.1 需求模型使用时代系数，用于补偿早期缺少商品、建筑槽有限和替代品种类不足的问题。该系数在第 1 时代较高，并随游戏推进逐步下降。

| 时代 | SOL 时代系数 |
|---|---:|
| 第 1 时代 | 1.5 |
| 第 2 时代 | 1.425 |
| 第 3 时代 | 1.35375 |
| 第 4 时代 | 1.28606 |
| 第 5 时代 | 1.22176 |
| 第 6 时代 | 1.16067 |

这是 v1.1 完整系统和后续 1.3 beta 精简模型之间的主要差异之一。

### 6. 市场中心稀缺修正

稀缺压力会按市场、按阶层储存在市场中心地点上。模组每年更新类似以下变量：

```text
sol_market_scarcity_adj_nobles
sol_market_scarcity_adj_clergy
sol_market_scarcity_adj_burghers
sol_market_scarcity_adj_commoners
sol_market_scarcity_adj_tribesmen
```

这个修正按预算份额加权。对平民重要的商品短缺，会更强地压低平民需求；对贵族重要的商品短缺，则更强地压低贵族需求。

### 7. 生活水平 UI

SOL 增加了用于查看完整系统的界面：

- 全国生活水平局势。
- 生活水平地图着色。
- 全国与各阶层生活水平数值。
- 地点级生活水平数据。
- 替代商品提示覆盖。
- 商品提示中的稀缺与需求指标。

## 经济平衡系统

### 时代经济递增

经济压力会随时代推进而增长。当前时代的效果为累计值。

| 时代 | 建筑与 RGO 成本 | 城市/城镇升级成本 | 人口食物消耗 | 月度繁荣 |
|---|---:|---:|---:|---:|
| 第 1 时代 | 0% | 0% | 0% | -0.0015 |
| 第 2 时代 | +20% | +10% | +10% | -0.001 |
| 第 3 时代 | +40% | +20% | +20% | -0.0005 |
| 第 4 时代 | +60% | +30% | +30% | 0 |
| 第 5 时代 | +80% | +40% | +40% | +0.0005 |
| 第 6 时代 | +100% | +50% | +50% | +0.001 |

早期世界具有更紧的繁荣压力；后期世界更加繁荣，但扩张成本也显著升高。

### 反滚雪球建设

SOL 通过改变基础建设激励来放慢无脑扩张：

- 基础 RGO 规模降为 1。
- 总人口带来的 RGO 规模增长降低。
- 低控制力地点获得额外建设成本惩罚。
- 道路和铁路价格提高：

| 行动 | 原版成本 | SOL v1.1 成本 | 变化 |
|---|---:|---:|---:|
| 碎石路 | 10 | 20 | 2 倍 |
| 铺装路 | 25 | 50 | 2 倍 |
| 现代道路 | 50 | 150 | 3 倍 |
| 铁路 | 100 | 500 | 5 倍 |

### 税收、难度、外交与发展度

- 基础税收效率默认为 **-15%**，可通过 CMF 调整。
- AI 困难 / 极难难度税收加成减半。
- 玩家简单 / 极简单难度税收加成减半。
- 外交支出会随已使用外交容量变化。
- 文化传统可以降低稳定度投资成本。
- GDP 转发展度会按本地 GDP 每年提供发展度增长。
- AI 国家可以获得可配置的荒废度恢复加成，帮助负繁荣地区恢复。

## 战争与扩张系统

### 更严苛的厌战

厌战更加危险，可能进一步削弱或损害：

- 征召规模。
- 控制力。
- 稳定度。
- 合法性。
- 防御能力。

占领压力也更高：

| 条件 | SOL 效果 |
|---|---:|
| 全境占领 | 在原版基础上额外 +1.6 月度厌战，合计每月 2.0 |
| 首都被占领 | 在原版基础上额外 +0.2 月度厌战，合计每月 0.3 |

降低厌战内阁行动可以通过 CMF 设置为仅和平时期可用。

### 地方战争创伤

战争相关地点修正更加严苛。以下状态会更明显地影响繁荣、控制力、建设、迁移吸引力、发展、原材料和食物：

- 封锁。
- 围城。
- 占领。
- 敌军存在。
- 劫掠。
- 游牧劫掠。
- 焚掠。

### 殖民限制

AI 通常需要超过 **500 税基** 才会建立殖民特许。

例外：

- 历史殖民国家不受该税基限制。
- 殖民地国家只能在首都所在大区殖民。
- 玩家不受该规则限制。

### 外交行动抑制

请求其他国家加入战争需要更多 favors，用于减少无脑召唤参战。

## 食物、气候与价格平衡

### 食物与气候

- 轻度冬季会比原版造成更强食物压力。
- 普通冬季会比原版造成更强食物压力。
- 征召民兵会降低本地原材料产出和本地食物。
- 小冰期极端食物和产出惩罚被缓和，以减少纯粹的灾难螺旋。

### 价格再平衡

多项金币转移和行动价格被重新平衡。例如：

- 将军需要金币。
- 海军将领需要金币。
- 顾问和艺术家需要金币。
- 多项宗教与外交行动调整了金币缩放或上限。
- 道路和铁路更加昂贵。

## CMF 设置

Community Mod Framework 2.* 可以在游戏内控制 SOL 的主要模块。

| 设置组 | 控制内容 |
|---|---|
| SOL 人口需求 | 总开关、地图着色 |
| 经济平衡 | 总开关、基础税收效率、时代经济递增、稳定投资折扣、外交支出调整、难度税收削弱、GDP 转发展度、AI 繁荣恢复 |
| 战争加速 | 总开关、更高厌战、更严苛厌战效果、战时降低厌战限制 |

当 CMF 变量不可用时，许多系统有默认开启的回退行为；但 Workshop 包声明 CMF 为依赖，因此仍建议启用。

## 兼容性

旧存档可以加载，但推荐开新档。

旧存档加载后，市场缓存、年度 SOL 变量和月度需求值可能需要一些时间刷新。

不保证与其他模组兼容，尤其是编辑以下内容的模组：

- 人口需求。
- 商品定义。
- 商品价格。
- 本地或国家经济修正。
- 厌战。
- 殖民特许。
- 道路或行动价格。
- 生活水平 / 局势 GUI。

v1.1 完整需求模型比后续 1.3 beta 精简模型更重，因为它包含替代商品、稀缺档位、按阶层恩格尔曲线和市场中心稀缺修正。

## 推荐加载和游玩说明

- 游玩旧分支时使用 v1.1 Workshop 项。
- 启用 Community Mod Framework 2.*。
- 测试平衡时推荐开新档。
- 如果加载旧档，请让游戏运行一段时间，让年度和月度缓存完成刷新。
- 多人游戏中，所有玩家应使用相同模组版本、相同依赖和相同 CMF 设置。

## 反馈模板

反馈问题时，请尽量提供：

- 游戏版本。
- SOL 版本。
- 新档还是旧档。
- 国家和年份。
- 启用的其他模组。
- 是否修改过 CMF 设置。
- 问题发生前后出现了什么变化。
- 截图或日志，如果有的话。

比较有用的反馈示例：

- 某种商品需求长期明显过高或过低。
- 人口没有按预期避开稀缺商品。
- 某个国家以可复现方式经济崩溃。
- SOL 地图着色或面板数值看起来不正确。
- 厌战或殖民限制表现异常。
- 某个兼容性冲突可以用较小模组列表复现。
