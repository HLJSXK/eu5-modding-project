# Standard of Living - 详细功能说明

## 当前状态

**适配版本：** 欧陆风云5 1.4.*
**依赖：** Community Mod Framework 2.*（游戏内设置）
**建议：** 更新后开新档。

Standard of Living（SOL）是一款经济与平衡改版。它让人口需求跟着各阶层真正负担得起的钱走，取代原版定死的需求；加入商品替代，以及把“钱买不到的东西”也算进去的生活水平；同时附带一套反滚雪球、加重战争代价的平衡改动。

发布目标：

| 目标 | 说明 |
|---|---|
| Standard of Living | 完整版：需求系统、商品替代、生活水平、界面与平衡改动。 |
| SOL Standalone | 只含需求、替代、生活水平和界面，不含平衡改动，不依赖 CMF。不要与完整版同时启用。 |
| SOL-PP / SOL-M&T / SOL-JTG | Prosper or Perish、MEIOU and Taxes、Just Goods 的兼容子模组，放在两个主模组下方。 |

### 简史

SOL 1.1（EU5 1.1）曾经有替代组和按阶层的恩格尔曲线。EU5 1.2 的引擎改动破坏了这套设计依赖的接口，此后的版本只保留了基于收入的需求。当前版本以全新的国家级设计恢复了商品替代；恩格尔曲线、文化/宗教偏好和市场中心稀缺修正仍不恢复。

## 设计目标

原版人口需求定死且偏低。阶层的钱花不出去，只能攒成巨额存款；市场要靠国家无限建造终端建筑、自己掏钱买货才能运转。SOL 希望做到：

- 人口挣多少就花多少，让钱流回市场。
- 需求对价格有反应，同一类商品之间可以互相替代。
- 生活水平不只看钱，也看健康、清洁水、污染和文化。
- 用平衡改动防止经济变强后过早滚雪球。

## 一、基于收入的需求（购买力）

### 校准基础消费篮子

SOL 重新校准了 56 种商品的人口基础需求。篮子以 1340 年各国中位数为准：贵族 ×1、教士 ×2、平民（劳工、农民、士兵）×4、市民约为旧校准的 ×0.66，各商品数量保留一到两位有效数字。

- 引擎的发展度需求倍率设为 0，并抵消原版每种商品的发展度门槛。发展度不再放大或限制需求。
- 人口按名义价格购买商品，移除原版购买时的额外加价，使收入记账与支出一致。

### 市场基础支出

每年扫描一次所有市场，缓存各人口类型的一份基础篮子在当地市场的价格，按 `数量 × min(市场价, 默认价)` 计算。便宜的商品会降低基础支出，昂贵的商品不会把它推到默认价以上。

### 流动资金

对每个地点的每个阶层，SOL 计算它真正能花的钱：

- 该阶层在当地收入中的份额；
- 减去阶层建筑维护：每座该阶层的建筑每年计数一次，扣除该阶层 1 金当地收入；
- 按全国存款压力调整：存款高于目标时多花，低于目标时少花（最多 +50%）。

### 购买力与需求系数

```text
购买力 = 流动资金 / 基础支出
```

购买力是需求的唯一输入。没有钱为 −100%，三倍基础支出为 +200%。每月为每个有主陆地地点施加一个月的 `local_pop_demand` 修正。

随后国家级求解器调整各地系数，使每个阶层的全国总量符合全国购买力，同时保留地区差异：先尝试精确求解，失败时采用“绝不比原始结果更差”的近似解；地点少于 5 个的国家跳过求解器。

### 计算频率

玩家每月计算。AI 默认每年在自己的周年计算一次，大幅降低后期开销；新国家、新获得的地点、开局/读档和设置变更会立即处理。可在 CMF 的“性能”页把 AI 改回每月计算。

部落民没有基础消费篮子。

### 价格偏好

每种商品按市场价与基础价之比获得偏好权重：

| 市场价 / 基础价 | 权重 |
|---|---:|
| 低于 0.40 | ×2 |
| 0.40 – 0.65 | ×1.5 |
| 0.65 – 0.85 | ×1.25 |
| 0.85 – 1.30 | ×1 |
| 1.30 – 1.70 | ×0.75 |
| 1.70 – 2.30 | ×0.5 |
| 高于 2.30 | ×0.25 |

在每个已订阅的组内，需求从贵的成员流向便宜的成员；没有供应的商品退出该组，由其余成员分担。跨组商品的结果会合并计算。

### 如何生效

替代按国家计算：先按市场和人口类型汇总全国人口，再与需求系统同频计算。结果以 **“商品替代（某商品）”** 国家修正生效，同时进入购买力计算，使基础支出反映人们实际购买的东西。其他来源的需求修正会被保留并相乘，不会被覆盖。

该功能有独立的 CMF 开关（默认开启），关闭后恢复中性篮子。

## 三、生活水平

### 生活水平与购买力

- **购买力**回答“手里的钱够买多少基本生活所需”，是需求的唯一输入。
- **生活水平（SOL）**回答“人们过得怎么样”，是一个数值，不是百分比：

```text
生活水平 = 固定值之和 + (1 + 百分比之和) × 千人均年流动资金
```

百分比相加，只乘钱的部分；每个阶层的生活水平最低为 0，全国按人口加权。生活水平加成不会凭空产生可花的钱，也不会改变需求。

### 生活水平来源

SOL 新增两种地点修正：**本地生活水平**（固定值）和 **本地生活水平比例修正**（百分比）。首批施加在 17 种建筑上，与原版建筑修正一样随建筑等级缩放：

| 建筑 | 效果 |
|---|---|
| 医院 | +0.05 |
| 隔离所、疫病院 | +0.03 |
| 引水渠系统 | +0.02 |
| 达鲁希法医院 | +0.08 |
| 夏里特医院、卫生署（Magistrato alla Sanità） | +0.06 |
| 制革作坊 / 制革工场 / 制革厂 | −0.01 / −0.02 / −0.03 |
| 腐化处理作坊 / 腐化处理厂 | −0.02 / −0.03 |
| 炼铁厂、炼钢厂 | −0.02 |
| 剧院 | +2% |
| 歌剧院 | +3% |
| 图书馆 | +1% |

（建筑名以游戏内中文为准。）

经验法则：关乎生存的东西（健康、用水、污染）用固定值，对穷人影响最大；关乎生活品质的东西（文化）用百分比，对富人影响最大。战争、疾病、制度等更多来源在计划中。

### 生活水平的作用

| 作用 | 规则 |
|---|---|
| 移民吸引力 | 当地生活水平每 1 点 +0.02，最多 +0.5（生活水平 25 时达到） |
| 人口增长 | 当地生活水平低于 0.1 时 −0.1 个百分点；高于 10 时 +0.1 个百分点 |
| 等级 | 与按人口加权的世界平均比较：低于 75% 为低，高于 133% 为高，其余为中 |
| 全球排名 | 每年 1 月 1 日按生活水平给国家和各阶层排名；只有一个地点的国家不参与排名 |

## 四、界面

### 四格 SOL 信息栏

位于左侧国家按钮下方：

1. **生活水平**：全国生活水平、等级徽章和同比变化；悬浮窗列出全国与各阶层的人口、生活水平和同比。
2. **购买力**：全国购买力；悬浮窗按阶层显示 −100% 到 +200% 的条形图。
3. **商品替代**：悬浮窗以卡片形式列出所有替代组，显示有供应的成员数，每种商品下方有七级替代指示。
4. **全球排名**：名次和百分位；悬浮窗显示排名中的前后国家，以及各阶层的世界排名、百分位和世界最高。

悬停任意一格预览对应地图模式，左键点击切换。兼容 Glorp UI。

### 地图模式

| 地图模式 | 着色 |
|---|---|
| SOL生活水平 | 当地生活水平：0 为红，世界平均为黄，世界平均 3 倍为绿 |
| SOL购买力 | 当地原始购买力，−100% 到 +200% |
| SOL商品替代 | 国家原色；悬停国家查看其替代概况 |
| SOL排行榜 | 总排名，越靠前越绿；不参与排名的国家显示条纹 |

### 商品悬浮窗与地点窗口

- 商品悬浮窗列出该商品所属的替代组及全部成员，以及七档价格偏好；市场商品悬浮窗还会显示当前价格比并高亮当前档位。
- 地点窗口中的 SOL 按钮显示各阶层购买力和当地消费的商品；无主地点不显示该按钮。

## 五、经济平衡

基于 Ethereal 的 Anti Snowballing，所有部分都可在 CMF 中设置。

### 时代经济递增

| 效果 | 第 6 时代累计 |
|---|---:|
| 全局建筑效率 | −100% |
| RGO 扩张成本 | +100% |
| 城市升级成本 | +50% |
| 城镇升级成本 | +50% |
| 人口食物消耗 | +50% |
| 全局每月繁荣 | +0.001 |

### 反滚雪球建设

- 基础 RGO 规模降为 1，并降低总人口对 RGO 的加成。
- 低控制力地点建设效率降低。
- 道路价格：碎石路 ×2、铺装路 ×2、现代道路 ×3、铁路 ×5。

### 税收、外交与发展度

- 基础税收效率默认 **−15%**（可在 CMF 中调整）。
- 困难/极难 AI 与简单/极简单玩家的原版税收加成减半。
- 外交支出随已用外交容量变化。
- 文化传统可降低稳定度投资成本。
- GDP 转化发展度：地点每年根据本地 GDP 获得发展度。
- 可选的 AI 繁荣恢复，帮助繁荣为负的 AI 地区恢复。

## 六、战争与扩张

- 厌战进一步削弱征召规模、控制力、稳定度、合法性和防御能力。
- 全境被占领在原版基础上每月额外 +1.6 厌战，首都被占领额外 +0.2。
- 可选：战争期间禁止使用降低厌战的内阁行动。
- 封锁、围城、占领、敌军驻扎、劫掠、游牧劫掠和焚掠对繁荣、控制力、建设、移民吸引力、发展度、原材料和食物的影响更大。
- AI 通常需要 500 以上税基才会建立殖民特许；历史殖民国家例外，殖民地国家只在首都所在大区殖民，玩家不受限制。
- 请求他国加入战争需要更多人情。

## 七、食物、气候与价格

- 普通冬季和征召民兵带来更明显的本地食物压力。
- 缓和小冰期事件的极端食物与产出惩罚，避免纯粹的灾难螺旋。
- 将军、海军将领、顾问和艺术家需要金币；多项宗教、外交行动和金币转移重新平衡。

## 九、兼容性

- 推荐开新档。旧档可以加载，但缓存需要时间重建，价格需要时间稳定。
- Prosper or Perish、MEIOU and Taxes、Just Goods 需要各自的 SOL 兼容子模组，放在两个主模组下方；同一时间只能启用一个兼容子模组。
- 其他修改人口需求或商品的模组，在没有子模组的情况下会与 SOL 的校准冲突。欢迎提出兼容需求。
- SOL 内置一个以 Glorp UI 为基础、插入了 SOL 按钮的统合地点窗口。不需要安装 Glorp UI 或 Construction Manager；启用 Construction Manager 时会提供其自动化控件。其他整体覆盖地点窗口的模组会冲突。
- 其他模组作者可以在依赖 SOL 的子模组里，用 `local_sol_living_standard` 和 `local_sol_living_standard_modifier` 让自己的建筑影响生活水平。
